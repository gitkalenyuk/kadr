Налаштування: команди

5 команд у категорії «Налаштування». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • secrets.exportExport secrets
  • secrets.importImport secrets
  • secrets.statusSecret vault status
  • spending.getSpending and limits
  • spending.set_limitSet spending limit

secrets.export

Export secrets

Без кроку скасуванняSettings › Secrets › ExportMCP secrets_export

Writes every stored secret — all API key pools (with labels, order and enabled state) and other provider secrets — to one password-protected backup file, so they can be moved to another computer or user (the OS encryption of the vault cannot travel) — Settings → Secrets → Export. The file is AES-256-GCM encrypted with a key derived from the password by PBKDF2-HMAC-SHA256 (600 000 iterations); without the password it is useless. Only run this when the user explicitly asks for a backup: anyone with the file and the password gets every key. The result reports counts only, never a key. Keys that cannot be decrypted on this computer are skipped (skipped > 0). An existing file is not replaced unless overwrite=true. App setting, not undoable.

Параметри

ПараметрТипОпис
passwordобов’язковийstringPassword protecting the file, at least 8 characters. It is not stored anywhere; it is needed to import.
pathобов’язковийstringAbsolute path of the backup file to write, e.g. C:\Users\me\Documents\kadr-secrets.json.
overwritebooleanReplace the file when it already exists (default false: conflict error).
Типово false

Повертає

{path, entries, keys, pools, bytes, skipped?} — counts only, never a secret.

Приклади

Back up all API keys

curl -X POST http://127.0.0.1:7777/api/v1/commands/secrets.export \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"password":"correct horse battery","path":"C:\\Users\\me\\Documents\\kadr-secrets.json"}'
kadrctl run secrets.export --password 'correct horse battery' --path 'C:\Users\me\Documents\kadr-secrets.json'
// MCP tool: secrets_export
{
  "password": "correct horse battery",
  "path": "C:\\Users\\me\\Documents\\kadr-secrets.json"
}

secrets.import

Import secrets

Без кроку скасуванняSettings › Secrets › ImportMCP secrets_import

Reads a backup written by secrets.export and stores its secrets in this computer's encrypted vault — Settings → Secrets → Import. mode "merge" (default) appends keys missing from each provider's pool (a key already present is counted in keys_duplicate and skipped; imported keys go to the end of the failover order with status unknown) and adds or overwrites other secrets; mode "replace" first deletes every secret stored here, then imports — use it only when the user asks to restore exactly the backup. A wrong password or a damaged file changes nothing (invalid_argument). Returns counts and the affected pools, never a key. App setting, not undoable.

Параметри

ПараметрТипОпис
passwordобов’язковийstringThe password used when the backup was exported.
pathобов’язковийstringAbsolute path of a backup file written by secrets.export.
modestringmerge (default) keeps existing keys and adds new ones; replace deletes every stored secret first.
Одне з merge replaceТипово "merge"

Повертає

{entries_added, entries_updated, keys_added, keys_duplicate, pools: ["kind/provider"], created (backup time), replaced}.

Приклади

Restore keys on a new computer

curl -X POST http://127.0.0.1:7777/api/v1/commands/secrets.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"password":"correct horse battery","path":"C:\\Users\\me\\Documents\\kadr-secrets.json"}'
kadrctl run secrets.import --password 'correct horse battery' --path 'C:\Users\me\Documents\kadr-secrets.json'
// MCP tool: secrets_import
{
  "password": "correct horse battery",
  "path": "C:\\Users\\me\\Documents\\kadr-secrets.json"
}

Replace everything with the backup

curl -X POST http://127.0.0.1:7777/api/v1/commands/secrets.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"mode":"replace","password":"correct horse battery","path":"/Users/me/kadr-secrets.json"}'
kadrctl run secrets.import --mode replace --password 'correct horse battery' --path /Users/me/kadr-secrets.json
// MCP tool: secrets_import
{
  "mode": "replace",
  "password": "correct horse battery",
  "path": "/Users/me/kadr-secrets.json"
}

secrets.status

Secret vault status

Без кроку скасуванняSettings › SecretsMCP secrets_status

Describes where Kadr keeps API keys and how they are protected — Settings → Secrets. backend is "dpapi" (Windows Data Protection API: only this Windows user on this computer can decrypt), "keychain" (macOS login Keychain, service "Kadr") or "file" (Linux/other: a 0600 file, NOT encrypted — warning explains it). Lists every key pool (kind tts | video | llm …, provider id) with masked keys ("sk_…a1b2"), each key's status (ok, exhausted, invalid, rate_limited, unknown), last error, cooldown and remaining quota when the provider reports it, and how many keys are usable now. Never returns a secret value. Use the owning module's commands (tts.keys.*, videogen.keys.*, assistant settings) to add or remove keys; secrets.export / secrets.import back everything up.

Параметри

ПараметрТипОпис
kindstringOnly pools of this kind ("tts", "video", "llm"); omit for all.

Повертає

{backend, encrypted, location, warning?, entries, pools: count, keys: count, key_pools: [{kind, provider, usable, statuses{status: n}, keys: [{id, label, preview, status, disabled, usable, last_error, last_used, cooldown_until, quota{remaining, limit, unit, resets_at}, uses, failures}]}]} — masked previews only.

Приклади

Where are my keys and do they work?

curl -X POST http://127.0.0.1:7777/api/v1/commands/secrets.status \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run secrets.status
// MCP tool: secrets_status
{}

Only voice provider keys

curl -X POST http://127.0.0.1:7777/api/v1/commands/secrets.status \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"tts"}'
kadrctl run secrets.status --kind tts
// MCP tool: secrets_status
{
  "kind": "tts"
}

spending.get

Spending and limits

Без кроку скасуванняSettings › SpendingMCP spending_get

Reports money spent on paid AI providers (cloud voices, video generation, AI assistant APIs) and the daily spending limits — Settings → Spending. Amounts are Kadr's estimates from each provider's published prices (estimated=true) or amounts the provider reported, recorded when a paid call or job was submitted (refunds of failed jobs are negative). Days are local calendar days; the limit resets at local midnight. today.total is in the limit currency (USD by default; other currencies are converted with limits.rates or built-in rates, the rest is listed under unconverted). Use it before starting paid work to see how much of today's limit is left.

Параметри

ПараметрТипОпис
daysintegerHow many days of history to return, newest first (1..400, default 7). Unit: days.
Типово 7Діапазон 1 … 400
entriesintegerHow many individual charges to return, newest first (0..2000, default 50).
Типово 50Діапазон 0 … 2000

Повертає

{limits{daily (0 = none), currency, providers{id: daily}, rates?}, today{date, total, currency, providers{id: {amounts{currency: amount}, count}}, unconverted?}, remaining_today? (null without a limit), days[…same as today], entries[{time, provider, kind, model, op, amount, currency, estimated, job_id, note}]}.

Приклади

How much did I spend this week?

curl -X POST http://127.0.0.1:7777/api/v1/commands/spending.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run spending.get
// MCP tool: spending_get
{}

Last 30 days, no individual charges

curl -X POST http://127.0.0.1:7777/api/v1/commands/spending.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"days":30,"entries":0}'
kadrctl run spending.get --days 30 --entries 0
// MCP tool: spending_get
{
  "days": 30,
  "entries": 0
}

spending.set_limit

Set spending limit

Без кроку скасуванняSettings › SpendingMCP spending_set_limit

Sets the daily spending limit for paid AI providers — Settings → Spending. Before a paid generation or cloud voice call Kadr reserves its estimated cost; if today's spending plus running jobs plus that estimate would exceed the limit, the call is refused (conflict error with a hint) instead of spending. daily is the limit for all providers together (0 removes it); provider + provider_daily set a separate limit for one provider id (the preset id, e.g. "fal", "elevenlabs", "runway"; 0 removes it). Calls whose cost is unknown are not blocked by the limit — the UI and the assistant still ask before running them. Omitted parameters keep their value. App setting, not undoable.

Параметри

ПараметрТипОпис
currencystringISO 4217 code of the limit currency (USD, EUR, GBP, CNY…). Omit to keep it (default USD).
dailynumberDaily limit for all providers together in the limit currency; 0 = no limit. Omit to keep it. Unit: currency.
Діапазон 0 … 1000000
providerstringProvider id for a per-provider limit (with provider_daily), e.g. "fal".
provider_dailynumberDaily limit for the given provider; 0 removes the per-provider limit. Unit: currency.
Діапазон 0 … 1000000
ratesobjectExchange rates as {currency: USD value of 1 unit}, e.g. {"CNY": 0.14}; merged into the stored rates.

Повертає

{limits{daily, currency, providers, rates}, today{date, total, currency, providers}, changed}.

Приклади

Spend at most $5 a day

curl -X POST http://127.0.0.1:7777/api/v1/commands/spending.set_limit \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"daily":5}'
kadrctl run spending.set_limit --daily 5
// MCP tool: spending_set_limit
{
  "daily": 5
}

Cap fal.ai at $2 a day

curl -X POST http://127.0.0.1:7777/api/v1/commands/spending.set_limit \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"provider":"fal","provider_daily":2}'
kadrctl run spending.set_limit --provider fal --provider_daily 2
// MCP tool: spending_set_limit
{
  "provider": "fal",
  "provider_daily": 2
}

Remove the daily limit

curl -X POST http://127.0.0.1:7777/api/v1/commands/spending.set_limit \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"daily":0}'
kadrctl run spending.set_limit --daily 0
// MCP tool: spending_set_limit
{
  "daily": 0
}
