timeline.get

Get timeline

Без кроку скасуванняTimelineMCP timeline_get

Returns a compact view of the timeline made for AI agents — much smaller than project.get. Tracks are listed top-to-bottom exactly as the CapCut timeline shows them: text/sticker/effect/filter and overlay tracks first, then the main_video track, then audio tracks. Each track has its id, type, layer (its compositing index in project.tracks: 0 is drawn first, at the bottom), lock/hide/mute flags and its clips in time order. Each clip has id, kind (video, photo, audio, sticker, text, effect, filter, adjustment), label (file name, text content or effect/filter id), start_us, end_us, duration_us, the source range it uses, speed, volume (video/audio), link_group, transition_out, filter and effects. Also returns markers, the current playhead, the timeline settings and a compact list of materials with how often each is used. Call it before editing to find segment and track ids, and after editing to check the result.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Повертає

{project_id, name, duration_us, playhead_us, fps, settings, tracks: [{id, type, name?, layer, muted, locked, hidden, segments: [{id, kind, label, start_us, end_us, duration_us, material_id?, source_start_us, source_duration_us, speed, reverse?, still?, volume?, link_group?, transition_out?, filter?, effects?}]}], markers: [{id, time_us, label?, color?}], materials: [{id, type, name, duration_us, uses}]}.

Приклади

Read the timeline

curl -X POST http://127.0.0.1:7777/api/v1/commands/timeline.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run timeline.get --project_id prj_1a2b3c4d5e6f
// MCP tool: timeline_get
{
  "project_id": "prj_1a2b3c4d5e6f"
}

timeline.segment.add

Add to timeline

СкасовуєтьсяLibrary › Media › Card › + (or drag to the timeline)MCP timeline_segment_add

Places an imported material (from media.import / media.list) on the timeline as a new clip — like pressing + on a media card or dragging it onto the timeline in CapCut. Where it goes: without track_id, video and photo clips go to the main track (created if needed); audio, sticker and other clips go to the first track of their type that is free at at_us, otherwise to a new track. On the main track with the magnet on (default) the clip is inserted at the clip boundary nearest to at_us and every later clip ripples right — there are never gaps; when at_us is omitted it is appended to the end of the main track. With the magnet off it lands at at_us and later clips are pushed right only if they would overlap. On other tracks the clip starts exactly at at_us (default: the playhead); if that spot on the requested track is taken, CapCut creates a new track directly above it and puts the clip there. new_track forces a brand-new track. Length: the whole material for video/audio (from source_start_us), 5 s for photos, 3 s for stickers; duration_us overrides it but cannot exceed the material for video/audio. Video clips keep their own sound until audio.extract. Locked tracks cannot receive clips (conflict).

Параметри

Діапазон 1 … ∞

Типово 0Діапазон 0 … ∞

timeline.segment.crop

Crop

СкасовуєтьсяToolbar › CropMCP timeline_segment_crop

Crops a video or photo clip — the Crop button in the timeline toolbar, which opens CapCut's crop dialog with ratio presets. Rectangle fields are fractions of the source frame (x,y = top-left corner, w,h = size; omitted fields keep the current crop, or the full frame). ratio fits the rectangle to an aspect ratio of the source pixels: with no rectangle it picks the largest centred area of that ratio; with a rectangle it shrinks it around its centre to match. 'free' keeps the rectangle as given. Calling it with neither a rectangle nor a fixed ratio resets the crop to the full frame (CapCut's Reset). A legacy rect object {x,y,w,h} is also accepted.

hnumberHeight of the kept area as a fraction of the source height (1 = full height). Unit: source fraction.
Діапазон 0.01 … 1

Одне з free 16:9 9:16 1:1 4:3 3:4

timeline.segment.delete

Delete

DeleteСкасовуєтьсяToolbar › DeleteMCP timeline_segment_delete

Deletes clips from the timeline (the media stays in the library). On the main track with the magnet on the following clips shift left to close the gap (ripple delete); on other tracks a gap remains. Linked clips (e.g. a video and its extracted audio) are deleted together when linkage is on. Tracks other than the main track that become empty are removed, as in CapCut. The transition into a deleted clip is removed. Clips on locked tracks cannot be deleted.

{deleted: [segment ids]} — every removed clip including linked ones.

timeline.segment.delete_left

Delete left

QСкасовуєтьсяToolbar › Delete leftMCP timeline_segment_delete_left

timeline.settings.set

Timeline settings

СкасовуєтьсяToolbar › Right toggles (magnet, snapping, linkage, preview axis)MCP timeline_settings_set

Toggles the timeline helpers on the right of CapCut's timeline toolbar. main_track_magnet: the main track never has gaps — inserts ripple later clips right and deletes close gaps; turning it on closes existing gaps immediately. auto_snapping: dragged clip edges, trims and moves snap to clip edges, the playhead, markers and 0 within 100 ms. linkage: clips sharing a link_group (a video and its extracted audio) are selected, moved, trimmed, split and deleted together. preview_axis: the player previews the frame under the mouse while hovering the timeline. Only the given toggles change; all default to on except preview_axis.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

linkagebooleanEdit linked clips (video + extracted audio) together.
main_track_magnetbooleanMain-track magnet: keep the main track gap-free (ripple editing).
preview_axisbooleanPreview the frame under the mouse while hovering the timeline.

Повертає

The settings after the change {main_track_magnet, auto_snapping, linkage, preview_axis}.

timeline.track.add

Add track

СкасовуєтьсяTimeline › Track headerMCP timeline_track_add

Adds an empty track. CapCut usually creates tracks automatically when you drop clips (see timeline.segment.add and timeline.segment.move with new_track); use this when you want to target a fresh track explicitly. Position follows CapCut: video_overlay tracks go above the main/overlay tracks, text/sticker/effect/filter/adjustment tracks on top of all visual tracks, audio tracks below the existing audio tracks. A project has exactly one main_video track, so adding another one is a conflict. Note: tracks other than the main track disappear when an edit removes their last clip.

timeline.track.set

Set track options

СкасовуєтьсяTimeline › Track header › Lock, Hide, MuteMCP timeline_track_set

Changes the toggles in a track header: locked (clips on a locked track cannot be selected, moved, trimmed, split or deleted — every edit returns conflict until it is unlocked), hidden (the track is not drawn in the preview or export; visual tracks only), muted (the sound of every clip on the track is silenced; video and audio tracks) and the track name. Only the given fields change. Works on locked tracks so they can be unlocked.
