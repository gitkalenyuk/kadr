Для ШІ-агентів

Довідник команд

Кожна дія в Kadr — це одна з цих 249 команд. Кнопки редактора, REST API, MCP-інструменти та kadrctl викликають той самий реєстр, тож ця сторінка — повна мапа того, що вміє редактор.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

Як викликати команду

  • REST: POST http://127.0.0.1:7777/api/v1/commands/<name> з JSON-об’єктом аргументів і заголовком Authorization: Bearer <token>. Відповідь — {"ok": true, "result": …} або {"ok": false, "error": {code, message, hint, field}}. Докладніше — REST API.
  • MCP: назва інструмента — це назва команди, де крапки замінено на підкреслення (timeline.segment.split → timeline_segment_split). Докладніше — налаштування MCP.
  • CLI: kadrctl run <name> --param value; kadrctl describe <name> виводить цю саму документацію. Докладніше — kadrctl.

Домовленості

  • Увесь час задається цілими мікросекундами (2500000 = 2,5 с) у параметрах із суфіксом _us. kadrctl також приймає 2.5s, 1500ms або 00:01:02.5.
  • Команди в межах проєкту приймають project_id — візьміть його з project.list або project.create. Ідентифікатори сегментів повертає timeline.get.
  • Команди з позначкою «Скасовується» створюють рівно один крок скасування; пакет викликів (POST /api/v1/projects/{id}/batch або MCP-інструмент kadr_batch) — теж один крок.
  • Помилки містять машинозчитуваний code і підказку hint, як виправити виклик, — написану для ШІ-агентів.
