Транскрипт: команди

7 команд у категорії «Транскрипт». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • transcript.clearDelete transcript
  • transcript.delete_textDelete text
  • transcript.delete_wordsDelete words
  • transcript.getGet transcript
  • transcript.remove_fillersRemove filler words
  • transcript.remove_pausesRemove pauses
  • transcript.transcribeTranscribe

transcript.clear

Delete transcript

СкасовуєтьсяMCP transcript_clear

Removes the stored transcript of a material (e.g. before transcribing again in another language). Captions already created are kept. Undoable.

Параметри

ПараметрТипОпис
material_idобов’язковийstringMaterial whose transcript is removed (from media.list or transcript.get).
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Повертає

{material_id, words: number of words removed}.

Приклади

Forget a transcript

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.clear \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"material_id":"mat_1a2b3c4d5e6f","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run transcript.clear --material_id mat_1a2b3c4d5e6f --project_id prj_1a2b3c4d5e6f
// MCP tool: transcript_clear
{
  "material_id": "mat_1a2b3c4d5e6f",
  "project_id": "prj_1a2b3c4d5e6f"
}

transcript.delete_text

Delete text

СкасовуєтьсяMCP transcript_delete_text

Finds a phrase in the transcript and cuts it out of the video — the easiest transcript edit for an AI agent ("delete 'so basically what I mean is'"). Matching ignores case and punctuation and is word by word within one clip. By default the first occurrence on the timeline is deleted (or the occurrence-th); all=true deletes every occurrence. The cut works like transcript.delete_words (split, delete, ripple, captions follow). One undo step; not_found when the phrase is not in the transcript.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
textобов’язковийstringThe words to delete, e.g. "you know what I mean".
allbooleanDelete every occurrence instead of one.
Типово false
occurrenceintegerWhich occurrence to delete when all=false (1 = the first on the timeline).
Типово 1Діапазон 1 … ∞
ripple_captionsbooleanMake caption cues follow the cut (later cues move left, removed words disappear from their cue). Default true.
Типово true
segment_idstringOnly search this clip (default: every transcribed audible clip).

Повертає

{matches: total found, cuts: [{segment_id, start_us, end_us, text}], removed_us, captions_changed, duration_us}.

Приклади

Cut a sentence

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.delete_text \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","text":"let me start again"}'
kadrctl run transcript.delete_text --project_id prj_1a2b3c4d5e6f --text 'let me start again'
// MCP tool: transcript_delete_text
{
  "project_id": "prj_1a2b3c4d5e6f",
  "text": "let me start again"
}

Cut every 'you know'

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.delete_text \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"all":true,"project_id":"prj_1a2b3c4d5e6f","text":"you know"}'
kadrctl run transcript.delete_text --all --project_id prj_1a2b3c4d5e6f --text 'you know'
// MCP tool: transcript_delete_text
{
  "all": true,
  "project_id": "prj_1a2b3c4d5e6f",
  "text": "you know"
}

transcript.delete_words

Delete words

СкасовуєтьсяLibrary › Transcript › DeleteMCP transcript_delete_words

Transcript-based editing: deletes words from a clip by cutting the video/audio where they are spoken (select words in the transcript → Delete). ranges are inclusive word indices from transcript.get for that segment_id. Each range removes the time from the first word's start to the last word's end plus the silence after it (up to 0.5 s, so the next word follows naturally): the clip is split, the part is deleted together with linked clips (extracted audio), and the rest of the track moves left (on the magnet main track every later clip ripples, and linked clips follow). Caption cues follow the cut unless ripple_captions=false. Everything is ONE undo step. Word indices of the clip change after the edit — call transcript.get again.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
rangesобов’язковийobject[]Word ranges to delete: [{"from": 3, "to": 5}] (inclusive indices from transcript.get → words[].index). [3, 5] pairs and single indices are accepted too.
segment_idобов’язковийstringClip whose words are deleted (from transcript.get → segments[].segment_id).
ripple_captionsbooleanMake caption cues follow the cut (later cues move left, removed words disappear from their cue). Default true.
Типово true

Повертає

{cuts: [{segment_id, start_us, end_us, text}] (timeline times before the edit), removed_us, captions_changed, duration_us (project length after)}.

Приклади

Delete words 3–5

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.delete_words \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","ranges":[{"from":3,"to":5}],"segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run transcript.delete_words --project_id prj_1a2b3c4d5e6f --ranges '[{"from":3,"to":5}]' --segment_id seg_1a2b3c4d5e6f
// MCP tool: transcript_delete_words
{
  "project_id": "prj_1a2b3c4d5e6f",
  "ranges": [
    {
      "from": 3,
      "to": 5
    }
  ],
  "segment_id": "seg_1a2b3c4d5e6f"
}

Delete two separate words

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.delete_words \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","ranges":[2,9],"segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run transcript.delete_words --project_id prj_1a2b3c4d5e6f --ranges '[2,9]' --segment_id seg_1a2b3c4d5e6f
// MCP tool: transcript_delete_words
{

  "segment_id": "seg_1a2b3c4d5e6f"
}

transcript.get

Get transcript

Без кроку скасуванняLibrary › TranscriptMCP transcript_get

Returns the transcript of the timeline — the Transcript panel: for every clip with sound (main track, overlays, audio tracks; or only segment_id) the recognised words mapped onto the TIMELINE (speed, speed curves, reverse and trims are honoured; words outside the clip's trimmed range are left out), with their source times and confidence, plus the clip's text. Clips whose material has not been transcribed are listed with transcribed=false (run transcript.transcribe). Word indices are per clip and are what transcript.delete_words expects; they change when the clip is edited, so re-read after edits. Clips that are not heard (muted track, volume 0 — e.g. a video whose sound was extracted to a linked audio clip) are omitted unless include_silent=true.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
include_silentbooleanAlso list clips that are muted or have volume 0.
Типово false
include_wordsbooleanInclude the word list (false = text only).
Типово true
segment_idstringOnly this clip (a video or audio clip).

Повертає

{segments: [{segment_id, track_id, track_type, material_id, material_name, transcribed, audible, language, model, start_us, end_us, text, words: [{index, text, start_us, end_us (timeline), source_start_us, source_end_us, confidence}]}], count, words (total), untranscribed_material_ids}.

Приклади

{
  "project_id": "prj_1a2b3c4d5e6f"
}

transcript.remove_fillers

Remove filler words

СкасовуєтьсяLibrary › Transcript › Remove filler wordsMCP transcript_remove_fillers

Cuts filler words out of the speech ("Remove filler words"): hesitation sounds that are always fillers — English um, uh, er, erm, ah, hmm, mm; Ukrainian/Russian е, еее, ем, ммм, а-а, хм, ну (elongated spellings like "ummm" match too) — and words often used as fillers only when they are set off by commas or sentence breaks: English like, you know, I mean, so, well, basically, actually, literally, kind of, sort of; Ukrainian типу, коротше, значить, ніби, як би, ну от, власне; Russian типа, короче, значит, как бы, вот, в общем. language=auto uses each transcript's language (all lists for other languages); words adds your own fillers (always removed). Each filler is cut like transcript.delete_words. Use preview=true to see the list first. One undo step.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
languagestringBuilt-in filler lists: auto (transcript language), all, none (only words), en, uk or ru.
Одне з auto all none en uk ruТипово "auto"
previewbooleanOnly report what would be removed; the project is not changed.
Типово false
ripple_captionsbooleanMake caption cues follow the cut (later cues move left, removed words disappear from their cue). Default true.
Типово true
segment_idstringOnly this clip (default: every transcribed audible clip).
wordsstring[]Extra filler words or phrases to remove wherever they occur, e.g. ["okay", "right so"].

Повертає

{found: [{segment_id, text, start_us, end_us}], count, removed_us, preview, cuts, captions_changed, duration_us}.

transcript.remove_pauses

Remove pauses

СкасовуєтьсяLibrary › Transcript › Remove pausesMCP transcript_remove_pauses

Shortens every silence between words that lasts at least min_pause_us ("Remove pauses > X s"), using the word timings of the transcript: each pause is cut down to keep_us (half kept before, half after) so speech does not sound chopped. With edges=true the silence before the first and after the last word of a clip is trimmed too. Clips without any recognised words are left alone. Cuts ripple like transcript.delete_words; captions follow. Use preview=true to see the pauses first. One undo step. (For silence detection from the audio level instead of words see ai.remove_silence.)

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
edgesbooleanAlso trim the silence at the start and end of each clip.
Типово true
keep_usintegerHow much of each pause to keep (default 0.3 s). Unit: microseconds.
Типово 300000Діапазон 0 … 5000000
min_pause_usintegerPauses at least this long are shortened (default 1 s). Unit: microseconds.
Типово 1000000Діапазон 100000 … 60000000
previewbooleanOnly report what would be removed; the project is not changed.
Типово false
ripple_captionsbooleanMake caption cues follow the cut (later cues move left, removed words disappear from their cue). Default true.
Типово true
segment_idstringOnly this clip (default: every transcribed audible clip).

Повертає

{found: [{segment_id, start_us, end_us}], count, removed_us, preview, cuts, captions_changed, duration_us}.

Приклади

Remove pauses over 1 s

curl -X POST http://127.0.0.1:7777/api/v1/commands/transcript.remove_pauses \

transcript.transcribe

Transcribe

Без кроку скасуванняLibrary › Transcript › TranscribeMCP transcript_transcribe

Recognises the speech of one material (or of the materials of segment_ids, or of every audible clip when both are omitted) and stores it as the material's transcript: every word with its start/end in SOURCE time and a confidence. This is the Transcript panel's "Transcribe" button; no captions are created (use captions.auto or captions.from_transcript for that). Afterwards transcript.get shows the words on the timeline and transcript.delete_words / delete_text / remove_fillers / remove_pauses edit the video by editing the text. Materials that already have a transcript are skipped unless force=true or a different explicit language is requested. Runs as a background job like captions.auto (wait=true blocks). Not undoable (transcripts are analysis data; transcript.clear removes one).

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
devicestringWhere recognition runs: auto (CUDA GPU when usable, else CPU int8), cuda or cpu. A failing GPU falls back to the CPU.
Одне з auto cuda cpuТипово "auto"
forcebooleanTranscribe again even when the material already has a transcript (e.g. to use a bigger model).
Типово false
languagestringSpoken language: "auto" (detect, default) or a code/name such as en, uk, es, de, fr, pt, ru, zh, ja, ko, ar, hi, it, nl, pl, tr, vi, th, id, ms, bn, my, ro, tl (Filipino). Locales ("en-US") and English names ("Ukrainian") are accepted. captions.asr_status lists all ~100 languages.
Типово "auto"
material_idstringMaterial to transcribe (from media.list). Omit to use segment_ids or every audible clip.
modelstringWhisper model size: tiny (fastest, least accurate), base, small (default: good accuracy, ~1× real time on a CPU, ~5× faster on an NVIDIA GPU), medium, large-v3 (best, slow without a GPU). Only models already downloaded can be used.
Одне з tiny base small medium large-v3Типово "small"
promptstringOptional hint text for the recogniser: names, jargon or spelling to prefer (e.g. "Kadr, CapCut, Kyiv").
segment_idstringShortcut for a single clip.
segment_idsstring[]Transcribe the materials of these clips.
waitbooleantrue = block until the job finishes and return its final status (with the result); false (default) = return the job right away and report progress through captions.progress events / captions.status.
Типово false

Повертає

Job status like captions.auto (kind "transcript"); when done result = {transcribed: [{material_id, language, model, words, text (first ~280 characters)}]}.
