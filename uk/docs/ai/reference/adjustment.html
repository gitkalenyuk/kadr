Корекція: команди

7 команд у категорії «Корекція». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • adjustment.auto_enhanceAuto adjust
  • segment.reset_adjustReset adjustments
  • segment.reset_curvesReset curves
  • segment.reset_hslReset HSL
  • segment.set_adjustSet colour adjustments
  • segment.set_curvesSet curves
  • segment.set_hslSet HSL

adjustment.auto_enhance

Auto adjust

СкасовуєтьсяInspector › Adjustment › Basic › Auto adjustMCP adjustment_auto_enhance

Automatically corrects the colour of a video/photo clip or of an adjustment layer — CapCut's Auto adjust wand. Renders one representative frame (by default the middle of the segment; time_us picks another moment) of what the segment colours — the clip itself WITHOUT its current adjustments, filter and effects, or for an adjustment-layer segment everything on the tracks below it — and analyses it: luminance percentiles set exposure (median towards mid grey without clipping the highlights) and contrast (stretch a flat tonal range), a grey-world estimate on near-neutral midtones sets temperature and tint (removes colour casts such as orange tungsten or blue shade), and low mean chroma raises saturation a little. Writes exposure, contrast, temperature, tint and saturation (other adjustments, HSL and curves are kept; keyframed fields get a keyframe at the playhead). strength scales the correction (0.5 = half). Running it twice gives the same values. Returns the applied values and the measurements. Needs the media to be readable (ffmpeg for video).

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
strengthnumberHow much of the computed correction to apply, 0..1 (default 1).
Типово 1Діапазон 0 … 1
time_usintegerFrame to analyse, relative to the segment start. Defaults to the middle of the segment. Unit: microseconds.
Діапазон 0 … ∞

Повертає

segment.reset_adjust

Reset adjustments

СкасовуєтьсяInspector › Adjustment › ResetMCP segment_reset_adjust

Returns every colour adjustment of a clip (or adjustment segment) to neutral — basic sliders (incl. hue, fade, grain, shine), all eight HSL bands and every tone curve — and removes its LUT and all adjust.* keyframes: the Reset button of CapCut's Adjustment tab. Filters and effects are not affected (use filter.remove / effect.remove). To reset only HSL or curves use segment.reset_hsl / segment.reset_curves.

segment.set_adjust

Set colour adjustments

СкасовуєтьсяInspector › Adjustment › BasicMCP segment_set_adjust

Sets colour/light controls of a video or photo clip, or of an adjustment segment (which applies to all tracks below it) — the Adjustment tab → Basic in CapCut. Pass any subset of: brightness, contrast, saturation, exposure, temperature, tint, highlights, shadows, vignette, hue (global hue rotation, -1..1 = -180°..+180°) and shine (local contrast / clarity; negative = soft glow) — each -1..1, 0 = neutral; CapCut's inspector shows them as -100..100 — and sharpen, fade (lifted blacks) and grain (film grain) 0..1, plus an optional .cube LUT with lut_intensity 0..1. Omitted fields keep their value. Fields animated by keyframes (adjust.<field>) record the value as a keyframe at the playhead. Render order: exposure → brightness → contrast → highlights/shadows → temperature/tint → hue + HSL → saturation → curves → fade → LUT → shine → sharpen → vignette → grain. Per-colour-range changes use segment.set_hsl, tone curves segment.set_curves, automatic correction adjustment.auto_enhance; segment.reset_adjust returns everything (incl. HSL and curves) to neutral.

segment.set_curves

Set curves

СкасовуєтьсяInspector › Adjustment › CurvesMCP segment_set_curves

Sets the tone curves of a video/photo clip or adjustment segment — the Curves page of CapCut's Adjustment tab. A curve maps input level x to output level y (both 0..1, 0 = black, 1 = white) through up to 16 control points joined by a smooth monotone cubic (no overshoot: rising points give a rising curve). The master (luma) curve applies to all channels first, then the r, g and b curves. Ways to call it: preset alone replaces every channel with a built-in look (lighten, darken, fade, contrast, cool, warm, vintage; custom = straight lines to edit by hand); channel + points replaces one channel (channel defaults to master); preset + channel + points starts from the preset and then replaces that channel. points is an array of [x, y] pairs or {x, y} objects; they are sorted by x, x values must differ, and the straight line [[0,0],[1,1]] means 'no change'. Examples of shapes: S-curve [[0,0],[0.25,0.18],[0.75,0.82],[1,1]] adds contrast; [[0,0.1],[1,1]] lifts the blacks (matte); a red curve [[0,0],[0.5,0.56],[1,1]] warms the midtones. Curves render after the basic sliders and HSL and before a .cube LUT.

Параметри

ПараметрТипОпис

segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
channelstringChannel that points apply to: master (luma, all channels), r, g or b. Defaults to master.
Одне з master r g b
pointsarray[]Control points of the channel: 2..16 pairs [x, y] (or {x, y} objects), each 0..1. [[0,0],[1,1]] = identity (clears the channel).
presetstringBuilt-in curve set: custom (straight lines), lighten, darken, fade, contrast, cool, warm or vintage. Replaces all four channels.
Одне з custom lighten darken fade contrast cool warm vintage

segment.set_hsl

Set HSL

СкасовуєтьсяInspector › Adjustment › HSLMCP segment_set_hsl

Adjusts one colour range of a video/photo clip or adjustment segment — the HSL page of CapCut's Adjustment tab (8 colour dots). Bands: red (0°), orange (30°), yellow (60°), green (120°), cyan (180°), blue (240°), purple (270°), magenta (300°). Each band has h (hue shift: -1 = -30° … +1 = +30° around the colour wheel), s (saturation: -1 = grey, +1 = double) and l (lightness: -1 darker … +1 lighter), all -1..1 with 0 = unchanged. Pixels between two band centres belong to both with smooth weights, so there are no hard edges, and a band never affects hues beyond its neighbours (shifting red does not touch blue). Neutral greys are never changed. Omitted h/s/l keep their value. band "all" writes the given values into every band (e.g. s -1 → black and white). Alternatively pass bands = {red: {h, s, l}, …} to set several bands at once (omitted bands and fields are kept). Use segment.reset_hsl to clear one band or all of them. Typical recipes: bluer sky = blue {s: 0.3, l: -0.2}; greener foliage = yellow {h: 0.4} + green {s: 0.3}; skin = orange {s: -0.1, l: 0.1}.
