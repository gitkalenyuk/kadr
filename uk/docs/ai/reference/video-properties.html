Властивості відео: команди

9 команд у категорії «Властивості відео». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • segment.getGet segment properties
  • segment.resetReset properties
  • segment.set_backgroundSet canvas background
  • segment.set_blendSet blend mode
  • segment.set_chroma_keySet chroma key
  • segment.set_cropSet crop rectangle
  • segment.set_maskSet mask
  • segment.set_opacitySet opacity
  • segment.set_transformSet transform

segment.get

Get segment properties

Без кроку скасуванняInspectorMCP segment_get

Returns one segment with everything the inspector shows for it: the raw segment, its track, the kind (video, photo, audio, text, sticker, effect, filter, adjustment), the material, which property commands apply (capabilities), the keyframeable properties, and the evaluated values (transform, opacity, volume, adjustments and source time, keyframes interpolated) at time_us — by default at the playhead (clamped into the segment). Use it to check the effect of segment.* / keyframe.* commands.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
time_usintegerTime relative to the segment start to evaluate keyframes at. Defaults to the playhead. Unit: microseconds.
Діапазон 0 … ∞

Повертає

{segment, track_id, track_type, kind, material?, capabilities, keyframe_properties, time_us, evaluated, volume_db}.

Приклади

Inspect a clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/segment.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run segment.get --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: segment_get
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

segment.reset

Reset properties

СкасовуєтьсяInspector › Section › ResetMCP segment_reset

Resets one group of a segment's properties to CapCut's defaults — the ↺ buttons of the inspector sections. Groups: transform (position, scale 100%, rotation 0, flips + their keyframes), blend (opacity 100%, normal blend + opacity keyframes), crop, mask, chroma_key, background (canvas fill → project default), adjust (all colour adjustments, LUT, adjust.* keyframes), audio (0 dB, no fades, voice effect, noise reduction and normalisation off, volume keyframes), speed (1x, no curve, pitch off — the timeline length changes and the main track ripples like segment.set_speed), animation (in/out/combo/loop), keyframes (every keyframe) and all (every group that applies to this segment type). A specific group that does not apply (e.g. audio on a photo) is rejected with invalid_argument. Content (text, source range, filters, effects, transitions) is never touched.

Параметри

ПараметрТипОпис
groupобов’язковийstringWhich group of properties to reset; all resets every applicable group.
Одне з transform blend crop mask chroma_key background adjust audio speed animation keyframes all
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.

Повертає

{segment, rippled_segments?} after the reset.

segment.set_background

Set canvas background

СкасовуєтьсяInspector › Video › Basic › CanvasMCP segment_set_background

Sets the canvas fill shown behind a main-track clip where it does not cover the frame (e.g. a vertical video on a 16:9 canvas) — Video → Basic → Canvas in CapCut. type: color (solid colour), blur (blurred, zoomed copy of the clip; blur 0..1 = strength), image (a picture file), none (use the project's canvas background from project.set_canvas). apply_to_all copies the setting to every video/photo clip on the main track (CapCut's 'Apply to all'). Only main-track clips have a canvas background.

segment.set_blend

Set blend mode

СкасовуєтьсяInspector › Video › Basic › BlendMCP segment_set_blend

Sets how a clip mixes with the layers below it — Video → Basic → Blend in CapCut. Blend modes only show a difference on overlay tracks (or text/stickers) because the main track has nothing below it except the canvas. Modes: normal, darken, screen, overlay, multiply, lighten, hard_light, soft_light, linear_burn, color_burn, color_dodge, add (linear dodge / lighter), difference, exclusion. Optionally sets opacity in the same call.

СкасовуєтьсяInspector › Video › Remove BG › Chroma keyMCP segment_set_chroma_key

Removes a colour from a video/photo clip (green/blue screen) — Video → Remove BG → Chroma key in CapCut. color is the colour to key out (#RRGGBB, CapCut's colour picker); intensity 0..1 is how wide a range of similar colours becomes transparent (default 0.5 when the key is created); shadow 0..1 keeps/darkens shadows cast on the screen. enabled=false removes the chroma key. СкасовуєтьсяToolbar › CropMCP segment_set_crop

segment.set_mask

Set mask

СкасовуєтьсяInspector › Video › MaskMCP segment_set_mask

Adds, edits or removes the mask of a video/photo clip — Video → Mask in CapCut. Shapes: linear (one straight edge through the centre, rotate it to choose the side), mirror (a band of height h), circle (ellipse w×h), rectangle (w×h with round corners), heart, star; none removes the mask. Geometry is in clip fractions: x,y is the centre (0.5,0.5 = middle of the clip), w,h the size (1 = clip size), rotation in degrees, feather 0..1 softens the edge, round 0..1 rounds rectangle corners, invert shows the outside instead. Changing the type resets the geometry to that shape's defaults; omitted fields keep their value. type may be omitted to tweak an existing mask.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
feathernumberEdge softness: 0 = hard edge, 1 = very soft. Unit: fraction 0..1.
Діапазон 0 … 1
hnumberMask height relative to the clip height (mirror band height, circle, rectangle, heart, star). Unit: clip fraction.
Діапазон 0.01 … 4
invertbooleanShow the area outside the shape instead of inside.
rotationnumberRotation of the mask shape in degrees clockwise. Unit: degrees.
Діапазон -360 … 360
roundnumberCorner roundness of the rectangle mask: 0 = square corners, 1 = pill shape. Unit: fraction 0..1.
Діапазон 0 … 1
typestringMask shape; none removes the mask. Required when the clip has no mask yet.
Одне з none linear mirror circle rectangle heart star
wnumberMask width relative to the clip width (circle, rectangle, heart, star). Unit: clip fraction.
Діапазон 0.01 … 4
xnumberHorizontal centre of the mask (0 = left edge of the clip, 0.5 = middle, 1 = right edge). Unit: clip fraction.
Діапазон -1 … 2
ynumberVertical centre of the mask (0 = top edge of the clip, 0.5 = middle, 1 = bottom edge). Unit: clip fraction.
Діапазон -1 … 2

segment.set_transform

Set transform

СкасовуєтьсяInspector › Video › Basic › TransformMCP segment_set_transform

Sets position, scale, rotation and flips of a visual segment — Video → Basic → Transform in the CapCut inspector (also used for text and stickers). Only supplied fields change. Units: x and y move the centre of the clip in canvas fractions (0 = centred, 1 = centre on the right/bottom edge, -1 = left/top edge; positive y is down; range -2..2); scale is a multiplier where 1 = fit inside the canvas (0.01..4, i.e. 1%..400%); rotation is in degrees clockwise (-360..360). If a property is animated by keyframes, its new value is stored as a keyframe at the playhead instead (listed in result.keyframed), exactly like dragging a slider in CapCut after adding a keyframe. Audio, effect, filter and adjustment segments have no picture and are rejected with invalid_argument.

ПараметрТипОпис
