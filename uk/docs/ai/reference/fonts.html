Шрифти: команди

5 команд у категорії «Шрифти». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • font.catalogFont catalogue
  • font.importImport font file
  • font.installInstall font
  • font.removeRemove font
  • font.rescanRescan fonts

font.catalog

Font catalogue

Без кроку скасуванняInspector › Text › Font › More fontsMCP font_catalog

Lists Kadr's curated catalogue of downloadable font families — the "More fonts" section of the Text → Font picker. Every family is free and open-source (SIL Open Font License 1.1) from the google/fonts repository; most support Cyrillic (cyrillic=true; ukrainian is verified after installation). Each entry has an id (also the font id to use in text.update font once installed), name, style category (sans, serif, display, handwriting, monospace, pixel), a short note on its look and best use, download size, the exact file URLs, licence and specimen page, and installed=true when it is already available (downloaded into the Kadr data folder or bundled with the app). Use it to pick a font by mood, then call font.install {id} and text.update {font: id}. Read-only and offline: nothing is downloaded. Filters: query (name, id or note), category, cyrillic, installed.

Параметри

ПараметрТипОпис
categorystringOnly families of this style: sans, serif, display, handwriting, monospace or pixel.
Одне з sans serif display handwriting monospace pixel
cyrillicbooleantrue = only families with Cyrillic letters (Ukrainian/Russian text); false = only Latin-only ones.
installedbooleantrue = only families that are already installed; false = only those that still need font.install.
querystringCase-insensitive search in the family name, id and note, e.g. "script", "retro", "mono".

Повертає

{count, total, families:[{id, name, category, cyrillic, ukrainian? (after install), note, license, license_url, page_url, repo_path, variable, size_bytes, files:[{style, file, url, size_bytes}], installed, source?, font_id, job?{state, progress, error}}], categories, base_url, folders{downloaded, bundled[], system[]}}.

Приклади

All handwriting fonts with Cyrillic

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.catalog \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"category":"handwriting","cyrillic":true}'
kadrctl run font.catalog --category handwriting --cyrillic
// MCP tool: font_catalog
{
  "category": "handwriting",
  "cyrillic": true
}

Search for a pixel font

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.catalog \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"query":"pixel"}'
kadrctl run font.catalog --query pixel
// MCP tool: font_catalog
{
  "query": "pixel"
}

font.import

Import font file

Без кроку скасуванняInspector › Text › Font › Import font fileMCP font_import

Installs a font file from this computer into the Kadr data folder so it can be used in texts — "Import font file" in the Text → Font picker. Accepts TrueType (.ttf), OpenType (.otf) and collections (.ttc/.otc); the file is checked (it must parse and draw Latin, digit or Cyrillic glyphs; web fonts .woff/.woff2 and CFF2 variable fonts are rejected with a hint) and copied — the original stays where it is. The family name inside the font becomes the font id ("My Brand Sans" → "my_brand_sans"); importing the other styles of the same family (Bold, Italic…) adds them to that family. The category (sans, serif, display, handwriting, monospace, pixel) is inferred from the font unless given. Publishes fonts.changed. Make sure the font's licence allows the use you plan.

Параметри

ПараметрТипОпис
pathобов’язковийstringAbsolute path of the .ttf/.otf/.ttc file to import.
categorystringOnly families of this style: sans, serif, display, handwriting, monospace or pixel.
Одне з sans serif display handwriting monospace pixel
replacebooleanReplace an already imported file of the same family and style (or a catalogue install of that family).
Типово false

Повертає

{font_id, family, style, category, cyrillic, ukrainian, variable, path (the stored copy), replaced}.

Приклади

Import a downloaded font

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"path":"C:\\Users\\me\\Downloads\\MyBrandSans-Regular.ttf"}'
kadrctl run font.import --path 'C:\Users\me\Downloads\MyBrandSans-Regular.ttf'
// MCP tool: font_import
{
  "path": "C:\\Users\\me\\Downloads\\MyBrandSans-Regular.ttf"
}

Import as a handwriting font

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"category":"handwriting","path":"/Users/me/Downloads/MyHand.otf"}'
kadrctl run font.import --category handwriting --path /Users/me/Downloads/MyHand.otf
// MCP tool: font_import
{
  "category": "handwriting",
  "path": "/Users/me/Downloads/MyHand.otf"
}

font.install

Install font

Без кроку скасуванняInspector › Text › Font › More fontsMCP font_install

Downloads a font family from font.catalog into the Kadr data folder (<DataDir>/fonts/<id>/) so it can be used in any text — the Install button in the Text → Font picker. Fetches the family's font files and its OFL.txt licence over HTTPS from the google/fonts repository, checks every file (size limits, TrueType/OpenType signature, the font must draw), checks that the licence is the SIL Open Font License, then moves the folder into place atomically — a failed or interrupted download leaves nothing behind. Variable fonts get real Regular and Bold weights. Runs in the background and returns at once unless wait=true; progress arrives as font.progress events (state queued → downloading → verifying → installing → done | failed, with downloaded_bytes/total_bytes/progress), and fonts.changed when the font is ready. Afterwards use font_id with text.update {font}. An already installed family is not downloaded again (already_installed=true) unless force=true. Fails with not_found for unknown ids and not_available when the internet cannot be reached.

Параметри

ПараметрТипОпис
idобов’язковийstringCatalogue id from font.catalog, e.g. "montserrat", "caveat", "press_start_2p".
forcebooleanDownload and reinstall even when the family is already installed.
Типово false
waitbooleanBlock until the font is installed (or failed) instead of returning immediately.
Типово false

Повертає

{started, already_installed, font_id, message, job{id, font_id, state, file, downloaded_bytes, total_bytes, progress, error, hint}}.

Приклади

Install Montserrat in the background

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.install \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"id":"montserrat"}'
kadrctl run font.install --id montserrat
// MCP tool: font_install
{
  "id": "montserrat"
}

Install Caveat and wait until it is ready

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.install \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"id":"caveat","wait":true}'
kadrctl run font.install --id caveat --wait
// MCP tool: font_install
{
  "id": "caveat",
  "wait": true
}

font.remove

Remove font

Без кроку скасуванняВидаляє даніInspector › Text › Font › Remove fontMCP font_remove

Deletes a font family that was installed with font.install or font.import (library.list kind=font category=Downloaded) from the Kadr data folder. Built-in, bundled and operating-system fonts cannot be removed here (conflict). Texts that use the removed font fall back to Go Sans until it is installed again (font.install restores catalogue fonts with the same id). Publishes fonts.changed.

Параметри

ПараметрТипОпис
font_idобов’язковийstringFont id of a downloaded/imported family, e.g. "montserrat".

Повертає

{font_id, family, dir}.

Приклади

Remove Montserrat

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.remove \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"font_id":"montserrat"}'
kadrctl run font.remove --font_id montserrat
// MCP tool: font_remove
{
  "font_id": "montserrat"
}

font.rescan

Rescan fonts

Без кроку скасуванняInspector › Text › Font › RescanMCP font_rescan

Re-reads every font folder — the Kadr data folder (downloaded/imported fonts), the folders bundled with the app (<exe dir>/fonts, Kadr.app/Contents/Resources/fonts on macOS, KADR_FONTS_DIR) and, with system=true, the operating system's font folders — so fonts copied there while Kadr runs appear in library.list kind=font without a restart. Returns the number of families per source and the folders that were scanned. Publishes fonts.changed.

Параметри

ПараметрТипОпис
systembooleanAlso rescan the operating-system font folders (slower; a few seconds with thousands of fonts).
Типово true

Повертає

{downloaded, bundled, system, total (family counts), folders{downloaded, bundled[], system[]}}.

Приклади

Pick up newly installed fonts

curl -X POST http://127.0.0.1:7777/api/v1/commands/font.rescan \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run font.rescan
// MCP tool: font_rescan
{}
