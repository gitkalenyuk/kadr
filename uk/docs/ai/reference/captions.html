captions.add

Add caption

СкасовуєтьсяLibrary › Captions › Manual captionsMCP captions_add

Adds a caption cue typed by hand (CapCut's Manual captions) on the caption track at at_us (default: the playhead). It takes the look and position of the existing captions on that track (or style_id, or the default style) and gets estimated word timings so highlight styles work. When the next cue starts earlier than at_us + duration_us the new cue is shortened to fit; starting inside an existing cue is a conflict.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
textобов’язковийstringCaption text; \n breaks lines.
at_usintegerStart on the timeline (default: the playhead). Unit: microseconds.
Діапазон 0 … ∞
duration_usintegerLength of the cue (default 2 s). Unit: microseconds.
Типово 2000000Діапазон 100000 … 60000000
style_idstringCaption style id from library.list kind=caption_style, e.g. cap_clean, cap_highlight_word, cap_karaoke_bar, cap_pop_word, cap_box_dark.
track_idstringText track (default: the first caption track, created when missing).

Повертає

{segment_id, track_id, cue: {segment_id, track_id, index, start_us, end_us, text, style_id, words}}.

Приклади

Add a caption at 5 s

  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"at_us":5000000,"project_id":"prj_1a2b3c4d5e6f","text":"Welcome back!"}'
kadrctl run captions.add --at_us 5s --project_id prj_1a2b3c4d5e6f --text 'Welcome back!'
// MCP tool: captions_add
{
  "at_us": 5000000,
  "project_id": "prj_1a2b3c4d5e6f",
  "text": "Welcome back!"
}

captions.asr_status

Speech recognition status

Без кроку скасуванняMCP captions_asr_status

Reports whether local speech recognition (auto captions, transcripts) works on this computer: the Python interpreter found (KADR_PYTHON overrides it), the faster-whisper version, whether an NVIDIA GPU is usable, which Whisper models are downloaded (tiny, base, small, medium, large-v3 — Kadr never downloads models itself), plus the list of recognisable languages and the defaults. When unavailable, code/message/hint explain what to install. The first call takes a few seconds (it starts Python); the answer is cached.

Параметри

Типово false

Повертає

{available, engine, python, python_version, version, cuda, models: {tiny: true, …}, code?, message?, hint?, default_model, models_list, devices, languages: [{code, name}]}.

captions.auto

Auto captions

Без кроку скасуванняLibrary › Captions › Auto captionsMCP captions_auto

Generates captions from the speech in the timeline, like CapCut's Captions → Auto captions → Generate, but fully offline: the sound of every audible clip (main track, overlays and audio tracks; muted tracks and clips with volume 0 are skipped — or only segment_ids) is recognised locally with Whisper (faster-whisper in a Python subprocess, word-level timestamps), the words are stored on each material as its transcript (source time, reused next time — see transcript.get) and turned into caption cues on a text track named "Captions": at most max_lines lines of max_chars characters, split at sentences, commas and pauses, each cue carrying per-word timings (TextStyle.words, relative to the cue start) so word-highlight caption styles animate. Existing cues on the Captions track over the transcribed clips are replaced (replace=false adds a second track). Recognition runs as a background job: the call returns {job_id, state…} at once; follow captions.progress events or poll captions.status {job_id} (or pass wait=true to block until done — fine for clips of a few minutes). Creating the cues is ONE undo step ("Create captions from transcript"); transcripts themselves are analysis data and are not undone. Errors not_available (code "not_available") when Python/faster-whisper/the model is missing — see captions.asr_status. Typical speed: small model ≈ 5× real time on an NVIDIA GPU, ≈ 1× on a CPU.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
devicestringWhere recognition runs: auto (CUDA GPU when usable, else CPU int8), cuda or cpu. A failing GPU falls back to the CPU.
Одне з auto cuda cpuТипово "auto"
forcebooleanTranscribe again even when the material already has a transcript (e.g. to use a bigger model).
Типово false
languagestringSpoken language: "auto" (detect, default) or a code/name such as en, uk, es, de, fr, pt, ru, zh, ja, ko, ar, hi, it, nl, pl, tr, vi, th, id, ms, bn, my, ro, tl (Filipino). Locales ("en-US") and English names ("Ukrainian") are accepted. captions.asr_status lists all ~100 languages.
Типово "auto"
max_charsintegerCharacters per line (default from the style, 42 for cap_clean; reduced automatically on portrait canvases).
Діапазон 8 … 80
max_linesintegerLines per caption (default 2, from the style).
Діапазон 1 … 4
max_wordsintegerWords per caption; 0 = no limit, 1 = one word at a time (default from the style).
Діапазон 0 … 50
modelstringWhisper model size: tiny (fastest, least accurate), base, small (default: good accuracy, ~1× real time on a CPU, ~5× faster on an NVIDIA GPU), medium, large-v3 (best, slow without a GPU). Only models already downloaded can be used.
Одне з tiny base small medium large-v3Типово "small"
promptstringOptional hint text for the recogniser: names, jargon or spelling to prefer (e.g. "Kadr, CapCut, Kyiv").
replacebooleanReplace existing cues on the Captions track over the captioned clips (default). false keeps them and puts the new captions on a new track.
Типово true
segment_idstringShortcut for a single clip (same as segment_ids with one id).
segment_idsstring[]Only caption these clips (ids of video/audio clips with sound). Omit to caption every audible clip.
style_idstringCaption style from library.list kind=caption_style, e.g. "cap_highlight_word" (default: the style of the existing captions, else "cap_clean").
waitbooleantrue = block until the job finishes and return its final status (with the result); false (default) = return the job right away and report progress through captions.progress events / captions.status.
Типово false

Повертає

Job status {job_id, project_id, kind: "captions", state: queued|running|done|failed|cancelled, phase, progress 0..1, material_ids (being transcribed), language, detected_languages, model, device, media_s, elapsed_s, error?, result?}. When done, result = captions.from_transcript's result {track_id, count, segment_ids, words, languages, removed, transcribed: [{material_id, language, words, text}]}.

captions.from_transcript

Create captions from transcript

СкасовуєтьсяLibrary › Captions › Create from transcriptMCP captions_from_transcript

Creates caption cues from the transcripts already stored on the materials (made by captions.auto or transcript.transcribe) without running speech recognition again — e.g. after editing the video, or to re-caption with other line rules. Words heard in the chosen clips (or every audible clip) are mapped to timeline time (speed, speed curves and reverse are honoured) and grouped into cues: a new cue starts after a pause of 0.7 s, after a sentence, or when max_lines × max_chars would overflow (preferring a comma in the second half); lines are balanced. Each cue is a text segment on the "Captions" track with text.words = per-word timings relative to the cue start (for word-highlight styles). With replace=true (default) existing cues on the caption track over those clips are removed first, and when style_id is omitted the look and position of the existing captions are kept. One undo step.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
max_charsintegerCharacters per line (default from the style; 42 for cap_clean, fewer on portrait canvases).
Діапазон 8 … 80
max_linesintegerLines per cue (default from the style, usually 2).
Діапазон 1 … 4
max_wordsintegerWords per cue; 0 = no limit, 1 = one word at a time (default from the style).
Діапазон 0 … 50
replacebooleanRemove existing cues that overlap the captioned clips (default true). false = a new caption track.
Типово true
segment_idsstring[]Clips to caption (default: every audible clip whose material has a transcript).
style_idstringCaption style id from library.list kind=caption_style, e.g. cap_clean, cap_highlight_word, cap_karaoke_bar, cap_pop_word, cap_box_dark.
track_idstringText track to fill (default: the existing Captions track, or a new one).

Повертає

{track_id, count, segment_ids (new cues), words, languages, style_id, removed (old cues removed), untranscribed_segment_ids}.

captions.import

Import caption file

СкасовуєтьсяLibrary › Captions › Upload caption fileMCP captions_import

Imports a subtitle file as caption cues (CapCut's Upload caption file): SubRip .srt, WebVTT .vtt, Advanced SubStation .ass/.ssa (Dialogue lines; override tags stripped, \N = line break) or LRC lyrics .lrc ([mm:ss.xx] lines, [offset:], enhanced <mm:ss.xx> word tags become word timings). The format comes from the extension (or format). Cues go to a new "Captions" text track (or track_id / the existing caption track with replace=true) in the chosen caption style, shifted by offset_us; overlapping cues are trimmed. Without word timings in the file they are estimated from the text so word-highlight styles work. One undo step.

Параметри

ПараметрТипОпис
pathобов’язковийstringAbsolute path of the subtitle file (UTF-8).
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
estimate_wordsbooleanGive cues without word timings estimated ones (proportional to word length).
Типово true
formatstringsrt, vtt, ass or lrc (default: from the file extension / content).
Одне з srt vtt ass lrc
offset_usintegerShift every cue by this much (negative = earlier; cues ending before 0 are dropped). Unit: microseconds.
Типово 0
replacebooleanClear the target caption track (track_id or the existing Captions track) first.
Типово false
style_idstringCaption style (default "cap_clean").
track_idstringText track to fill; it must be free where the cues go unless replace=true.

Повертає

{track_id, count, segment_ids, skipped (cues before 0), format}.

СкасовуєтьсяLibrary › Captions › StylesMCP captions_set_style
