Бібліотека: команди

3 команди у категорії «Бібліотека». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • library.getGet library item
  • library.listList library items
  • library.previewPreview library item

library.get

Get library item

Без кроку скасуванняLibraryMCP library_get

Returns one library item with all its details: name, categories, description, default parameters (effect intensity/speed, filter intensity, voice-effect ffmpeg filter), default duration, the full TextStyle of a text template, or the available styles of a font. Use it to inspect an id found in library.list or stored in a project (e.g. segment.transition_out.type). Animated items include preview {url, frames, fps, width, height} (the hover sprite strip); call library.preview to look at the motion as one image.

Параметри

ПараметрТипОпис
idобов’язковийstringItem id from library.list, e.g. "mix", "vhs", "film", "in_fade".
kindобов’язковийstringLibrary kind of the item (see library.list).
Одне з transition effect filter animation text_template font sticker voice_effect caption_style generated text_effect text_animation sound_effect

Повертає

The item: {kind, id, name, category, categories, description, anim_kind?, default_duration_us?, params?, style?, thumbnail, preview?}.

Приклади

Inspect the VHS effect

curl -X POST http://127.0.0.1:7777/api/v1/commands/library.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"id":"vhs","kind":"effect"}'
kadrctl run library.get --id vhs --kind effect
// MCP tool: library_get
{
  "id": "vhs",
  "kind": "effect"
}

library.list

List library items

Без кроку скасуванняLibraryMCP library_list

Lists the built-in library of one kind — exactly what the left panel tabs show: transitions, video effects, colour filters, clip animations (In/Out/Combo/Loop), text templates (style presets), fonts (embedded Go fonts, fonts installed on this computer, fonts bundled with Kadr and fonts downloaded with font.install — see font.catalog), stickers and voice effects. Every item has a stable id to pass to the matching command (transition.set type, effect.add effect_id, filter.add filter_id, animation.set id, text.add template_id, text.update font, sticker.add sticker_id, segment.set_audio voice_effect), a display name, CapCut-style categories, default parameters/durations and a thumbnail path (GET it with the API token for a PNG preview rendered by the engine). Filter by category tab and/or a case-insensitive search query, like the search box in the panel. More kinds: sound_effect (sfx.add), caption_style (captions.set_style), text_effect (text.apply_effect), text_animation (text.set_glyph_animation), generated (media.generate preset_id). Effects carry params.schema — the named sliders accepted by effect.set_params ({id, label, min, max, default}); transitions list their direction/softness options (see transition.set and transition.get). Items that move (transitions, effects, filters, clip animations, animated text templates/word art, text animations, caption styles with word highlight, animated stickers and generated clips) also carry preview {url, frames, fps, width, height}: GET url for a JPEG sprite strip (frames side by side, one seamless loop) — the app's hover preview; items without it are static. To SEE how an item plays, call library.preview (a PNG contact sheet).

Параметри

ПараметрТипОпис
kindобов’язковийstringWhich library to list: transition, effect, filter, animation, text_template, font, sticker, voice_effect, sound_effect, caption_style, text_effect, text_animation or generated.
Одне з transition effect filter animation text_template font sticker voice_effect caption_style generated text_effect text_animation sound_effect
categorystringOnly items in this category tab (case-insensitive), e.g. "Trending", "Basic", "In", "Retro". The result's categories field lists valid values.
querystringCase-insensitive search on the item name, id, categories and description (the panel's search box).

Повертає

{kind, categories: [category tab names in display order], total, items: [{kind, id, name, category, categories, description, anim_kind?, default_duration_us?, params?, style? (text templates), thumbnail, preview? {url, frames, fps, width, height}}]}.

library.preview

Preview library item

Без кроку скасуванняLibraryMCP library_preview

Renders how a library item PLAYS as one PNG contact sheet (frames left to right, top to bottom) so an AI agent can see a transition, effect, filter, clip animation, animated text template, text animation, caption style highlight, animated sticker or animated generated clip before applying it. Uses the same engine and sample pictures as the hover previews of the app: transitions go from a sunny landscape (clip A, progress 0) to a night city (clip B, progress 1); effects run over time on the landscape (static effects such as vignette show a before/after divider); filters show a before/after divider; clip animations move a small clip on a dark stage (dashed outline = rest position); text kinds render sample text. Static items (fonts, voice effects, non-animated templates/word art/stickers) return their thumbnail as a single tile with animated=false. Every item that animates has a preview field in library.list / library.get (the app's hover sprite: GET preview.url for a JPEG strip). Read-only.

Параметри

ПараметрТипОпис
idобов’язковийstringItem id from library.list, e.g. "cube_turn_left", "vhs", "film", "in_pop".
kindобов’язковийstringLibrary kind of the item: transition, effect, filter, animation, text_template, text_effect, text_animation, caption_style, sticker, generated (others are static).
Одне з transition effect filter animation text_template font sticker voice_effect caption_style generated text_effect text_animation sound_effect
columnsintegerTiles per row; rows are added as needed.
Типово 3Діапазон 1 … 6
framesintegerNumber of moments (tiles) to render; more tiles show the motion in finer steps.
Типово 6Діапазон 2 … 12
tile_widthintegerWidth of each tile; the height follows the preview's aspect ratio (16:9 for most kinds, square for stickers and text animations). Unit: pixels.
Типово 256Діапазон 64 … 480

Повертає

{kind, id, name, animated, frames, columns, rows, tile_width, tile_height, width, height, phases[] (0..1 position of each tile in the preview loop), times_us[] (the same in microseconds), loop_us (length of the hover loop), preview? ({url, frames, fps, width, height} of the JPEG sprite), png_base64, note (what the tiles show for this kind)}.
