ШІ-асистент

У Kadr вбудовано ШІ-асистента. Напишіть, чого хочете, — «виріж тихі паузи», «додай жирні субтитри», «згенеруй кадр туманного лісу для проміжку на 0:08» — і він змонтує проєкт у вас на очах: прочитає таймлайн, виконає власні команди Kadr, перегляне результат і відповість. Кожну зміну можна скасувати, ризиковані кроки чекають на вашу згоду, а один натиск відкочує все, що зробив чат.

Як відкрити асистента

Натисніть AI на верхній панелі, ліворуч від Shortcuts та Export, або Ctrl+Shift+A. Чат виїжджає згори поверх редактора; Esc його закриває. Кнопка закріплення в заголовку прикріплює чат до правого краю редактора — тоді таймлайн і плеєр видно, поки асистент працює.

Що його «живить»

Асистенту потрібна ШІ-модель. Kadr уміє працювати з двома видами, і їх можна змінювати для кожного чату перемикачем під полем повідомлення.

Як налаштувати агента на цьому комп’ютері

  1. Відкрийте налаштування

    Відкрийте Settings → AI assistant. У блоці Agents on this computer Kadr показує всіх відомих агентів і їхній стан: Not installed (не встановлено), Installed (встановлено), Sign in (встановлено, але вхід не виконано), Chat only (може розмовляти, але не користуватися інструментами Kadr) або Ready (готовий). Кнопка оновлення шукає агентів заново.

  2. Встановіть

    Агента немає? Натисніть Install. Kadr запускає офіційну команду встановлення агента (npm, winget, pip або скрипт виробника) і показує її вивід наживо. Деяким агентам для npm потрібен Node.js — меню встановлення підказує, чого потребує кожен спосіб.

  3. Увійдіть

    Натисніть Sign in. Власний вхід агента відкриває сайт провайдера у браузері (або вікно терміналу для агентів, які входять там); Kadr сам помітить, коли ви закінчите. Хочете ключ? Відкрийте деталі агента й вставте його API-ключ (наприклад ANTHROPIC_API_KEY для Claude Code) — він зберігається зашифрованим і передається лише цьому агенту.

  4. Перевірте

    Test безкоштовно перевіряє, чи агента знайдено і чи виконано вхід. Друга кнопка перевірки проганяє через Kadr один крихітний справжній запит, щоб довести, що все працює від початку до кінця (це витрачає трохи вашого плану чи ключа).

Kadr ніколи не змінює власних налаштувань агента: кожен чат отримує окрему робочу папку, а інструменти Kadr підключаються лише на час цього запуску.

Як налаштувати API-провайдера

  1. У Settings → AI assistant → API providers натисніть Add API provider (або відкрийте вже доданого) і вставте API-ключ (кілька ключів працюють так само, як для голосів: по черзі, з перемиканням). Один ключ OpenAI чи Gemini слугує також для голосів і генерування відео.
  2. Виберіть Model. Kadr показує актуальні моделі з ціною за мільйон токенів; кнопка оновлення завантажує живий список провайдера (безкоштовний запит). Значок ока позначає моделі, що бачать зображення, значок мозку — моделі з міркуванням.
  3. Test безкоштовно перевіряє ключ; перевірка крихітним промптом надсилає «Reply with OK» (кілька токенів).
  4. Для Ollama чи LM Studio запустіть локальний сервер і завантажте модель, що підтримує інструменти; Kadr знайде його за звичною адресою (для сервера на іншому ПК змініть Base URL).

Угорі розділу оберіть, що асистент використовує типово (Assistant uses, Default model, Reasoning effort). Якщо нічого не обрано, Kadr бере Claude Code, коли він готовий, інакше — першого API-провайдера з ключем.

Чат

  • Напишіть запит і натисніть Enter (Shift+Enter — новий рядок). Порожній чат пропонує кілька прикладів для початку.
  • Прикріплюйте скріпкою: файли з ПК (фото, відео, документи), виділений кліп чи кліпи або поточний кадр. Також можна перетягнути файли з Провідника Windows, перетягнути кліпи з таймлайна чи Media в чат, клацнути кліп правою кнопкою й вибрати Ask AI about this clip і вставити зображення або текст.
  • Поки асистент працює, ви бачите, що він робить: кожну команду Kadr з аргументами й результатом (клацніть, щоб розгорнути) і мініатюри кадрів, які він переглянув. Відповіді відформатовані (списки, таблиці, код).
  • Stop одразу завершує поточний хід. Уже зроблені зміни лишаються — скасуйте їх або відкотіть чат.

Що йому можна без запитання

Кнопка поруч із вибором моделі задає режим дозволів чату:

РежимПоведінка
Ask on risky (типово)Зміни виконуються одразу (кожну можна скасувати). Питає перед платним генеруванням, видаленням файлів чи проєктів, перезаписом файлів і будь-чим поза Kadr.
Ask every actionКожна зміна чекає на ваше схвалення. Читання проєкту ніколи не питає.
Full autoНіколи не питає — крім платного генерування, яке завжди підтверджується й не виходить за денний ліміт витрат.

Коли потрібна ваша згода, у чаті з’являється картка схвалення з тим, що асистент хоче зробити (і ціною, якщо генерування платне): Approve (схвалити), Deny (відхилити, за бажання — з приміткою, що робити натомість) або Always for this chat (завжди в цьому чаті; не пропонується для платного генерування). Картки без відповіді відхиляються через 10 хвилин.

Allow actions outside Kadr (у тому самому меню, типово вимкнено) дозволяє агенту в цьому чаті користуватися власними інструментами оболонки, файлів і вебу — він однаково питає, якщо не обрано Full auto. Деяких агентів (Kimi Code, Warp) неможливо обмежити інструментами Kadr, тому вони запускаються лише з цим перемикачем. Типовий режим для нових чатів — у Settings → AI assistant → Permissions.

Асистент ніколи не бачить і не змінює ваших API-ключів, ліміту витрат та інших секретів — ці команди для нього заблоковано.

Скасувати весь чат

Перед першим повідомленням чату Kadr запам’ятовує проєкт. Revert session (стрілка скасування в заголовку чату) повертає проєкт точно в той стан — одним кроком скасування, тож Ctrl+Z поверне роботу асистента, якщо ви передумаєте. Якщо ви теж змінювали проєкт після початку чату, Kadr спершу попередить, бо ваші зміни також відкотяться. Окремі кроки завжди можна скасувати звичайним Ctrl+Z.

Історія чатів

Кожен проєкт має власні чати. Кнопка з годинником показує їх із назвою, моделлю, кількістю дій і вартістю; відкрийте чат, щоб продовжити, або почніть New chat. Чати зберігаються в папці проєкту, ніколи не потрапляють в експорт і видаляються разом із проєктом. У Settings → AI assistant → Chat history можна зберігати їх назавжди або видаляти чати, старші за 7, 30 чи 90 днів.

Вартість

  • API-провайдери беруть плату за токени. Kadr оцінює кожен запит за прайсом моделі й записує його в Settings → Spending; денний ліміт діє й для асистента.
  • Агенти на цьому комп’ютері використовують ваш план чи ключ; витрати показуються в чаті, якщо агент їх повідомляє.
  • Ollama й LM Studio працюють на вашому ПК і нічого не коштують.
  • Коли асистент генерує відео чи мовлення в платного провайдера, він завжди показує ціну й чекає на ваше схвалення.

Приватність

Ваші повідомлення, вкладення, опис проєкту й кадри, які переглядає асистент, надсилаються обраному ШІ-провайдеру (або лишаються на ПК з локальною моделлю). Ключі зберігаються в зашифрованому сховищі Kadr. Асистент редагує лише командами Kadr — тими самими, що й кнопки, — тож усе, що він робить, видно в історії скасування.

Розширені налаштування

  • Steps per message, Output tokens, History budget і Tool result size обмежують, скільки може тривати хід і скільки читає модель; старіші частини довгого чату підсумовуються автоматично.
  • Custom provider (в Add API provider) — додайте будь-який OpenAI-сумісний сервер (vLLM, llama.cpp server, LiteLLM, корпоративний проксі) або точку доступу у форматі Anthropic, OpenAI Responses чи Gemini.
  • Executable (у деталях агента) — вкажіть Kadr агента, встановленого в незвичній папці.
