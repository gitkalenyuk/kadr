Голоси: хмарне й локальне озвучення тексту

Озвучення тексту в Kadr одразу працює офлайн — голосами вашого комп’ютера. Якщо хочеться природніших голосів, можна підключити майже будь-який сервіс мовлення — ElevenLabs, OpenAI, Azure, Google та ще 35 — або сервер мовлення на власному ПК. Kadr зберігає ключі зашифрованими, перемикається на наступний ключ, коли попередній вичерпано, і показує ціну, перш ніж платний голос заговорить.

Для закадрового голосу все це не обов’язкове: голоси Windows та eSpeak NG безкоштовні й нічого не надсилають в інтернет. Як додати озвучення до відео, описано в розділі Аудіо → Озвучення тексту; ця сторінка — про те, звідки беруться голоси.

Як додати провайдера

  1. Відкрийте налаштування голосів

    Відкрийте Settings → Voices (на головному екрані — Settings, у редакторі — Menu → Settings…). Угорі — вбудовані рушії з кількістю голосів; нижче, у блоці Cloud & self-hosted providers, — провайдери, якими ви користуєтеся.

  2. Оберіть провайдера

    Натисніть Add a provider. Галерея показує всі підтримувані сервіси з орієнтовною ціною; шукайте за назвою або фільтруйте за категорією. На кожній картці видно, чи провайдера звірено з офіційною документацією, чи він experimental (експериментальний).

  3. Вставте API-ключ

    Отримайте ключ на сайті провайдера (на кожній картці є посилання на сторінку ключів) і вставте його. Kadr одразу його шифрує. Власним серверам і Edge ключ не потрібен — їх достатньо ввімкнути.

  4. Перевірте

    Натисніть Test. Це безкоштовна перевірка — вона читає список голосів або дані облікового запису й ніколи не замовляє платне озвучення — і показує, чи працює ключ, скільки голосів він відкрив і, якщо сервіс це повідомляє, скільки квоти лишилося (наприклад символів ElevenLabs).

  5. Оберіть модель і голос

    Виберіть Default model (для ElevenLabs, наприклад, eleven_multilingual_v2, eleven_v3 або швидку модель Flash) і Default voice. Деяким сервісам потрібне ще одне налаштування, наприклад Region для Azure чи Amazon Polly. Base URL дає змогу спрямувати провайдера через проксі або на сервер на іншому ПК. Увімкніть Default, якщо Kadr має брати цього провайдера, коли ви нічого не обрали.

Тепер голоси кожного готового провайдера з’являються в Audio → Text to speech і в інспекторі на вкладці Text → Speech, згруповані за провайдерами. Якщо голосів нового провайдера ще не видно, натисніть стрілку оновлення поруч із Voice.

Кілька ключів для одного провайдера

Для кожного провайдера можна зберегти скільки завгодно ключів — скажімо, десять облікових записів ElevenLabs. Kadr використовує їх по черзі: коли ключ відхилено, на ньому скінчилися кредити або спрацювало обмеження частоти запитів, автоматично береться наступний, а проблемний позначається.

  • Add key — один ключ із необов’язковою міткою («Основний», «Запасний»).
  • Paste many — по ключу в рядку. Рядки на кшталт Main: sk_… задають мітку; порожні рядки, # коментарі і дублікати пропускаються.
  • Import file… — файл .txt, .env, .csv або .json з одним ключем на рядок чи запис.

Список API keys показує кожен ключ замаскованим (sk_…a1b2) і з його станом:

СтанЩо означаєЩо робить Kadr
OKОстанній запит із цим ключем пройшовВикористовує його
ExhaustedСкінчилися квота або кредитиПропускає, доки квота не оновиться (або годину), потім пробує знову
Rate-limitedЗабагато запитів просто заразЧекає стільки, скільки просить сервіс, а тим часом бере наступний ключ
InvalidСервіс відхилив ключПропускає, доки ви не перевірите його знову або не скинете помилку
Not testedЩе не використовувавсяПробує, коли настане його черга
DisabledВи вимкнули ключ (кнопка з оком)Зберігає, але не використовує

Стрілки змінюють порядок, олівець перейменовує ключ, кругла стрілка скидає помилку, око вимикає ключ без видалення, кнопка оновлення безкоштовно перевіряє один ключ, індикатор заново читає залишок квоти, а кошик видаляє ключ. Після збереження ключі більше ніколи не показуються — навіть вам.

Ціни й підтвердження

Платні сервіси беруть гроші за символи (або за секунди звуку). Kadr знає опубліковані ціни кожного сервісу з датою («≈ $0.08 за 1000 символів, ціни станом на 2026-10-07») і оцінює кожне озвучення, перш ніж його створити. Передплати на кшталт ElevenLabs списуються з квоти символів вашого плану — список ключів показує, скільки лишилося.

  • Kadr питає перед платним озвученням. Ви бачите орієнтовну ціну й підтверджуєте. Щоб не питати про дрібні суми, задайте для провайдера Ask before paying — суму, наприклад 0.05: озвучення, дешевше за неї, створюється без запитання.
  • Повторно той самий текст — безкоштовно. Озвучення, яке ви вже створили в проєкті (той самий текст, голос і швидкість), береться з кешу.
  • Денний ліміт витрат. У Settings → Spending можна задати, скільки Kadr може витратити за день на всі платні ШІ-сервіси разом або на окремого провайдера. Запит, що перевищив би ліміт, відхиляється, і гроші не витрачаються. Див. Spending.
  • Невдале озвучення повертається. Коли провайдер повідомляє, що не зміг створити озвучення, його орієнтовна ціна повертається в історії витрат Kadr і не враховується в ліміті.

Ціни — це оцінки за публічними прайсами провайдерів. Реальний рахунок виставляє провайдер, і він може відрізнятися (знижки, плани, податки, зміни цін).

Власний сервер мовлення або інший сервіс

Якщо вашого сервісу немає в галереї, оберіть Custom provider в Add a provider. Три режими:

  • OpenAI-compatible — найпростіший. Для будь-якого сервера, що розуміє запит мовлення OpenAI (Kokoro-FastAPI, LocalAI, vLLM, корпоративний проксі…): введіть його Base URL, назви моделі й голосів і ключ, якщо він потрібен. Позначте, що сервер працює на цьому ПК або у вашій мережі, — тоді Kadr не питатиме про ціну.
  • HTTP template — для будь-якого іншого веб-API. Вкажіть метод, URL і заголовки та напишіть JSON-тіло із заповнювачами {text}, {voice}, {model}, {speed} і {lang}. Потім скажіть, де у відповіді звук: сирі байти аудіо, поле base64 (JSON-шлях на кшталт data.audio), URL для завантаження або завдання, яке треба опитувати до завершення (шлях до id завдання, URL опитування з {job_id}, шлях до статусу зі значеннями «готово» й «помилка», шлях до результату).
  • Копія вбудованого провайдера, у якій ви змінюєте потрібне, наприклад адресу.

Натисніть Test, щоб перевірити. Власні провайдери зберігаються в папці даних Kadr; їхні ключі потрапляють у зашифроване сховище, як і всі інші.

Приватність і безпека

  • З хмарним голосом текст, який ви озвучуєте, надсилається цьому сервісу. Вбудовані голоси ніколи не залишають ваш комп’ютер; власний сервер отримує текст лише сам.
  • Ключі шифрує Windows для вашого облікового запису (на Mac — зберігаються в Keychain). Вони ніколи не потрапляють у проєкти, експорт, журнали чи повідомлення, і ШІ-асистенти не можуть їх прочитати.
  • Переїжджаєте на інший комп’ютер? Settings → Spending → Keys & secrets → Export записує всі ключі в один файл під паролем; Import читає його на іншому ПК. Див. Ключі й секрети.
  • Ключ ElevenLabs, збережений у Kadr 1.0, автоматично переноситься в зашифроване сховище під час першого запуску цієї версії.

Сервіси, яких немає

PlayHT і LMNT закрили свої API, а Neets.ai не вдалося надійно перевірити, тому їх немає у списку. Hume Octave є, але позначений як експериментальний: Hume планує закрити цей API в листопаді 2026 року.
