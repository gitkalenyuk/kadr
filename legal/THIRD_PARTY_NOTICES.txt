1. FFMPEG
---------
FFmpeg is NOT included in this distribution of Kadr.

Kadr uses FFmpeg (https://ffmpeg.org) for media decoding and encoding.
It runs ffmpeg.exe and ffprobe.exe as separate programs; Kadr does not
link to FFmpeg code. On first run, Kadr offers to download an official
GPL build of FFmpeg published by the BtbN/FFmpeg-Builds project on GitHub
(https://github.com/BtbN/FFmpeg-Builds) into
%LOCALAPPDATA%\Kadr\tools\ffmpeg. You can decline and instead install
FFmpeg yourself (put it on PATH, or set KADR_FFMPEG to the full path of
ffmpeg.exe).

The downloaded FFmpeg is distributed by its own authors under its own
licence (the "gpl" builds are licensed under the GNU General Public
License version 3 or later). It is not part of Kadr and is not covered by
the Kadr EULA. The Kadr uninstaller deletes it only if you ask it to.

  FFmpeg licence and legal information:  https://ffmpeg.org/legal.html
  FFmpeg source code:                    https://ffmpeg.org/download.html
                                         (git: https://git.ffmpeg.org/ffmpeg.git)
  Build scripts and the exact source of each build (every BtbN release
  names the FFmpeg commit and library versions it was built from):
                                         https://github.com/BtbN/FFmpeg-Builds
                                         https://github.com/BtbN/FFmpeg-Builds/releases

6. WGPU-NATIVE (GPU RENDERING)
------------------------------
This distribution of Kadr includes the wgpu-native library:
wgpu_native.dll, next to Kadr.exe.
It is an unmodified binary of wgpu-native, the native WebGPU
implementation of the wgpu project (https://github.com/gfx-rs/wgpu-native,
https://wgpu.rs). Kadr loads it at run time to render on the graphics
card (Vulkan, Direct3D 12).

    wgpu-native v29.0.1.1
    Source:
    https://github.com/gfx-rs/wgpu-native/releases/tag/v29.0.1.1
    (commit 6aed50955d934ac36049ba8d002034841633ae02)

wgpu-native is dual-licensed under the MIT licence or the Apache License
2.0, at your option. Its licence texts are reproduced below and are in

MICROSOFT VISUAL C++ RUNTIME (WINDOWS)
The Windows build of wgpu-native needs the Microsoft Visual C++ runtime
library vcruntime140.dll. So that GPU rendering also works on PCs without
the "Microsoft Visual C++ Redistributable", Kadr ships it next to
wgpu_native.dll:

    Microsoft Visual C++ Runtime 14.50.35719.0 (vcruntime140.dll, x64)
    Source: Visual Studio 2026 (18) Community,
    VC\Redist\MSVC\14.50.35710\x64\Microsoft.VC145.CRT\vcruntime140.dll
    (unmodified, Authenticode-signed by Microsoft)
