Переклад і повторне «вшивання» субтитрів

Результат — ваше відео з субтитрами іншою мовою: копія проєкту з вшитими перекладеними субтитрами плюс файли .srt обома мовами для YouTube чи плеєра. Перекладає Claude; Kadr тримає кожну репліку на її початковому таймінгу. Тут перекладаємо англійські субтитри українською — можна просити будь-яку мову, яку знає Claude.

  • Час: ~2 хв
  • Що потрібно: Проєкт Kadr із субтитрами (наприклад, з рецепта про «говорющу голову»)
  • Основні команди: captions.list, project.duplicate, captions.update, captions.set_style, captions.export, captions.import, export.start

Попросіть Claude

У моєму проєкті Kadr «Tips short» є англійські субтитри. Зроби українську версію: дублюй проєкт як «Tips short (UK)», переклади кожну репліку природною розмовною українською (кожна приблизно такої ж довжини, як оригінал, щоб таймінг лишився робочим) і запиши переклади в копію одним пакетом. Перемкни субтитри копії на стиль cap_yellow_outline. Експортуй обидві доріжки субтитрів у файли SRT поруч із відео, перевір один кадр, що кирилиця відображається правильно, і експортуй українську версію в 1080p у C:\Users\you\Videos\Kadr\tips-short-uk.mp4.

Крок за кроком

Кожен крок показує ті самі виклики двічі. Вкладка kadrctl — для PowerShell: рядок, що починається з kadrctl --%, передає JSON, а без --% той самий рядок працює і в командному рядку (cmd). Вкладка MCP — це виклик інструмента, який надсилає агент: назва інструмента та його аргументи. Ідентифікатори на кшталт prj_…, mat_… і seg_… беруться з результатів попередніх кроків, тож у вас вони будуть інші. Шляхи в C:/Users/you — лише приклад.

  1. Прочитайте субтитри

    captions.list повертає кожну репліку з ідентифікатором, часом і текстом. include_words false прибирає таймінг окремих слів, щоб відповідь була компактною.

  2. Працюйте з копією

    project.duplicate копіює проєкт з тими самими ідентифікаторами реплік, тож список із кроку 1 і далі чинний. Оригінал не змінюється.

    kadrctl run project.duplicate --project_id prj_ed95831b1bf0 --name "Tips short (UK)"
    {"name": "project_duplicate", "arguments": {"project_id": "prj_ed95831b1bf0", "name": "Tips short (UK)"}}

  4. Дайте новій версії власний вигляд

    captions.set_style змінює вигляд усіх реплік, зберігаючи текст і таймінг.

    kadrctl run captions.set_style --project_id prj_0ae446772d4b --style_id cap_yellow_outline
    {"name": "captions_set_style", "arguments": {"project_id": "prj_0ae446772d4b", "style_id": "cap_yellow_outline"}}

  5. Експортуйте файли субтитрів

    captions.export записує SRT, VTT, TXT або LRC; відсутні папки створюються. Без path текст повертається в полі content.

    kadrctl run captions.export --project_id prj_0ae446772d4b --format srt --path C:/Users/you/Videos/Kadr/tips-short-uk.srt
kadrctl run captions.export --project_id prj_ed95831b1bf0 --format srt --path C:/Users/you/Videos/Kadr/tips-short-en.srt

{"name": "captions_export", "arguments": {"project_id": "prj_ed95831b1bf0", "format": "srt", "path": "C:/Users/you/Videos/Kadr/tips-short-en.srt"}}

  6. Перевірте символи й експортуйте

    Для символів, яких немає в шрифті субтитрів, Kadr бере системний шрифт, тож діакритика, кирилиця й ієрогліфи відображаються. Один кадр це підтвердить:

    kadrctl run preview.frame --project_id prj_0ae446772d4b --time_us 2s --width 540
kadrctl run export.start --project_id prj_0ae446772d4b --resolution 1080p --path C:/Users/you/Videos/Kadr/tips-short-uk.mp4

  7. За бажанням: обидві мови в кадрі

    Імпортуйте перекладений SRT в оригінальний проєкт як другу доріжку субтитрів іншим стилем. replace false лишає англійську доріжку й додає нову.

    kadrctl run captions.import --project_id prj_ed95831b1bf0 --path C:/Users/you/Videos/Kadr/tips-short-uk.srt --style_id cap_box_dark --replace false
    {"name": "captions_import", "arguments": {"project_id": "prj_ed95831b1bf0", "path": "C:/Users/you/Videos/Kadr/tips-short-uk.srt", "style_id": "cap_box_dark", "replace": false}}

Інші ідеї

  • Лише субтитри. Пропустіть експорт із вшитими субтитрами й завантажте файли SRT; YouTube покаже їх як субтитри, що вмикаються окремо.
  • Переділити довгі переклади. Якщо рядки перекладу задовгі, запустіть на копії captions.relayout з max_words 3 або max_chars 24. Репліки перегрупуються за таймінгом слів.
  • Текст із субтитрів. captions.export з format txt і без path повертає чистий текст — попросіть Claude перетворити його на допис чи опис відео.
  • Субтитрів ще немає? Спершу запустіть captions.auto; Whisper розпізнає близько 100 мов.

Поради

  • Просіть Claude робити кожну перекладену репліку приблизно такої ж довжини, як оригінал: субтитри, яким раптом потрібно три рядки, важко читати.
  • captions.shift зсуває всі репліки раніше чи пізніше, якщо субтитри відстають на кілька кадрів.
  • Кілька мов: повторіть кроки 2–6 для кожної; копії незалежні.
