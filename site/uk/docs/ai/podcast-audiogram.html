Аудіограма з уривка подкасту

Результат — відео 1080×1080 для соцмереж з аудіоуривка подкасту: плавне градієнтне тло, яке генерує сам Kadr, караоке-субтитри, що заповнюються слово за словом, іконка-нота, що пульсує раз на секунду, м’які вогники боке і плашка з назвою епізоду.

  • Час: ~2 хв
  • Що потрібно: Аудіоуривок подкасту (WAV або MP3)
  • Основні команди: media.generate, timeline.segment.add, timeline.segment.trim, segment.set_audio, captions.auto, sticker.add, animation.set, effect.add, text.add, preview.layout, export.start

Попросіть Claude

Зроби в Kadr квадратну аудіограму 1:1 з C:\Users\you\Podcast\ep12-clip.wav. Згенеруй тло aurora_flow на всю довжину аудіо, поклади аудіо зверху й нормалізуй гучність. Додай англійські субтитри стилем cap_karaoke_bar. Постав стікер music_note зверху посередині приблизно на 22% розміру з циклічною анімацією «серцебиття» раз на секунду, додай ефект bokeh_drift поверх усього, а вгорі — плашку «Night Shift | Ep. 12» шаблоном name_tag_podcast. Перевір через preview_layout, що ніщо не перекривається, покажи кадр на 5-й секунді, потім експортуй 1080p.

Крок за кроком

Кожен крок показує ті самі виклики двічі. Вкладка kadrctl — для PowerShell: рядок, що починається з kadrctl --%, передає JSON, а без --% той самий рядок працює і в командному рядку (cmd). Вкладка MCP — це виклик інструмента, який надсилає агент: назва інструмента та його аргументи. Ідентифікатори на кшталт prj_…, mat_… і seg_… беруться з результатів попередніх кроків, тож у вас вони будуть інші. Шляхи в C:/Users/you — лише приклад.

  1. Створіть квадратний проєкт та імпортуйте аудіо

    kadrctl run project.create --name "Night Shift ep 12 - clip" --ratio 1:1
kadrctl --% run media.import --project_id prj_0bcf441b42a1 --paths "[\"C:/Users/you/Podcast/ep12-clip.wav\"]"
    {"name": "project_create", "arguments": {"name": "Night Shift ep 12 - clip", "ratio": "1:1"}}
{"name": "media_import", "arguments": {"project_id": "prj_0bcf441b42a1", "paths": ["C:/Users/you/Podcast/ep12-clip.wav"]}}

    duration_us матеріалу — 20855782 (20,9 с); наступні кроки підганяють усе під цю довжину.

  2. Згенеруйте рухоме тло

    media.generate рендерить тло на вашому ПК — без стокових відео, нічого не завантажується. aurora_flow — плавний градієнт у розмірі полотна (1080×1080). add_to_timeline кладе його на основну доріжку в тому самому кроці скасування. Рухоме тло може тривати до 60 с.

    kadrctl run media.generate --project_id prj_0bcf441b42a1 --preset_id aurora_flow --duration_us 21s --add_to_timeline --at_us 0
    {"name": "media_generate", "arguments": {"project_id": "prj_0bcf441b42a1", "preset_id": "aurora_flow", "duration_us": 21000000, "add_to_timeline": true, "at_us": 0}}

  3. Додайте аудіо й вирівняйте довжини

    Аудіо лягає на аудіодоріжку з 0 с. Тло обрізається рівно там, де закінчується аудіо (snap false — для точного краю), а голос нормалізується.

    kadrctl run timeline.segment.add --project_id prj_0bcf441b42a1 --material_id mat_53712ca92932 --at_us 0
kadrctl run timeline.segment.trim --project_id prj_0bcf441b42a1 --segment_id seg_6e315408791c --edge right --to_us 20855782 --snap false
kadrctl run segment.set_audio --project_id prj_0bcf441b42a1 --segment_id seg_283eb97dc326 --normalize_loudness
    {"name": "timeline_segment_add", "arguments": {"project_id": "prj_0bcf441b42a1", "material_id": "mat_53712ca92932", "at_us": 0}}
{"name": "timeline_segment_trim", "arguments": {"project_id": "prj_0bcf441b42a1", "segment_id": "seg_6e315408791c", "edge": "right", "to_us": 20855782, "snap": false}}
{"name": "segment_set_audio", "arguments": {"project_id": "prj_0bcf441b42a1", "segment_id": "seg_283eb97dc326", "normalize_loudness": true}}

  4. Караоке-субтитри

    captions.auto локально розпізнає голос. cap_karaoke_bar заповнює кожне слово зліва направо в момент вимови.

    kadrctl run captions.auto --project_id prj_0bcf441b42a1 --language en --style_id cap_karaoke_bar --wait
    {"name": "captions_auto", "arguments": {"project_id": "prj_0bcf441b42a1", "language": "en", "style_id": "cap_karaoke_bar", "wait": true}}

  5. Додайте рух: пульсуючу іконку й вогники

    sticker.add ставить вбудований стікер на весь кліп. segment.set_transform піднімає його (−0.35 по осі y; від’ємне — вгору) і зменшує. Циклічна анімація через animation.set повторюється весь кліп — тут один удар серця на секунду. effect.add накладає bokeh_drift на все, що під ним.

    kadrctl run sticker.add --project_id prj_0bcf441b42a1 --sticker_id music_note --at_us 0 --duration_us 20855782
kadrctl run segment.set_transform --project_id prj_0bcf441b42a1 --segment_id seg_6a38981dcbc1 --x 0 --y -0.35 --scale 0.22
kadrctl run animation.set --project_id prj_0bcf441b42a1 --segment_id seg_6a38981dcbc1 --kind loop --id loop_heartbeat --duration_us 1s
kadrctl run effect.add --project_id prj_0bcf441b42a1 --effect_id bokeh_drift --at_us 0 --duration_us 20855782
    {"name": "sticker_add", "arguments": {"project_id": "prj_0bcf441b42a1", "sticker_id": "music_note", "at_us": 0, "duration_us": 20855782}}
{"name": "segment_set_transform", "arguments": {"project_id": "prj_0bcf441b42a1", "segment_id": "seg_6a38981dcbc1", "x": 0, "y": -0.35, "scale": 0.22}}
{"name": "animation_set", "arguments": {"project_id": "prj_0bcf441b42a1", "segment_id": "seg_6a38981dcbc1", "kind": "loop", "id": "loop_heartbeat", "duration_us": 1000000}}
{"name": "effect_add", "arguments": {"project_id": "prj_0bcf441b42a1", "effect_id": "bokeh_drift", "at_us": 0, "duration_us": 20855782}}

    Kadr не малює хвильову форму, що реагує на звук. Пульсуюча циклічна анімація іконки дає знайомий рух аудіограми; щоб пульс збігався з ритмом, задайте duration_us циклу рівним одній долі.

  6. Плашка з назвою шоу

    kadrctl run text.add --project_id prj_0bcf441b42a1 --text "Night Shift | Ep. 12" --template_id name_tag_podcast --at_us 0 --duration_us 20855782
kadrctl run segment.set_transform --project_id prj_0bcf441b42a1 --segment_id seg_bb9e0f0b8692 --y -0.75
    {"name": "text_add", "arguments": {"project_id": "prj_0bcf441b42a1", "text": "Night Shift | Ep. 12", "template_id": "name_tag_podcast", "at_us": 0, "duration_us": 20855782}}
{"name": "segment_set_transform", "arguments": {"project_id": "prj_0bcf441b42a1", "segment_id": "seg_bb9e0f0b8692", "y": -0.75}}

  7. Перевірте компонування

    preview.layout повертає рамку кожного видимого кліпу й тексту в пікселях полотна, тож агент може переконатися, що ніщо не перекривається й не обрізане. На 5-й секунді:

    kadrctl run preview.layout --project_id prj_0bcf441b42a1 --time_us 5s
    {"name": "preview_layout", "arguments": {"project_id": "prj_0bcf441b42a1", "time_us": 5000000}}
    type     x    y    w     h
video    0    0    1080  1080   background
text     351  105  379   61     name tag
sticker  420  231  239   239    music note
text     213  815  654   98     caption
    kadrctl run preview.frame --project_id prj_0bcf441b42a1 --time_us 5s --width 540
    {"name": "preview_frame", "arguments": {"project_id": "prj_0bcf441b42a1", "time_us": 5000000, "width": 540}}

  8. Експорт

    На полотні 1:1 «1080p» означає 1080×1080.

    kadrctl run export.start --project_id prj_0bcf441b42a1 --resolution 1080p --path C:/Users/you/Videos/Kadr/night-shift-ep12.mp4
    {"name": "export_start", "arguments": {"project_id": "prj_0bcf441b42a1", "resolution": "1080p", "path": "C:/Users/you/Videos/Kadr/night-shift-ep12.mp4"}}

Варіації

  • По одному слову. captions.set_style з cap_pop_word переділяє репліки на окремі слова, що «вистрибують».
  • Довші уривки. Рухоме тло обмежене 60 с. Для довших уривків візьміть статичний пресет на кшталт midnight_glow чи ocean_gradient: з add_to_timeline його duration_us задає довжину кліпу довільно.
  • Вертикальна аудіограма. Створіть проєкт 9:16 і рознесіть іконку та плашку далі одна від одної.
  • Фото гостя. Імпортуйте портрет, додайте через timeline.segment.add з new_track і зробіть круглим через segment.set_mask (type circle).

Поради

  • Згенероване тло кешується: той самий пресет, розмір і довжина використовуються повторно миттєво.
  • Якщо ім’я гостя розпізнається з помилками, передайте його в captions.auto як prompt.
  • Щоб отримати лише звукову доріжку уривка, викличте export.start з audio_only.
