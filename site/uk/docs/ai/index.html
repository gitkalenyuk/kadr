Для ШІ-агентів

Kadr для ШІ-агентів

Kadr — це десктопний відеоредактор у стилі CapCut, у якому кожна кнопка, повзунок і пункт меню — задокументована команда. ШІ-агент виконує ті самі 180+ команд через MCP, локальний REST API або CLI kadrctl, а людина бачить кожну правку наживо у вікні редактора, зі спільною історією скасування.

Швидкий старт: Claude CodeОдна команда — і Kadr під’єднано; перші запити, які варто спробувати. Claude DesktopФрагмент конфігурації на чотири рядки. РецептиОдинадцять наскрізних сценаріїв, кожен виклик перевірено на справжньому рушії. Довідник командКожна команда з параметрами, одиницями, типовими значеннями й прикладами.

Три способи під’єднатися

Усі три ведуть до того самого рушія — відкритого редактора (Kadr.exe) або «безголового» kadr-server.exe — за адресою http://127.0.0.1:7777 і виконують ті самі команди.

ІнтерфейсДля чого найкращеЯк називаються команди
MCP (kadr-mcp.exe)Claude Code, Claude Desktop та інші застосунки з агентами. Сам запускає рушій, якщо Kadr не відкритий; повертає кадри як зображення.Крапки стають підкресленнями: timeline_segment_split; плюс kadr_batch
RESTВласні скрипти й сервіси будь-якою мовою; події через WebSocket.POST /api/v1/commands/timeline.segment.split
CLI (kadrctl.exe)Термінали, скрипти оболонки, швидкі перевірки; розуміє час на кшталт 2.5s.kadrctl run timeline.segment.split --at_us 2.5s …

Модель редактора

project          prj_…   полотно, налаштування, курсор
├─ materials[]   mat_…   імпортовані чи згенеровані файли (у фото тривалість 0)
├─ tracks[]      trk_…   tracks[0] малюється першою, найнижче
│  ├─ main_video         магнітна: кліпи впритул, без проміжків
│  ├─ video_overlay · text · sticker · effect · filter · adjustment
│  └─ audio
│     └─ segments[]  seg_…  діапазон на таймлайні + діапазон у матеріалі
└─ markers[]     mrk_…
  • Час — ціле число мікросекунд усюди: 1 с = 1000000. Параметри з часом закінчуються на _us.
  • Ідентифікатори — непрозорі рядки з префіксом типу (prj_, trk_, seg_, mat_, exp_…). Беріть їх із результатів; ніколи не вигадуйте.
  • Команди бувають проєктні (приймають project_id, зберігаються й скасовуються) або глобальні (список проєктів, бібліотека, завдання експорту, налаштування).
  • Кожну правку можна скасувати через edit.undo; пакет правок — один крок скасування; правки з інтерфейсу й від агентів мають спільну історію.

Усі правила — магніт, зв’язані кліпи, переходи, ключові кадри, координати, одиниці — у розділі Концепції. Як знаходити, переглядати й застосовувати елементи бібліотеки та шрифти — на сторінці Бібліотека, прев’ю й шрифти.

Перші п’ять викликів

Повний монтаж: створити вертикальний проєкт, згенерувати тло, додати титр, подивитися, експортувати. Кожна вкладка показує ті самі виклики; вкладка MCP — це те, що надсилає агент.

{"name": "project_create", "arguments": {"name": "Моє перше відео", "ratio": "9:16"}}
{"name": "media_generate", "arguments": {"project_id": "prj_74f3bf737c17", "preset_id": "sunset_gradient", "duration_us": 5000000, "add_to_timeline": true}}
{"name": "text_add", "arguments": {"project_id": "prj_74f3bf737c17", "text": "Привіт від агента", "template_id": "title_bold", "at_us": 0, "duration_us": 3000000}}
{"name": "preview_frame", "arguments": {"project_id": "prj_74f3bf737c17", "time_us": 1000000, "width": 540}}
{"name": "export_start", "arguments": {"project_id": "prj_74f3bf737c17", "resolution": "1080p"}}
kadrctl run project.create --name "Моє перше відео" --ratio 9:16
kadrctl run media.generate --project_id prj_74f3bf737c17 --preset_id sunset_gradient --duration_us 5s --add_to_timeline
kadrctl run text.add --project_id prj_74f3bf737c17 --text "Привіт від агента" --template_id title_bold --at_us 0 --duration_us 3s
kadrctl run preview.frame --project_id prj_74f3bf737c17 --time_us 1s --width 540
kadrctl run export.start --project_id prj_74f3bf737c17 --resolution 1080p
curl -s http://127.0.0.1:7777/api/v1/commands/project.create -H "Authorization: Bearer $KADR_TOKEN" -d '{"name":"Моє перше відео","ratio":"9:16"}'
curl -s http://127.0.0.1:7777/api/v1/commands/media.generate -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","preset_id":"sunset_gradient","duration_us":5000000,"add_to_timeline":true}'
curl -s http://127.0.0.1:7777/api/v1/commands/text.add -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","text":"Привіт від агента","template_id":"title_bold","at_us":0,"duration_us":3000000}'
curl -s http://127.0.0.1:7777/api/v1/commands/preview.frame -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","time_us":1000000,"width":540}'
curl -s http://127.0.0.1:7777/api/v1/commands/export.start -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","resolution":"1080p"}'

Експорт іде у фоні; export.status з отриманим job_id показує прогрес, доки state не стане done. Без path відео зберігаються в %USERPROFILE%\Videos\Kadr.

Безпека і приватність

  • Лише локально. API слухає на 127.0.0.1; запити, адресовані будь-якому іншому імені хоста, отримують 403 forbidden (захист від DNS rebinding), а браузери можуть під’єднуватися лише з локальних origin.
  • Токен. Кожен запит, крім перевірки стану й документації, потребує токена з %APPDATA%\Kadr\api-token. kadr-mcp і kadrctl читають його самі. Бережіть його, як пароль: він дає повний контроль над вашими проєктами.
  • Усе можна скасувати — крім видалення цілого проєкту, яке MCP позначає як руйнівне, тож клієнти перепитують. Імпортовані медіафайли ніколи не змінюються й не видаляються.
  • Kadr нічого не вивантажує. Команди читають і записують файли на вашому ПК за шляхами, які ви вказуєте. Мережевий трафік — лише необов’язковий: голоси ElevenLabs (текст, який ви синтезуєте), перевірка оновлень, одноразове завантаження FFmpeg і файли шрифтів із репозиторію google/fonts, коли виконується font.install. Кадри й дані потрапляють до вашого ШІ-провайдера лише тоді, коли агент просить їх через інструменти, які ви дозволили.
