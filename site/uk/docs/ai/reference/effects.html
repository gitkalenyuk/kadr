Ефекти: команди

5 команд у категорії «Ефекти». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • effect.addAdd effect
  • effect.applyApply effect to clip
  • effect.get_paramsEffect parameters
  • effect.removeRemove effect
  • effect.set_paramsAdjust effect

effect.add

Add effect

СкасовуєтьсяLibrary › EffectsMCP effect_add

Adds a video effect as its own segment on an effect track, like clicking an effect card in the Effects tab. An effect-track segment applies to everything drawn below it (all lower tracks) for its time range. Placed at at_us (default: playhead) for duration_us (default 3 s) on the first free effect track or a new effect track above all visual tracks. Animated effects (shake, glitch, zoom pulse...) run from the segment start. To put an effect on one clip only use effect.apply instead.

Параметри

ПараметрТипОпис
effect_idобов’язковийstringEffect id from library.list kind=effect, e.g. "vhs", "shake", "sparkle".
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
at_usintegerTimeline time where the new segment starts (1 second = 1000000). Defaults to the playhead position. Unit: microseconds.
Діапазон 0 … ∞
duration_usintegerLength of the new effect segment on the timeline. CapCut's default is 3 seconds (3000000). Unit: microseconds.
Типово 3000000Діапазон 100000 … 86400000000
paramsobjectOptional named effect parameters, e.g. {"intensity": 0.8, "speed": 1.5, "levels": 4}. Every effect accepts intensity (0..1) and speed (0.1..10); the effect's own sliders are listed in library.get {kind: "effect"} → params.schema ([{id, label, min, max, default, step?, unit?}]). Values are clamped to their range; unknown names are rejected.
track_idstringPut the segment on this existing track. Omit to use the first free track of the right type, or a new track created above all visual tracks.

Повертає

{segment_id, track_id, segment} — segment.effect holds {id, params}.

Приклади

VHS look at the playhead

curl -X POST http://127.0.0.1:7777/api/v1/commands/effect.add \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"effect_id":"vhs","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run effect.add --effect_id vhs --project_id prj_1a2b3c4d5e6f
// MCP tool: effect_add
{
  "effect_id": "vhs",
  "project_id": "prj_1a2b3c4d5e6f"
}

Strong shake for 1.5 s at 10 s

curl -X POST http://127.0.0.1:7777/api/v1/commands/effect.add \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"at_us":10000000,"duration_us":1500000,"effect_id":"shake","params":{"intensity":0.9},"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run effect.add --at_us 10s --duration_us 1.5s --effect_id shake --params '{"intensity":0.9}' --project_id prj_1a2b3c4d5e6f
// MCP tool: effect_add
{
  "at_us": 10000000,
  "duration_us": 1500000,
  "effect_id": "shake",
  "params": {
    "intensity": 0.9
  },
  "project_id": "prj_1a2b3c4d5e6f"
}

effect.apply

Apply effect to clip

СкасовуєтьсяLibrary › Effects › Drag onto clipMCP effect_apply

Applies a video effect directly to one clip (video, photo or sticker segment), like dragging an effect card onto a clip. The effect lasts as long as the clip; applying an effect the clip already has just updates its parameters. When segment_id is an effect-track segment its effect is replaced instead. Text, audio, filter and adjustment segments cannot carry video effects.

Параметри

ПараметрТипОпис
effect_idобов’язковийstringEffect id from library.list kind=effect.
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
paramsobjectOptional named effect parameters, e.g. {"intensity": 0.8, "speed": 1.5, "levels": 4}. Every effect accepts intensity (0..1) and speed (0.1..10); the effect's own sliders are listed in library.get {kind: "effect"} → params.schema ([{id, label, min, max, default, step?, unit?}]). Values are clamped to their range; unknown names are rejected.

Повертає

The updated segment (effects[] for clips, effect for effect-track segments).

Приклади

Glitch a clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/effect.apply \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"effect_id":"glitch","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run effect.apply --effect_id glitch --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: effect_apply
{
  "effect_id": "glitch",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

effect.get_params

Effect parameters

Без кроку скасуванняInspector › EffectMCP effect_get_params

Reads the current parameters of an effect in use together with its slider schema — what the Effect inspector shows. Target: the effect of an effect-track segment, or one of a clip's applied effects (effect_id selects which; optional when the clip has exactly one). params contains every schema parameter (defaults filled in for values never set); schema is [{id, label, min, max, default, step?, unit?}] in display order (intensity first, then speed for animated effects, then the effect's own sliders). Change values with effect.set_params.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
effect_idstringWhich applied effect to read (needed when a clip has several).

Повертає

{segment_id, effect_id, name, params: {id: value}, schema: [{id, label, min, max, default, step?, unit?}]}.

Приклади

Read the sliders of an effect segment

curl -X POST http://127.0.0.1:7777/api/v1/commands/effect.get_params \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run effect.get_params --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: effect_get_params
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

effect.remove

Remove effect

СкасовуєтьсяInspector › Effect › DeleteMCP effect_remove

Removes video effects. For a segment on an effect track the whole effect segment is deleted (an emptied effect track is removed too). For a clip, removes the applied effect effect_id, or all applied effects when effect_id is omitted.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
effect_idstringApplied effect to remove from a clip; omit to remove all of them.

Повертає

{segment_id, deleted_segment: bool, effects: [remaining effects on the clip]}.

Приклади

// MCP tool: effect_remove

effect.set_params

Adjust effect

СкасовуєтьсяInspector › EffectMCP effect_set_params

Changes the slider parameters of an effect that is already used — CapCut's per-effect sliders in the Effect inspector (e.g. Intensity, Speed, Range). Target: the effect of an effect-track segment, or one of the effects applied to a clip (effect_id selects which; it may be omitted when the clip has exactly one). Every effect has intensity (0..1, 0 = off) and speed (animation speed multiplier, 0.1..10); most have their own named parameters listed in library.get {kind: "effect", id} → params.schema as [{id, label, min, max, default, step?, unit?}] (unit "%" = a 0..1 fraction shown as percent, "x" = multiplier, "/s" = per second, "s" = seconds, "°" = degrees). Pass them in params ({"levels": 4}) — intensity and speed may also be passed flat. Only the given parameters change; reset=true first restores every default. A value outside its range or an unknown parameter name is an invalid_argument error whose hint lists the valid parameters. Use effect.get_params to read the current values.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
effect_idstringWhich applied effect to change (needed when a clip has several).
intensitynumberEffect strength 0..1 (same as params.intensity).
Діапазон 0 … 1
paramsobjectNamed parameter values from the effect's schema, e.g. {"strength": 0.2, "rate": 2}. Must be within each parameter's min..max.
resetbooleantrue restores all parameters to their defaults before applying the given ones (the slider panel's reset button).
speednumberAnimation speed multiplier, 1 = normal (same as params.speed).
Діапазон 0.1 … 10

Повертає

The updated segment (segment.effect.params for effect-track segments, segment.effects[i].params for clips).
