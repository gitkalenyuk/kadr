Анімація: команди

2 команди у категорії «Анімація». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • animation.removeRemove animation
  • animation.setSet animation

animation.remove

Remove animation

СкасовуєтьсяInspector › Animation › NoneMCP animation_remove

Removes the In, Out, Combo or Loop animation of a segment (choosing 'None' in CapCut's Animation tab). kind=all (default) removes every animation. Removing an animation that is not set succeeds without changes.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
kindstringWhich animation to remove; all removes in, out, combo and loop.
Одне з in out combo loop allТипово "all"

Повертає

{segment_id, animations, loop_animation?} after removal.

Приклади

Remove the out animation

curl -X POST http://127.0.0.1:7777/api/v1/commands/animation.remove \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"out","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run animation.remove --kind out --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: animation_remove
{
  "kind": "out",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

Remove all animations

curl -X POST http://127.0.0.1:7777/api/v1/commands/animation.remove \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run animation.remove --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: animation_remove
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

animation.set

Set animation

СкасовуєтьсяInspector › AnimationMCP animation_set

Applies an In, Out or Combo animation preset to a video, photo, sticker or text segment — the Animation tab in CapCut (In plays at the start, Out at the end, Combo runs across the clip). id comes from library.list {kind: "animation"} and is kind-qualified ("in_fade", "out_zoom_out", "combo_swing", "loop_pulse"); an id whose prefix names another slot is rejected. Setting a Combo removes In and Out, and setting In or Out removes Combo, like CapCut. duration_us defaults to 0.5 s for in/out and to the whole segment for combo, and is clamped to the segment; when in+out would exceed the segment, the other one is shortened. kind=loop adds a repeating animation (duration = one cycle, default 1 s) that runs for the whole clip on any picture segment (video, photo, sticker, text) and combines with In/Out/Combo.

Параметри

ПараметрТипОпис
idобов’язковийstringAnimation id from library.list {kind: "animation"}, e.g. "in_fade", "out_slide_left" or "combo_swing".
kindобов’язковийstringAnimation slot: in (start), out (end), combo (whole clip) or loop (repeats for the whole clip).
Одне з in out combo loop
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id or from timeline.get.
duration_usintegerAnimation length; default 500000 for in/out, the segment length for combo, 1000000 for loop. Unit: microseconds.
Діапазон 0 … ∞

Повертає

{segment_id, animations: {in?, out?, combo?}, loop_animation?}.

Приклади

Fade in over 1 second

curl -X POST http://127.0.0.1:7777/api/v1/commands/animation.set \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"duration_us":1000000,"id":"in_fade","kind":"in","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run animation.set --duration_us 1s --id in_fade --kind in --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: animation_set
{
  "duration_us": 1000000,
  "id": "in_fade",
  "kind": "in",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

Zoom out at the end

curl -X POST http://127.0.0.1:7777/api/v1/commands/animation.set \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"id":"out_zoom_out","kind":"out","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run animation.set --id out_zoom_out --kind out --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: animation_set
{
  "id": "out_zoom_out",
  "kind": "out",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}
