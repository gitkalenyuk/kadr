captions.export_srt

Export captions

Без кроку скасуванняLibrary › Captions › ExportMCP captions_export_srt

Writes the project's text segments to a SubRip (.srt) file — Captions → Export. By default every text segment of every text track is exported in timeline order (overlapping texts from different tracks become separate cues); pass track_id to export a single caption track. The project is not modified. Existing files are overwritten; the folder must exist.

Параметри

ПараметрТипОпис
pathобов’язковийstringAbsolute path of the .srt file to write, e.g. C:\Users\me\Videos\captions.srt.
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
track_idstringOnly export this text track.

Повертає

{path, count}.

Приклади

Export subtitles

curl -X POST http://127.0.0.1:7777/api/v1/commands/captions.export_srt \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"path":"C:\\Users\\me\\Videos\\captions.srt","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run captions.export_srt --path 'C:\Users\me\Videos\captions.srt' --project_id prj_1a2b3c4d5e6f
// MCP tool: captions_export_srt
{
  "path": "C:\\Users\\me\\Videos\\captions.srt",
  "project_id": "prj_1a2b3c4d5e6f"
}

captions.import_srt

Import captions

СкасовуєтьсяLibrary › Captions › Import captionsMCP captions_import_srt

Imports a SubRip (.srt) subtitle file as text segments — one per cue — on a new text track (or on track_id), like Captions → Import captions. Timings come from the file (shifted by offset_us); overlapping cues are trimmed so they do not overlap, formatting tags such as <i> are stripped and multi-line cues keep their line breaks. Captions use the "Caption" look (white, size 9, thin black outline) or template_id, and sit in the lower part of the frame (transform y = 0.6, i.e. centred at 80% of the height). Edit any caption afterwards with text.update.

Параметри

ПараметрТипОпис
pathобов’язковийstringAbsolute path of the .srt file to import (UTF-8).
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
offset_usintegerShift every cue by this much on the timeline (may be negative; cues before 0 are dropped). Unit: microseconds.
Типово 0
template_idstringText template for the captions, e.g. "caption_box" or "caption_yellow" (default "caption_classic").
track_idstringExisting text track to fill; it must be free where the captions go. Omit to create a new text track.

Повертає

{track_id, count, segment_ids: [...], skipped: cues dropped because they ended before 0}.

text.add

Add text

СкасовуєтьсяLibrary › Text › Default textMCP text_add

Adds a text segment to a text track, like clicking "Default text" or a text template in the Text tab. The segment starts at at_us (default: playhead) and lasts duration_us (default 3 s). Without track_id the first text track that is free over that range is used; if every text track is occupied (or none exists) a new text track is created above all other visual tracks so the text draws on top. Default look (CapCut "Default text"): white Go Sans, size 15 (font height ≈ 1/20 of the canvas height), centred, positioned in the middle of the frame (transform x=0, y=0, scale 1). template_id applies a text-template preset (library.list kind=text_template, may include glyph animations); style overrides individual TextStyle fields on top of the default or template — including the wave-2 fields (case, glow, fill gradient, extra_strokes, extrude, curve, glyph_in/out/loop, words, highlight). style.effect_id applies a word-art preset (library kind text_effect) first, so other style fields in the same object override it. Change the look later with text.update, move it with segment.set_transform.

Діапазон 0 … ∞

Типово 3000000Діапазон 100000 … 86400000000

text.apply_effect

Apply text effect

СкасовуєтьсяLibrary › Text › EffectsMCP text_apply_effect

Applies a word-art preset ("text effect": gradient, metal, luxury, neon, candy, texture, sticker, hand-made, outline, 3D, retro, spooky, gaming and cute looks from library.list kind=text_effect) to a text segment, like clicking a card in the Text → Effects grid. The preset WRITES its fields into the TextStyle — fill gradient, glow, extra_strokes, extrude, the wave-4 pattern / bevel / inner shadow / inner glow / echo / distress / sparkle / drip / rough / pixelate fields and, where the preset uses them, stroke, shadow and color — after clearing the previous preset's fill/glow/extra outlines/extrusion, and records its id in effect_id. Rendering uses only the stored fields, so every value stays editable with text.update afterwards. Words, font, size, alignment, animations and timing are kept. effect_id "none" removes the preset's fill, glow, extra outlines and extrusion (a transparent hollow colour becomes white).

Параметри

effect_idобов’язковийstringText effect id from library.list kind=text_effect, e.g. "fx_gold_metal", "fx_neon_outline", "fx_3d_extrude", or "none" to remove.
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Повертає

The new TextStyle of the segment.

text.set_glyph_animation

Set text animation

СкасовуєтьсяInspector › Text › AnimateMCP text_set_glyph_animation

Sets a per-letter / per-word text animation (library.list kind=text_animation) — the Text → Animate panel: typewriter with caret, letter rise/drop/pop/zoom/spin, karaoke sweep, random spell (scramble), word pop, word focus (blur-in), wave, jitter, rainbow, glow pulse, shine and more. These play INSIDE the text image and combine freely with each other and with the clip-level animations of animation.set. kind=in plays over duration_us from the segment start, kind=out over duration_us up to the segment end (in and out are shortened proportionally when they do not both fit), kind=loop repeats with duration_us as the period for the whole segment. A bare name is qualified with kind ("typewriter" + in → "in_typewriter"). Without duration_us the slot keeps its current duration, else the item's default_duration_us is used; in/out durations are clamped to the segment length.

Параметри

ПараметрТипОпис
idобов’язковийstringText animation id from library.list kind=text_animation (in_*, out_*, loop_*), e.g. "in_typewriter", "out_letter_drop", "loop_wave".
kindобов’язковийstringWhich slot: in (plays from the segment start), out (ends at the segment end) or loop (repeats for the whole segment).
Одне з in out loop
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
duration_usintegerDuration of the in/out animation, or the period of one loop cycle (1 second = 1000000). Unit: microseconds.
Діапазон 100000 … 60000000

Повертає

The updated TextStyle (glyph_in / glyph_out / glyph_loop = {id, duration_us}).

text.update

Edit text

СкасовуєтьсяInspector › TextMCP text_update

Changes the content and look of a text segment — the Text tab of the inspector (Basic: font, size, style, colour, case, alignment, spacing; Stroke; Extra outlines; Shadow; Background box; Glow; Gradient fill; 3D extrude; Curve; Word-art effect; caption highlight). Only the parameters you pass change. Units: size is CapCut's scale (15 = default, font height ≈ size/300 of the canvas height); letter_spacing and line_spacing are in em (0.1 = 10% of the font size) added to the normal spacing; stroke_width, shadow_blur and shadow_distance are 0..1 (stroke up to 0.25 em thick, shadow offset/blur up to 0.5 em); shadow_angle, fill_angle and extrude_angle are in degrees counter-clockwise from the right (-45 = down-right, -90 = downwards / top→bottom); box_radius 0..1 rounds the corners (1 = pill). Stroke, shadow, box, glow and extrude are enabled by setting any of their parameters (missing ones get defaults: black stroke width 0.3, black shadow opacity 0.6/blur 0.3/distance 0.15/angle -45, black box opacity 0.6/radius 0.2, glow in the text colour intensity 0.6/radius 0.35, dark-grey extrude depth 0.15/angle -45) and removed with stroke_width=0, shadow_opacity=0, box_opacity=0, glow_intensity=0 or extrude_depth=0. Gradient fill: fill_type linear|radial with 2–4 fill_colors (evenly spaced; radial goes centre→edge), fill_type=solid removes it (the text colour is used again); passing only fill_colors turns on a linear gradient. A color with alpha 00 ("#FFFFFF00") plus a stroke gives hollow outline text. curve -1..1 bends the lines into an arc (1 = half circle arch, -1 = smile). case upper|lower|title converts letters when rendering (the stored content is unchanged; none = as typed). effect_id applies a word-art preset from library.list kind=text_effect FIRST (it writes fill, glow, extra_strokes, extrude and the stroke/shadow/color it uses — the rendered look comes only from the stored fields), so other parameters in the same call override it; effect_id "" or "none" removes the preset's fill/glow/extra outlines/extrusion. Captions: words (timings relative to the segment start) plus highlight_style color|box|scale|underline|karaoke|pop|bounce|reveal|dim|glow|sweep_line|slide_box highlight the spoken word (highlight_style=none removes it). Per-letter animations are set with text.set_glyph_animation. Wave-4 word art (all optional; each group is enabled by any of its parameters and removed by its zero amount): fill_stops (hard-edged chrome/duotone gradients, up to 8 fill_colors); stroke_fill_* (gradient outline); pattern_* (procedural texture over the fill: stripes, checker, dots, halftone, hearts, stars, grain, glitter, holo, foil, brushed metal, marble, camo, galaxy, lava flow, aurora, rainbow…, pattern_speed animates the moving ones); bevel_* (emboss lighting; bevel_round + bevel_gloss = puffy glossy letters); inner_shadow_* and inner_glow_* (inside the letters); echo_* (stacked offset copies, retro 3D stacks / trails); distress_* (grunge, chalk, stamp, spray, scratch, worn); sparkle_* (star glints, sparkle_speed twinkles); drip_* (paint or slime drips); rough (hand-made wobble); pixelate (pixel-art blocks); box_* extras (gradient box, border, card shadow, one box per line, skew, padding, knockout stencil); highlight_text_color (letter colour of the active caption word). Highlight styles also include pop, bounce, reveal, dim, glow, sweep_line and slide_box.
