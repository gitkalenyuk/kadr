ai.auto_reframe

Auto reframe

СкасовуєтьсяToolbar › Auto reframeMCP ai_auto_reframe

Re-frames a clip for another aspect ratio (e.g. landscape 16:9 footage for a 9:16 TikTok/Reels/Shorts canvas) and keeps the main subject in the picture, like CapCut's 'Auto reframe'. The clip is scaled to FILL the target ratio (no bars) and its position is animated with transform.x keyframes (transform.y when the source is taller than the target) that follow the subject: frames are sampled at sample_fps, the subject centre is estimated from motion, edge density and skin-tone cues, and the path is smoothed with a critically damped filter (smoothing 0 = responsive, 1 = very calm camera). Positions are clamped so the clip always covers the canvas. Existing transform.x/y/scale keyframes of the clip are replaced; rotation, crop and animations are kept. With set_canvas=true the project canvas is switched to `ratio` too (other clips are not reframed — run the command for each clip). ratio defaults to the current canvas ratio. Photos get a static best position. Takes about a second per minute of video. One undo step. Undoable.

project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringVideo or photo clip to reframe.
ratiostringTarget aspect ratio, e.g. 9:16 (vertical), 1:1, 4:5-like 3:4, 16:9. Defaults to the project's canvas ratio.
Одне з 16:9 9:16 1:1 4:3 3:4 21:9 2.35:1 2:1 1.85:1 5.8-inch
sample_fpsnumberAnalysis frames per second of video; higher follows fast motion better but is slower.
Типово 6Діапазон 1 … 15

Типово false

Типово 0.5Діапазон 0 … 1

Типово 1Діапазон 1 … 3

ai.cancel

Cancel smart tool job

Без кроку скасуванняMCP ai_cancel

Cancels a queued or running background smart-tool job (e.g. a long background removal). The partial result is discarded and the clips stay as they were; ai.progress reports state 'cancelled'. Cancelling a finished job is a no-op that returns its final state.

ai.capabilities

Smart tools status

Без кроку скасуванняInspector › Video › Remove BGMCP ai_capabilities

Reports which smart tools work on this machine. Scene detection, silence removal, auto reframe and video clean-up only need ffmpeg. Background removal needs a local model provider; the report says which one was found (rembg / onnx / torch), the model file and Python used, which Python packages are importable and where models were searched — or, when none is usable, the error and an install hint (e.g. `pip install rembg onnxruntime`, or put an ONNX matting model at <DataDir>/models/matting.onnx / set KADR_MATTING_MODEL). Detection results are cached; pass refresh=true after installing something. Read-only.

ai.detect_scenes

Detect scenes

Без кроку скасуванняToolbar › Split sceneMCP ai_detect_scenes

Finds the scene changes (camera cuts) inside a video clip without changing anything. ffmpeg's scene detector scores every frame of the clip's source range by how different it is from the previous frame; frames scoring at least `threshold` are cuts. Cut times are mapped onto the timeline with the clip's speed, speed curve and reverse, so time_us can be passed straight to timeline.segment.split. Use it to preview what ai.split_scenes would do, to place markers, or to pick shots. Takes a few seconds per minute of video (results are cached). Read-only.

project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringVideo clip to analyse (timeline.get lists segment ids).
min_scene_usintegerShortest scene to keep: cuts closer than this to another (stronger) cut or to the clip edges are ignored (flashes, strobes). Unit: microseconds.
Типово 500000Діапазон 0 … 600000000
thresholdnumberScene-change sensitivity: ffmpeg scene score 0..1 a frame must reach. 0.2 = sensitive (also soft cuts), 0.3 = default, 0.5+ = only hard cuts.
Типово 0.3Діапазон 0.05 … 1

Повертає

ai.remove_background

Remove background

СкасовуєтьсяInspector › Video › Remove BGMCP ai_remove_background

Removes the background of a video, photo or sticker clip automatically (CapCut's 'Remove background → Auto removal'), leaving the person/main subject on a transparent background so lower tracks or the canvas background show through. A local segmentation model computes a greyscale alpha matte per frame (saved in the project cache and recorded as the material's matte_path); the renderer multiplies it into the clip's alpha, so preview, preview.frame and export agree. The matte belongs to the material, so split or duplicated clips of the same file reuse it. Only the frames the project's clips use (+1 s margin) are processed. Providers are detected at run time (see ai.capabilities): Python `rembg`, or `onnxruntime` with an ONNX matting model (KADR_MATTING_MODEL, <DataDir>/models/matting.onnx or rembg's ~/.u2net cache), or `torch` with a TorchScript model; without one the command fails with not_available and an install hint. Matting is slow (roughly 2-10 frames per second on a CPU): by default the command returns at once with state 'running' and a job_id, publishes 'ai.progress' events and, when the matte is ready, applies it as its own undoable step. Agents can pass wait=true to block until it is done (the project cannot be edited meanwhile) and get state 'done'. When a matte already exists the clip is switched on immediately. enabled=false switches the removal off (the matte is kept for later). Undoable.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringVideo, photo or sticker clip whose background to remove.
enabledbooleantrue removes the background (computing the matte if needed); false shows the clip unmasked again.
Типово true
regeneratebooleantrue recomputes the matte even when a usable one exists (e.g. after installing a better model).
Типово false
waitbooleantrue blocks until the matte is computed and returns state done (short clips; matting runs at roughly 2-10 frames/s). If the caller disconnects, the job keeps running and is applied when done. false returns at once with a job_id.
Типово false

Повертає

{segment_id, state: done|off|running|queued, enabled, job_id?, provider?, model?, matte_path?, reused?, note}. With state running/queued, follow the job with ai.progress events or ai.jobs{job_id}.

ai.remove_silence

Remove silence

СкасовуєтьсяToolbar › Smart tools › Remove silenceMCP ai_remove_silence

Cuts the silent parts out of a clip with sound (talking-head videos, voice-overs, podcasts) and closes the gaps: ffmpeg's silencedetect finds stretches where the clip's own audio stays below threshold_db for at least min_silence_us; padding_us of each silence is kept on both sides so words are not clipped; the remaining parts are joined (ripple). On the main track with the magnet everything after the clip moves left; elsewhere the following clips on the same track move left. Linked clips (e.g. extracted audio) are cut identically. Silence at the clip edges is trimmed too. Works on video clips with an audio stream and on audio clips; times honour speed and reverse. The whole edit is one undo step; removed lists what was cut (timeline times before the ripple). When the entire clip is below the threshold nothing changes and an error explains how to adjust it. Undoable.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringVideo (with sound) or audio clip to tighten.
min_silence_usintegerShortest pause to remove (timeline time). Shorter pauses are natural speech rhythm and are kept. Unit: microseconds.
Типово 500000Діапазон 50000 … 60000000
padding_usintegerSilence kept on each side of a cut so speech does not start or end abruptly. Unit: microseconds.
Типово 100000Діапазон 0 … 2000000
threshold_dbnumberAudio quieter than this counts as silence. -40 suits clean voice recordings; use -30 for noisy rooms, -50 for very quiet ones. Unit: dBFS.
Типово -40Діапазон -90 … -5

Повертає

{segment_id, threshold_db, removed:[{start_us, end_us, duration_us, source_start_us, source_end_us}], removed_total_us, segment_ids[] (remaining clips in order), rippled, note}.

ai.split_scenes

Split scenes

СкасовуєтьсяToolbar › Split sceneMCP ai_split_scenes

CapCut's 'Split scene': detects the scene changes of a video clip (exactly like ai.detect_scenes) and splits the clip at every cut, so each shot becomes its own clip that can be trimmed, reordered or deleted. Linked clips (e.g. the extracted audio) are split at the same times. The original segment id stays on the first scene; segment_ids lists all resulting clips in timeline order. The whole split is one undo step. When no cut is found nothing changes (lower threshold to be more sensitive). Undoable.
