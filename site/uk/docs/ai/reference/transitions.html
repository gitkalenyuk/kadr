Переходи: команди

4 команди у категорії «Переходи». Кожна працює однаково з інтерфейсу редактора, через REST, MCP і kadrctl.

Описи команд і параметрів залишено англійською навмисно: це дослівно той самий текст, який ШІ-агенти отримують через MCP та OpenAPI, тож тут ви бачите саме те, що бачить агент. Решту сторінки перекладено.

  • transition.apply_allApply transition to all
  • transition.getGet transition
  • transition.removeRemove transition
  • transition.setSet transition

transition.apply_all

Apply transition to all

СкасовуєтьсяInspector › Transition › Apply to allMCP transition_apply_all

Puts the same transition between every pair of touching clips on a track (default: the main video track) — CapCut's "Apply to all" button. type/duration default to the transition of segment_id if given, else the first transition already on the track, else Mix 0.5 s. Each duration is clamped to half of the shorter clip of its pair; pairs with a gap or clips shorter than 0.2 s are skipped and counted. direction and softness work as in transition.set (they are applied on top of the copied type).

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
directionstringOptional direction for transitions that have one (library item params.directions): the way the motion travels. For directional families (wipe_*, slide_*, push_*, cube_turn_*, whip_*) it selects the sibling id.
Одне з left right up down
duration_usintegerTransition length; clamped per pair. See the description for the default. Unit: microseconds.
Діапазон 100000 … 10000000
segment_idstringCopy type and duration from this clip's transition (the selected transition in the UI).
softnessnumberOptional edge softness 0..1 (0 = hard edge, 1 = very soft) for mask transitions with params.softness=true (wipes, irises, shape reveals, checkerboard, luma/ink dissolves, burns, light sweep).
Діапазон 0 … 1
track_idstringTrack to process (main or overlay video track). Defaults to the main video track.
typestringTransition id from library.list kind=transition. See the description for the default.

Повертає

{track_id, type, duration_us, applied: number of pairs set, skipped: number of pairs skipped}.

Приклади

Mix between every clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/transition.apply_all \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","type":"mix"}'
kadrctl run transition.apply_all --project_id prj_1a2b3c4d5e6f --type mix
// MCP tool: transition_apply_all
{
  "project_id": "prj_1a2b3c4d5e6f",
  "type": "mix"
}

Copy the selected clip's transition

curl -X POST http://127.0.0.1:7777/api/v1/commands/transition.apply_all \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run transition.apply_all --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f

transition.get

Get transition

Без кроку скасуванняInspector › TransitionMCP transition_get

Describes the transition that follows a clip — what the Transition inspector shows when a transition badge is selected: the stored type, its library id and name, duration, the current direction and softness (defaults filled in) and which options the transition supports, plus the longest duration the pair allows. has_transition=false (and no transition fields) when the cut is a hard cut. Change it with transition.set.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Повертає

{segment_id, has_transition, next_segment_id?, max_duration_us?, type?, id?, name?, duration_us?, direction?, softness?, options?}.

Приклади

Inspect the transition after a clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/transition.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run transition.get --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: transition_get
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

transition.remove

Remove transition

СкасовуєтьсяInspector › Transition › DeleteMCP transition_remove

Removes the transition that follows a clip (segment.transition_out), turning it back into a hard cut. Removing from a clip without a transition is a no-op that reports removed=false.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Повертає

{segment_id, removed: bool}.

Приклади

Back to a hard cut

  -H "Authorization: Bearer $KADR_TOKEN" \

kadrctl run transition.remove --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: transition_remove
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"

transition.set

Set transition

СкасовуєтьсяLibrary › TransitionsMCP transition_set

Adds or replaces the transition between a clip and the NEXT clip on the same track (main or overlay video track), like dropping a transition between two clips in CapCut. The transition is stored on the left clip (segment.transition_out) and plays across the cut. The two clips must touch (the next clip starts where this one ends, within half a frame); otherwise a conflict error explains how to fix it. duration_us is clamped to half of the shorter of the two clips (the result reports clamped=true); both clips must be at least 0.2 s long. Optional direction (left/right/up/down) and softness (0..1) apply to transitions whose library item lists them in params (directions, softness); they are stored in the type as URL-style options, e.g. "bars_stagger?direction=up&softness=0.3" (directional families such as wipe_left + direction up store the sibling id "wipe_up"; values equal to the defaults are dropped). Strip everything from "?" to get the library id. Asking a transition for an option it does not have is an invalid_argument error listing its options.

Параметри

ПараметрТипОпис
project_idобов’язковийstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idобов’язковийstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
typeобов’язковийstringTransition id from library.list kind=transition, e.g. "mix", "black_fade", "wipe_left", "cube_turn_left", "iris_heart". A stored type with options ("blinds_h?direction=up") is accepted too.
directionstringOptional direction for transitions that have one (library item params.directions): the way the motion travels. For directional families (wipe_*, slide_*, push_*, cube_turn_*, whip_*) it selects the sibling id.
Одне з left right up down
duration_usintegerTransition length (default 0.5 s). Clamped to half of the shorter neighbouring clip. Unit: microseconds.
Типово 500000Діапазон 100000 … 10000000
softnessnumberOptional edge softness 0..1 (0 = hard edge, 1 = very soft) for mask transitions with params.softness=true (wipes, irises, shape reveals, checkerboard, luma/ink dissolves, burns, light sweep).
Діапазон 0 … 1

Повертає

{segment_id, next_segment_id, transition: {type, duration_us}, id, name, direction?, softness?, options: {directions, default_direction, softness, default_softness, direction_by_sibling}, clamped, max_duration_us}.
