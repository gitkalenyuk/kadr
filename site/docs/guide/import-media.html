Import media

Before you can edit, bring your videos, photos and music into the project. They appear in the Media tab, ready to be placed on the timeline.

Three ways to import

  • Import button. Open the Media tab and click Import. A normal Windows file window opens; select one or several files (hold Ctrl or Shift to pick many) and click Open.
  • Keyboard. Press Ctrl+I anywhere in the editor. The same is in Menu → Import media.
  • Drag and drop. Drag files — or a whole folder — from File Explorer onto the Kadr window. When you drop a folder, every video, audio and photo file inside it is imported.

A progress bar shows the import. Thumbnails, filmstrips (the little pictures inside timeline clips) and audio waveforms are created in the background, so you can start editing straight away. Importing the same file twice does nothing — Kadr recognises it.

Kadr does not copy your files. It remembers where they are, so keep the originals in place until the video is exported.

Supported formats

KindFile types
VideoMP4, MOV, M4V, MKV, WebM, AVI, WMV, FLV, MTS / M2TS / TS, 3GP, MPG / MPEG, OGV, MXF and animated GIF
AudioMP3, WAV, AAC, M4A, FLAC, OGG, Opus, WMA, AIFF
PhotosJPG / JPEG, PNG, BMP, WebP, TIFF, HEIC / HEIF, AVIF, JFIF

Practically anything FFmpeg can read works, including H.264, HEVC (H.265), ProRes and VP9 video. Phone videos recorded upright are shown the right way up automatically.

Find your media

  • The chips All, Videos, Photos and Audio filter the list; the number on the right is how many items are shown.
  • Search media finds files by name.
  • A green Added label means the file is already used on the timeline. The time in the corner is the length of the clip; a small icon marks photos and audio.

Put media on the timeline

  • Hover a card and click +, or select it and press Enter. Videos and photos are added to the end of the main track; audio goes onto an audio track, starting at the playhead.
  • Or drag the card onto the timeline exactly where you want it. Dropped on the main track, the clip is inserted at the nearest cut and the clips after it move right. Dropped on an overlay track — or above the top track, which creates a new one — it becomes a picture-in-picture overlay.

Photos get a duration of 5 seconds; drag their edge on the timeline to make them longer or shorter. Continue in Timeline editing.

The card menu

Right-click a card (or press the Menu key) to see:

ItemWhat it does
Add to timeline (Enter)Same as the + button.
Rename (F2)Changes the name shown in Kadr. The file on disk keeps its name.
Create proxyMakes a light copy for smooth playback — see below. Video only.
Relink… / Link media…Point Kadr to the file's new location after you moved or renamed it.
Copy file pathCopies the full path of the original file.
Delete (Del)Removes the item from the project. If it is used on the timeline, Kadr tells you how many clips will be removed with it. The file on your disk is not touched, and Ctrl+Z brings it back.

Proxies for 4K and heavy footage

4K, HEVC and other heavy videos can make the preview stutter. A proxy is a small, easy-to-play copy (540p) that Kadr uses only while you edit. Right-click the video card and choose Create proxy; a percentage on the card shows the progress, and the menu then says Proxy created.

  • The player and the timeline use the proxy automatically.
  • Export always uses the original file, so the final video keeps its full quality.
  • Proxies are stored in the project's cache folder.

Another quick fix for a slow preview is lowering the preview quality to Half or Quarter under the player — see Player & preview.

Missing files

If you move, rename or delete an original file, its card is marked as missing and its clips can't be shown. Right-click the card, choose Link media… and type the new full path of the file (for example D:\Footage\beach.mp4). Everything on the timeline comes back as it was.

Library section

The Library entry on the left of the Media tab is reserved for built-in stock footage, which is not available yet. For ready-made backgrounds, countdowns and colour bars, use the generated media in the Stickers tab. For music, import your own audio files.
