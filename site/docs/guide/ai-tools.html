AI tools

Smart tools do tedious work for you: they find scene changes, cut silences, follow the subject when you change the video's shape and cut people out of the background. They all run on your computer — nothing is uploaded.

Where to find them

  • Smart tools menu in the toolbar above the timeline: Split scenes, Remove silence, Auto reframe, Separate audio, Auto captions.
  • The right-click menu of a clip lists the smart tools that fit that clip.
  • The inspector: Video → Smart tools (with extra options) and Video → Remove BG.

Select a clip first — the menu tells you “Select a clip” or “Not for this clip” when a tool doesn't apply. Longer jobs show a “started” message and run in the background; every result is one undo step, so Ctrl+Z brings everything back.

Remove background

Cuts out people or the main subject from a video or photo — no green screen needed. Whatever is on lower tracks, or the canvas background, shows through.

  1. Select the clip and open Video → Remove BG in the inspector.
  2. Switch on Auto removal. A progress bar shows “Finding the subject” with a percentage and the time left. You can keep editing; Cancel stops it.
  3. When it is done, the subject is cut out. Redo computes it again (for example after installing a better model); switching the toggle off brings the background back.

What you need

Background removal uses the free rembg package for Python. Setup is a one-time job:

  1. Install Python

    Install Python 3 from python.org and tick Add python.exe to PATH (if you set up auto captions, you already have it).

  2. Install rembg

    Open PowerShell and run:

    pip install rembg onnxruntime

    The first background removal downloads rembg's model once; after that everything works offline.

  3. Check in Kadr

    Open Video → Remove BG. If it says Auto removal is not available on this computer, it also explains what is missing; fix that and click Check again (or restart Kadr).

Advanced alternative: instead of rembg, Kadr can use onnxruntime with any ONNX matting model (U²-Net, IS-Net, MODNet…) saved as models\matting.onnx inside the Kadr data folder. Removal takes a while on long or 4K clips — you can keep editing meanwhile.

Split scenes

Have a long video made of several shots — a trailer, a screen recording with cuts, a downloaded compilation? Split scenes finds every camera change and cuts the clip there, so you can delete or reorder shots.

  • Quick: select a video clip, then Smart tools → Split scenes.
  • With options: Video → Smart tools → Split scenes. Raise Sensitivity to catch softer changes, lower it if Kadr cuts too often.

Remove silence

Perfect for talking-head videos, lessons and podcasts. Select a video or audio clip with speech and choose Smart tools → Remove silence. Kadr cuts out every pause longer than half a second and closes the gaps; a message tells you how many pauses and seconds were removed.

For word-level control — removing “um”s and choosing pause lengths — use the Transcript tab.

Auto reframe

Turns a landscape video into a vertical (or square) one without losing the subject: Kadr follows the person or the main action and moves the picture smoothly with keyframes.

  • Quick: select a video or photo clip, open Smart tools → Auto reframe and choose 9:16, 1:1, 4:3, 3:4 or 16:9. The project switches to that shape too.
  • With options: Video → Smart tools → Auto reframe… lets you pick the Ratio, the Smoothness of the camera movement, and whether to switch the Canvas; then click Reframe.

Afterwards you can fine-tune the position keyframes like any other keyframes.

More smart features

  • Auto captions and transcript editing with offline Whisper — Captions & transcript.
  • Separate audio — Audio.
  • Auto adjust for colour — Colour adjustment.
  • Reduce image noise, Remove flicker (Video → Basic) and Reduce noise for sound (Audio → Basic).

Let an AI assistant drive. Everything above — and the whole editor — can be operated by Claude or another AI assistant: “cut the silences, add word-highlight captions and export a vertical version”. You watch every step happen in the window. Start with the AI documentation.
