Music video cut to the beat

You get a music video where every cut lands on a beat, with a white flash on each cut, a teal-and-orange grade over everything, a punch-zoom when the track drops and a title over the first bar. The beats are detected on your PC, and the whole cut list is applied as one undoable step.

  • Time: ~2 min
  • You need: A song and a folder of clips
  • Main commands: audio.detect_beats, timeline.segment.add, timeline.segment.trim, segment.set_volume, transition.apply_all, filter.add, effect.add, text.add, export.start

Ask Claude

In Kadr, make a 16:9 music video from C:\Users\you\Music\night-drive.mp3 and the clips in C:\Users\you\Videos\drive. Detect the beats and add beat markers. Cut to a new clip on every bar (every 8th onset — about 2 seconds at this tempo) for the first 16 seconds, cycling through the clips and using a later part of each clip the second time round. Mute the clips' own sound, end the song where the video ends with a 1.5 s fade-out, put a short white flash on every cut, grade everything with teal_orange at 80%, add punch_zoom for one bar at 8 seconds and the title "NIGHT DRIVE" with the cinematic template for the first 3 seconds. Show me a contact sheet, then export 1080p.

Step by step

Each step shows the same calls twice. The kadrctl tab is for PowerShell: a line that starts with kadrctl --% passes JSON, and without --% the same line also works in Command Prompt. The MCP tab is the tool call an agent sends — the tool name and its arguments. Ids such as prj_…, mat_… and seg_… come from the results of earlier steps, so yours will differ. Paths under C:/Users/you are examples.

  1. Create the project and import

    kadrctl run project.create --name "Night drive" --ratio 16:9
kadrctl --% run media.import --project_id prj_408e1a6dfbd6 --paths "[\"C:/Users/you/Music/night-drive.mp3\",\"C:/Users/you/Videos/drive\"]"
    {"name": "project_create", "arguments": {"name": "Night drive", "ratio": "16:9"}}
{"name": "media_import", "arguments": {"project_id": "prj_408e1a6dfbd6", "paths": ["C:/Users/you/Music/night-drive.mp3", "C:/Users/you/Videos/drive"]}}

    The song becomes mat_971f6c60fb07; the four clips are mat_757801976c94, mat_eb4ddf31388d, mat_f5b1e7278a6f and mat_434577267af4.

  2. Put the song on the timeline

    Audio never goes to the main track: it lands on an audio track, here from 0 s.

    kadrctl run timeline.segment.add --project_id prj_408e1a6dfbd6 --material_id mat_971f6c60fb07 --at_us 0
    {"name": "timeline_segment_add", "arguments": {"project_id": "prj_408e1a6dfbd6", "material_id": "mat_971f6c60fb07", "at_us": 0}}

  3. Detect the beats

    audio.detect_beats analyses the song on your PC and returns every onset as a timeline time in microseconds, plus a rough tempo. add_markers also puts a “Beat” marker on the ruler, so clips you drag later in the editor snap to the music.

    kadrctl run audio.detect_beats --project_id prj_408e1a6dfbd6 --segment_id seg_a685cca02d34 --sensitivity 0.5 --add_markers
    {"name": "audio_detect_beats", "arguments": {"project_id": "prj_408e1a6dfbd6", "segment_id": "seg_a685cca02d34", "sensitivity": 0.5, "add_markers": true}}
    {
  "segment_id": "seg_a685cca02d34",
  "count": 120,
  "bpm": 119.8,
  "markers_added": 120,
  "beats_us": [0, 252517, 501769, 720907, 1000998, 1248435, 1501678, 1750567, 2001270, …]
}

    Shortened. This track has a hi-hat on every eighth note, so onsets come about every 0.25 s at 120 BPM; one 4/4 bar is 8 onsets. Taking every 8th entry gives the cut points 0, 2001270, 4001088, 6001270, 8001088, 10001270, 12001088, 14001270 and 16001088 µs.

  4. Cut the clips on the beats in one batch

  6. Flash on every cut

    A short transition keeps the cut on the beat. transition.apply_all sets it on all seven cuts.

    kadrctl run transition.apply_all --project_id prj_408e1a6dfbd6 --type white_flash --duration_us 160ms
    {"name": "transition_apply_all", "arguments": {"project_id": "prj_408e1a6dfbd6", "type": "white_flash", "duration_us": 160000}}

  7. Grade, hit the drop, add a title

    filter.add puts the filter on its own track, so it colours everything below it for its whole length. effect.add places punch_zoom on the fifth bar, from 8001088 µs for one bar. text.add with the cinematic template adds the title on a text track.

    kadrctl run filter.add --project_id prj_408e1a6dfbd6 --filter_id teal_orange --at_us 0 --duration_us 16001088 --intensity 0.8
kadrctl run effect.add --project_id prj_408e1a6dfbd6 --effect_id punch_zoom --at_us 8001088 --duration_us 2000182
kadrctl run text.add --project_id prj_408e1a6dfbd6 --text "NIGHT DRIVE" --template_id cinematic --at_us 0 --duration_us 3s
    {"name": "filter_add", "arguments": {"project_id": "prj_408e1a6dfbd6", "filter_id": "teal_orange", "at_us": 0, "duration_us": 16001088, "intensity": 0.8}}

    kadrctl run preview.contact_sheet --project_id prj_408e1a6dfbd6 --count 8 --columns 4 --tile_width 240
kadrctl run export.start --project_id prj_408e1a6dfbd6 --resolution 1080p --path C:/Users/you/Videos/Kadr/night-drive.mp4

Variations

One long clip, split on every beat

timeline.segment.split needs no segment_id when you pass only at_us: it splits whatever main-track clip is under that time. A batch of splits, one per cut point, chops a single long take into beat-length pieces that you can then delete, reverse or speed up one by one.

[
  { "command": "timeline.segment.split", "args": { "at_us": 2001270 } },
  { "command": "timeline.segment.split", "args": { "at_us": 4001088 } },
  { "command": "timeline.segment.split", "args": { "at_us": 6001270 } }
]

More ideas

  • Faster cuts. Use every 4th onset (one cut per beat) for the chorus and every 8th for the verse.
  • Other cut styles. Try flash_zoom, glitch, whip_pan or zoom_blur_through as the transition, and rgb_pulse or hard_shake as the drop effect. library.list with kind transition or effect lists them all.
  • Vertical version. See One project, three formats.

Tips

  • sensitivity goes from 0 to 1: 0.7–0.9 for busy percussion, 0.2–0.4 to keep only strong hits. strengths gives each beat’s strength (0–1), which helps tell downbeats from off-beats.
  • Beat times are already timeline times (the song’s position and speed are taken into account), so they go straight into at_us and duration_us.
  • audio.detect_beats is recorded as an undo step even without add_markers; that is harmless.
