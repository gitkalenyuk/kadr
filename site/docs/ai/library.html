Library, previews and fonts

Everything an agent can add to a video — transitions, effects, filters, animations, text looks, stickers, generated backgrounds, fonts, sounds — comes from the built-in library. Discover ids with library.list, look at the candidates with library.preview, then apply the one that fits. Never guess an id.

What is in the library

Find candidates

library.list takes a kind, an optional category (a tab name from the result's categories) and an optional query that searches names, ids, categories and descriptions. Narrow the list instead of reading 300 items: descriptions are written for agents — what the item looks like and when to use it.

{"name": "library_list", "arguments": {"kind": "transition", "category": "Liquid"}}
{"name": "library_list", "arguments": {"kind": "effect", "query": "rain"}}
kadrctl run library.list --kind transition --category Liquid
kadrctl run library.list --kind effect --query rain
tide_wipe   Tide        A rolling wave front with a sparkling white foam crest washes the new clip in…
                        params: directions [right left down up], softness true, default_softness 0.2
paint_drip  Paint drip  The new clip pours down from the top like thick glossy paint…
ink_bleed   Ink bleed   Dark ink blots spread with organic tendrils from a few drops…

Look before you choose: library.preview

Names and descriptions only go so far. library.preview renders how an item plays as one PNG contact sheet — over MCP it comes back as an image the model can see. Use it to compare two or three candidates before applying one.

{"name": "library_preview", "arguments": {"kind": "transition", "id": "tide_wipe", "frames": 6, "columns": 6, "tile_width": 160}}
kadrctl run library.preview --kind transition --id tide_wipe --frames 6 --columns 6 --tile_width 160
{"kind": "transition", "id": "tide_wipe", "name": "Tide", "animated": true,
 "frames": 6, "columns": 6, "rows": 1, "tile_width": 160, "tile_height": 90,
 "phases": [0.159, 0.227, 0.295, 0.364, 0.432, 0.5], "times_us": [344697, …], "loop_us": 2166667,
 "preview": {"url": "/api/v1/library/transition/tide_wipe/preview", "frames": 26, "fps": 12, "width": 192, "height": 108},
 "note": "Tiles run from transition progress 0 (outgoing clip A, a sunny landscape) to 1 (incoming clip B, a night city)…",
 "png_base64": "…"}
KindWhat the tiles show
TransitionsFrom a sunny landscape (clip A) to a night city (clip B), left to right, top to bottom.
EffectsEvenly spaced moments of the effect on the landscape; static effects such as a vignette show a before/after divider.
FiltersA before/after divider sweeping across the picture.
Clip animationsA small clip moving on a dark stage; a dashed outline marks its rest position.
Text templates, word art, text animations, caption stylesSample text as it animates, or the spoken-word highlight moving through a caption.
Animated stickers, moving generated mediaOne loop of the sticker's default animation or of the background.
  • frames 2–12 (default 6) sets how many moments you see; columns (≤ 6) and tile_width set the layout. A one-row strip of 6 tiles at 160 px is cheap and easy to compare.
  • note says what the tiles show for this kind; times_us and phases place each tile in the preview loop.
  • Static items (fonts, voice effects, still stickers and templates) return their thumbnail as one tile with "animated": false.
  • The sample pictures are not your footage. To see the item in your edit, apply it and check with preview.frame or preview.contact_sheet — see Verifying results.

A complete walk-through is the recipe Choose a transition and an effect by looking at them.

The preview field and thumbnails

Every item that moves carries preview in library.list and library.get results — the editor uses it for its hover previews:

"preview": {"url": "/api/v1/library/transition/mix/preview", "frames": 24, "fps": 12, "width": 192, "height": 108}

GET the url (with the API token) for a JPEG sprite strip: frames tiles of width×height side by side, left to right, one seamless loop at fps. No preview field means a static item. Every item also has a thumbnail path (a still PNG). Agents normally prefer library.preview; the strip is for your own UI. Strips are cached in memory and under <DataDir>/library/previews/.

Options: directions, softness and effect sliders

A transition item lists what it accepts: params.directions and default_direction, params.softness and default_softness. Pass them to transition.set (direction = the way the motion travels; softness 0–1). An effect item lists its sliders in params.schema ({id, label, min, max, default}); pass values in params of effect.add / effect.apply, or later with effect.set_params.

{"name": "transition_set", "arguments": {"project_id": "prj_e21b467917e3", "segment_id": "seg_3ccd6c9e2cbe", "type": "tide_wipe", "duration_us": 800000, "direction": "left", "softness": 0.3}}
{"name": "effect_add", "arguments": {"project_id": "prj_e21b467917e3", "effect_id": "rain_glass", "at_us": 3000000, "duration_us": 3000000, "params": {"density": 0.7, "fog": 0.3}}}
kadrctl run transition.set --project_id prj_e21b467917e3 --segment_id seg_3ccd6c9e2cbe --type tide_wipe --duration_us 0.8s --direction left --softness 0.3
kadrctl --% run effect.add --project_id prj_e21b467917e3 --effect_id rain_glass --at_us 3s --duration_us 3s --params "{\"density\":0.7,\"fog\":0.3}"

Fonts: catalogue, install, import

library.list with kind: "font" lists the fonts that are ready to use. Category tabs say where a font comes from — Built-in (4 Go fonts, identical everywhere), Downloaded (installed through Kadr), Bundled (shipped next to the app), System (installed in the OS) — and its style: Sans, Serif, Display, Handwriting, Monospace, Pixel, Symbol. params has source, styles, cyrillic, ukrainian (Ґ Є І Ї) and variable.

More fonts come from font.catalog: 146 free SIL-OFL families from the google/fonts repository, 123 of them with Cyrillic, each with a note on its look and best use. The catalogue is read-only and offline; font.install downloads a family into <DataDir>/fonts/<id>/, after which its id works in text.update font.

  1. Pick a family

    {"name": "font_catalog", "arguments": {"category": "handwriting", "cyrillic": true}}
    kadrctl run font.catalog --category handwriting --cyrillic
    13 of 146 families
caveat        Caveat        Natural quick handwriting with Cyrillic; notes, annotations and vlogs.   394 KB  installed: false
marck_script  Marck Script  Casual flowing script with Cyrillic; greetings and personal stories.      82 KB
bad_script    Bad Script    Thin lively handwriting with Cyrillic; diaries and travel notes.          180 KB

  2. Install it

    The download runs in the background and reports font.progress events, then fonts.changed. With wait: true the call returns when the font is ready. Without internet it fails with not_available; an already installed family returns already_installed: true.

    {"name": "font_install", "arguments": {"id": "caveat", "wait": true}}
    kadrctl run font.install --id caveat --wait

  3. Use it

    {"name": "text_update", "arguments": {"project_id": "prj_e21b467917e3", "segment_id": "seg_c39f3546d148", "font": "caveat"}}
    kadrctl run text.update --project_id prj_e21b467917e3 --segment_id seg_c39f3546d148 --font caveat
  • An id from the catalogue is not usable until it is installed. text.update with an unknown font fails with not_found and a hint to call font.catalog / font.install. Check installed in the catalogue first.
  • Fonts travel with the computer, not the project. A project (or a My kit text preset) that names a font this machine lacks renders with Go Sans. Catalogue fonts are reproducible — one font.install on the other machine; sys_* fonts depend on that OS.
  • font.import {path} installs a local .ttf/.otf/.ttc (the family name becomes the id); font.remove deletes only fonts installed through Kadr; font.rescan picks up fonts copied into font folders while Kadr runs.
  • For Ukrainian text prefer fonts with ukrainian: true; missing letters are borrowed from a system font, which works but may not match.
  • GET /api/v1/fonts/{id}/preview?text=&h=&color= returns a transparent PNG of sample text in that font.

Word-art fields of TextStyle

Beyond fill, stroke, shadow, box, glow, gradient, 3D extrude and curve, a text style has optional word-art fields (absent or zero = off). text.add accepts them inside style; text.update has flat parameters for each (pattern_type, bevel_depth, sparkle_amount…); text.apply_effect sets them from a word-art preset.

FieldWhat it does
fill.stopsPositions 0–1 of up to 8 gradient colours; equal neighbours make a hard edge (chrome horizon).
stroke_fillGradient along the outline {type, colors, angle}.
pattern{type, colors, scale, angle, opacity, speed} — 28 types: stripes, pinstripe, checker, gingham, plaid, dots, halftone, hearts, stars, grain, static, scanlines, brushed, foil, carbon, glitter, holo, rainbow, aurora, flow, galaxy, marble, wood, camo, leopard, zebra, frost, grid.
bevel{depth, angle, strength, gloss, highlight, shade, round} — embossed or puffy lighting.
inner_shadow, inner_glowShadow or light inside the letters (inner_glow: {color, intensity, radius}).
echo{colors (1–6), distance, angle, hollow} — stacked offset copies behind the text.
distress{type: grunge|chalk|stamp|spray|scratch|worn, amount, scale}.
sparkle, dripStar glints {color, amount, size, speed}; paint drips {amount, length}.
rough, pixelate0–1: hand-made wobble; blocky pixel art.
box extrasfill (gradient), border, shadow, per_line, skew, pad, knockout (letters cut out of the box).
highlight.text_colorLetter colour of the spoken caption word for box-like highlight styles.

  "size": 26, "bold": true, "color": "#FFD84D",
  "stroke": {"color": "#FFFFFF", "width": 0.25},
  "stroke_fill": {"type": "linear", "colors": ["#FFFFFF", "#FF3D7F"], "angle": -90},
  "pattern": {"type": "glitter", "speed": 0.6},
  "bevel": {"depth": 0.35, "angle": 135, "gloss": 0.6, "round": true},
  "echo": {"colors": ["#FF3D7F", "#7B2FF7"], "distance": 0.25, "angle": -45},
  "sparkle": {"amount": 0.4, "speed": 1.5}}}}
{"name": "text_update", "arguments": {"project_id": "prj_e21b467917e3", "segment_id": "seg_c39f3546d148", "distress_type": "worn", "distress_amount": 0.3, "inner_shadow_opacity": 0.5}}

A pattern with speed > 0 or sparkles with speed > 0 make the text animate by itself, so a single preview.frame shows only one moment of it.

Animated stickers

Stickers whose library item has params.loop_anim (plus optional params.in_anim and params.loop_us) are animated — the 73 in the Animated tab. sticker.add applies those animations automatically, exactly as animation.set would; pass animate: false to place the sticker still. Change them later with animation.set / animation.remove.

{"name": "sticker_add", "arguments": {"project_id": "prj_e21b467917e3", "sticker_id": "emoji_grin", "at_us": 0}}
kadrctl run sticker.add --project_id prj_e21b467917e3 --sticker_id emoji_grin --at_us 0
segment.animations: {"in": {"id": "in_pop", "duration_us": 500000}, "loop": {"id": "loop_jelly", "duration_us": 1200000}}

Generated media

media.generate draws backgrounds and overlays locally — 22 kinds, 98 presets (library.list kind=generated). The newer kinds:

KindsWhat they make
mesh, aurora, lava, plasma, bokeh, particlesMoving backgrounds that loop seamlessly every loop seconds (also their default length), so copies can be placed back to back.
light_leak, film_dustLight leaks, film burns, prism streaks, lens flares and old-film dirt drawn on black — put them on an overlay track and set segment.set_blend mode: "screen".
texture, patternPaper, kraft, grunge, concrete, canvas, denim, marble, watercolour, wood; memphis, waves, dots, halftone, terrazzo, chevron, honeycomb, gingham, scales, cubes, triangles.
timerStyled countdowns: flip clock, neon ring, progress bar, dots, pop bursts (optional beeps).
banner, frameTransparent PNGs for an overlay track: text-free lower thirds, pills, ribbons, glass panels, news bars, brush strokes; film, neon, instant photo, vignette, torn paper, viewfinder and other borders.
 
{"name": "media_generate", "arguments": {"project_id": "prj_e21b467917e3", "preset_id": "leak_warm", "add_to_timeline": true, "new_track": true, "at_us": 0, "duration_us": 3000000}}
{"name": "segment_set_blend", "arguments": {"project_id": "prj_e21b467917e3", "segment_id": "seg_978c06ee7ef6", "mode": "screen"}}
kadrctl run media.generate --project_id prj_e21b467917e3 --preset_id leak_warm --add_to_timeline --new_track --at_us 0 --duration_us 3s
kadrctl run segment.set_blend --project_id prj_e21b467917e3 --segment_id seg_978c06ee7ef6 --mode screen

The full parameter list of every kind is in the description of media.generate.
