Projects commands

8 commands in the Projects category. Each one works the same from the editor UI, REST, MCP and kadrctl.

project.create

Create project

Ctrl+NNo undo stepHome › Create projectMCP project_create

Creates a new empty project, exactly like pressing "Create project" on the Home screen. Defaults match CapCut: 16:9 canvas at 1920x1080, 30 fps, black background, main-track magnet, auto snapping and linkage enabled. If name is omitted the project is named after today's date (MMDD).

Parameters

ParameterTypeDescription
fpsnumberProject frame rate used for the timeline grid and export default. Unit: frames per second.
Default 30Range 1 … 120
namestringProject name shown on the Home screen and in the editor title bar.
ratiostringCanvas aspect ratio. 9:16 is vertical (TikTok/Reels/Shorts), 16:9 is landscape (YouTube), 1:1 is square.
One of 16:9 9:16 1:1 4:3 3:4 21:9 2.35:1 2:1 1.85:1 5.8-inchDefault "16:9"

Returns

The full project object, including its new id.

Examples

Vertical video for TikTok

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.create \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"name":"My TikTok","ratio":"9:16"}'
kadrctl run project.create --name 'My TikTok' --ratio 9:16
// MCP tool: project_create
{
  "name": "My TikTok",
  "ratio": "9:16"
}

project.delete

Delete project

No undo stepHome › Project menu › DeleteMCP project_delete

Permanently deletes a project and its undo history. Imported media files on disk are NOT deleted. This cannot be undone. Same as Delete in the Home screen context menu.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{deleted: true, project_id}.

Examples

Delete

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.delete \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run project.delete --project_id prj_1a2b3c4d5e6f
// MCP tool: project_delete
{
  "project_id": "prj_1a2b3c4d5e6f"
}

project.duplicate

Duplicate project

No undo stepHome › Project menu › DuplicateMCP project_duplicate

Creates an independent copy of a project with a new id. The copy is named "<name> copy" unless a name is given. Media files are referenced, not copied. Same as Duplicate in the Home screen context menu.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
namestringName for the copy. Defaults to "<original name> copy".

Returns

The full new project object.

Examples

Duplicate

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.duplicate \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run project.duplicate --project_id prj_1a2b3c4d5e6f
// MCP tool: project_duplicate
{
  "project_id": "prj_1a2b3c4d5e6f"
}

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

The full project object.

Examples

Read a project

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.get \

project.list

List projects

No undo stepHome › ProjectsMCP project_list

Returns every project in the local project library, most recently modified first — the same list shown on the Home screen. Each item contains the project id, name, canvas ratio and size, total duration and timestamps. Use the returned id as project_id for every other project command.

Parameters

ParameterTypeDescription
querystringOptional case-insensitive filter on the project name (same as the Home screen search box).

Returns

Array of project summaries: {id, name, ratio, width, height, duration_us, created_at, modified_at}.

Examples

List all projects

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.list \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run project.list
// MCP tool: project_list
{}

project.rename

Rename project

No undo stepHome › Project menu › RenameMCP project_rename

Changes the project name. Same as editing the name in the editor title bar or choosing Rename from a project's context menu on the Home screen. Renaming is not recorded in undo history (like CapCut).

Parameters

ParameterTypeDescription
namerequiredstringNew project name. Leading/trailing spaces are removed; must not be empty.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

The project summary after renaming.

Examples

Rename

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.rename \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"name":"Travel vlog","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run project.rename --name 'Travel vlog' --project_id prj_1a2b3c4d5e6f
// MCP tool: project_rename
{
  "name": "Travel vlog",
  "project_id": "prj_1a2b3c4d5e6f"
}

project.set_canvas

Set canvas

UndoablePlayer › RatioMCP project_set_canvas

Changes the canvas (output frame) settings — the Ratio menu under the player and the canvas options in the inspector when nothing is selected. Changing the ratio recomputes width/height with the short side at 1080 px; existing clips keep their relative position and scale. Only the supplied fields change.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
background_blurnumberBlur strength 0..1 used when background_type is blur.
Range 0 … 1
background_colorstringHex color like "#000000" used when background_type is color.
background_typestringHow empty canvas areas are filled: a solid color, a blurred copy of the clip, or an image.
One of color blur image
fpsnumberNew project frame rate. Unit: frames per second.
Range 1 … 120
ratiostringNew aspect ratio.
One of 16:9 9:16 1:1 4:3 3:4 21:9 2.35:1 2:1 1.85:1 5.8-inch

Returns

The updated canvas object.

Examples

Switch to vertical

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.set_canvas \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","ratio":"9:16"}'
kadrctl run project.set_canvas --project_id prj_1a2b3c4d5e6f --ratio 9:16
// MCP tool: project_set_canvas
{
  "project_id": "prj_1a2b3c4d5e6f",
  "ratio": "9:16"
}

project.set_cover

Set cover

UndoableTimeline › Main track › CoverMCP project_set_cover

Chooses the project's cover (thumbnail) frame — the Cover button at the start of the main track in CapCut. time_us is a TIMELINE time; the cover is the composited frame at that time (render it with GET /api/v1/projects/{id}/frame?t_us=<cover_us> or preview.frame). It must lie inside the project (0 ≤ time_us < project duration); an empty project has no frames and returns conflict. clear=true removes the choice so the first frame is used again. The value is stored in project.cover_us (null = first frame) and is one undo step. Moving or trimming clips later does not move the cover time.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
clearbooleantrue = forget the chosen cover and use the first frame (time_us is ignored).
time_usintegerTimeline time of the cover frame in microseconds (1 s = 1000000). Required unless clear is true. Unit: microseconds.
Range 0 … ∞

Returns

{cover_us: chosen time or null (first frame), duration_us: project duration}.

Examples

Use the frame at 2.5 s as the cover

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.set_cover \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","time_us":2500000}'
kadrctl run project.set_cover --project_id prj_1a2b3c4d5e6f --time_us 2.5s
// MCP tool: project_set_cover
{
  "project_id": "prj_1a2b3c4d5e6f",
  "time_us": 2500000
}

Back to the first frame

curl -X POST http://127.0.0.1:7777/api/v1/commands/project.set_cover \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"clear":true,"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run project.set_cover --clear --project_id prj_1a2b3c4d5e6f
// MCP tool: project_set_cover
{
  "clear": true,
  "project_id": "prj_1a2b3c4d5e6f"
}
