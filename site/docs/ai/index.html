For AI agents

Kadr for AI agents

Kadr is a CapCut-style desktop video editor in which every button, slider and menu item is a documented command. An AI agent runs the same 170+ commands over MCP, a local REST API or the kadrctl CLI — and a human sees every edit appear live in the editor window, with one shared undo history.

Quick start: Claude CodeOne command connects Kadr; first prompts to try. Claude DesktopA four-line config snippet. RecipesTen end-to-end workflows, every call verified against a real engine. Command referenceEvery command with parameters, units, defaults and examples.

Three ways in

All three reach the same engine — the open editor (Kadr.exe) or the headless kadr-server.exe — at http://127.0.0.1:7777, and run exactly the same commands.

InterfaceBest forHow it names commands
MCP (kadr-mcp.exe)Claude Code, Claude Desktop and other agent apps. Starts the engine by itself if Kadr is not running; returns frames as images.Dots become underscores: timeline_segment_split; plus kadr_batch
RESTYour own scripts and services in any language; WebSocket events.POST /api/v1/commands/timeline.segment.split
CLI (kadrctl.exe)Terminals, shell scripts, quick checks; accepts times like 2.5s.kadrctl run timeline.segment.split --at_us 2.5s …

Mental model

project          prj_…   canvas, settings, playhead
├─ materials[]   mat_…   imported or generated files (photos: duration 0)
├─ tracks[]      trk_…   tracks[0] is drawn first, at the bottom
│  ├─ main_video         magnetic: clips sit back to back, no gaps
│  ├─ video_overlay · text · sticker · effect · filter · adjustment
│  └─ audio
│     └─ segments[]  seg_…  timeline range + source range in a material
└─ markers[]     mrk_…
  • Time is integer microseconds everywhere: 1 s = 1000000. Parameters that hold time end in _us.
  • Ids are opaque strings with a type prefix (prj_, trk_, seg_, mat_, exp_…). Read them from results; never invent them.
  • Commands are either project-scoped (they take project_id, are saved and are undoable) or global (projects list, library, export jobs, settings).
  • Every edit is undoable with edit.undo; a batch of edits is one undo step; edits from the UI and from agents share the history.

The full rules — magnet, linked clips, transitions, keyframes, coordinates, units — are in Concepts.

The first five calls

A complete edit: create a vertical project, generate a background, add a title, look at it, export. Each tab shows the same calls; the MCP tab is what an agent sends.

{"name": "project_create", "arguments": {"name": "My first video", "ratio": "9:16"}}
{"name": "media_generate", "arguments": {"project_id": "prj_74f3bf737c17", "preset_id": "sunset_gradient", "duration_us": 5000000, "add_to_timeline": true}}
{"name": "text_add", "arguments": {"project_id": "prj_74f3bf737c17", "text": "Hello from an agent", "template_id": "title_bold", "at_us": 0, "duration_us": 3000000}}
{"name": "preview_frame", "arguments": {"project_id": "prj_74f3bf737c17", "time_us": 1000000, "width": 540}}
{"name": "export_start", "arguments": {"project_id": "prj_74f3bf737c17", "resolution": "1080p"}}
kadrctl run project.create --name "My first video" --ratio 9:16
kadrctl run media.generate --project_id prj_74f3bf737c17 --preset_id sunset_gradient --duration_us 5s --add_to_timeline
kadrctl run text.add --project_id prj_74f3bf737c17 --text "Hello from an agent" --template_id title_bold --at_us 0 --duration_us 3s
kadrctl run preview.frame --project_id prj_74f3bf737c17 --time_us 1s --width 540
kadrctl run export.start --project_id prj_74f3bf737c17 --resolution 1080p
curl -s http://127.0.0.1:7777/api/v1/commands/project.create -H "Authorization: Bearer $KADR_TOKEN" -d '{"name":"My first video","ratio":"9:16"}'
curl -s http://127.0.0.1:7777/api/v1/commands/media.generate -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","preset_id":"sunset_gradient","duration_us":5000000,"add_to_timeline":true}'
curl -s http://127.0.0.1:7777/api/v1/commands/text.add -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","text":"Hello from an agent","template_id":"title_bold","at_us":0,"duration_us":3000000}'
curl -s http://127.0.0.1:7777/api/v1/commands/preview.frame -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","time_us":1000000,"width":540}'
curl -s http://127.0.0.1:7777/api/v1/commands/export.start -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_74f3bf737c17","resolution":"1080p"}'

The export runs in the background; export.status with the returned job_id reports progress until state is done. Without path, videos go to %USERPROFILE%\Videos\Kadr.

Safety and privacy

  • Local only. The API listens on 127.0.0.1; requests addressed to any other host name get 403 forbidden (DNS-rebinding protection), and browsers may only connect from local origins.
  • Token. Every request except health and documentation needs the token from %APPDATA%\Kadr\api-token. kadr-mcp and kadrctl read it themselves. Treat it like a password: it gives full control over your projects.
  • Everything is undoable — except deleting a whole project, which MCP marks as destructive so clients ask first. Imported media files are never modified or deleted.
  • Nothing is uploaded by Kadr. Commands read and write files on your PC at paths you give. The only network traffic is optional: ElevenLabs voices (the text you synthesise), update checks, and the one-time FFmpeg download. Frames and data reach your AI provider only when the agent asks for them through tools you allow.
