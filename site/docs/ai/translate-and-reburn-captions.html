Translate and re-burn captions

You get your captioned video in another language: a copy of the project with translated captions burned in, plus .srt files in both languages for YouTube or a player. Claude does the translation; Kadr keeps every caption on its original timing. The English page translates into Spanish — ask for any language Claude knows.

  • Time: ~2 min
  • You need: A Kadr project with captions (for example from the talking-head recipe)
  • Main commands: captions.list, project.duplicate, captions.update, captions.set_style, captions.export, captions.import, export.start

Ask Claude

My Kadr project "Tips short" has English captions. Make a Spanish version: duplicate the project as "Tips short (ES)", translate every caption cue into natural, informal Spanish (keep each cue about as long as the original so the timing still works) and write the translations into the copy in one batch. Switch the copy's captions to the cap_yellow_outline style. Export both caption tracks as SRT files next to the video, check one frame to make sure accents like ñ and ¡ render, then export the Spanish video at 1080p to C:\Users\you\Videos\Kadr\tips-short-es.mp4.

Step by step

Each step shows the same calls twice. The kadrctl tab is for PowerShell: a line that starts with kadrctl --% passes JSON, and without --% the same line also works in Command Prompt. The MCP tab is the tool call an agent sends — the tool name and its arguments. Ids such as prj_…, mat_… and seg_… come from the results of earlier steps, so yours will differ. Paths under C:/Users/you are examples.

  1. Read the captions

    captions.list returns every cue with its id, time and text. include_words false leaves out the per-word timing to keep the answer small.

  2. Work on a copy

    project.duplicate copies the project with the same cue ids, so the list from step 1 still applies. The original is not touched.

    kadrctl run project.duplicate --project_id prj_ed95831b1bf0 --name "Tips short (ES)"

  4. Give the new version its own look

    captions.set_style changes the look of every cue and keeps the text and timing.

    kadrctl run captions.set_style --project_id prj_0ae446772d4b --style_id cap_yellow_outline
    {"name": "captions_set_style", "arguments": {"project_id": "prj_0ae446772d4b", "style_id": "cap_yellow_outline"}}

  5. Export subtitle files

    captions.export writes SRT, VTT, TXT or LRC; missing folders are created. Without path the text comes back in content instead.

    kadrctl run captions.export --project_id prj_0ae446772d4b --format srt --path C:/Users/you/Videos/Kadr/tips-short-es.srt
kadrctl run captions.export --project_id prj_ed95831b1bf0 --format srt --path C:/Users/you/Videos/Kadr/tips-short-en.srt
    {"name": "captions_export", "arguments": {"project_id": "prj_0ae446772d4b", "format": "srt", "path": "C:/Users/you/Videos/Kadr/tips-short-es.srt"}}
{"name": "captions_export", "arguments": {"project_id": "prj_ed95831b1bf0", "format": "srt", "path": "C:/Users/you/Videos/Kadr/tips-short-en.srt"}}

  6. Check the characters, then export

    Kadr falls back to a system font for any character the caption font lacks, so accents, Cyrillic and CJK all render. One frame confirms it:

    kadrctl run preview.frame --project_id prj_0ae446772d4b --time_us 2s --width 540
kadrctl run export.start --project_id prj_0ae446772d4b --resolution 1080p --path C:/Users/you/Videos/Kadr/tips-short-es.mp4

  7. Optional: both languages on screen

    Import the translated SRT into the original project as a second caption track in another style. replace false keeps the English track and adds a new one.

    kadrctl run captions.import --project_id prj_ed95831b1bf0 --path C:/Users/you/Videos/Kadr/tips-short-es.srt --style_id cap_box_dark --replace false
    {"name": "captions_import", "arguments": {"project_id": "prj_ed95831b1bf0", "path": "C:/Users/you/Videos/Kadr/tips-short-es.srt", "style_id": "cap_box_dark", "replace": false}}

More ideas

  • Subtitles only. Skip the burned-in export and upload the SRT files; YouTube shows them as selectable subtitles.
  • Re-split long translations. If translated lines get long, run captions.relayout on the copy with max_words 3 or max_chars 24. Cues are regrouped from their word timings.
  • A script from the captions. captions.export with format txt and no path returns the plain text — ask Claude to turn it into a blog post or a video description.
  • No captions yet? Run captions.auto first; Whisper recognises about 100 languages.

Tips

  • Ask Claude to keep each translated cue roughly as long as the original: captions that suddenly need three lines are hard to read.
  • captions.shift nudges every cue earlier or later if the subtitles feel a few frames off.
  • Several languages: repeat steps 2–6 per language; each copy is independent.
