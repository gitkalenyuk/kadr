Будь-який клієнт, що вміє запускати локальний stdio MCP-сервер, може керувати Kadr. Сервер — це один виконуваний файл без аргументів; усе інше необов’язкове.

Налаштування, потрібні будь-якому клієнту

ПараметрЗначення
Транспортstdio
КомандаПовний шлях до kadr-mcp.exe (або kadr-mcp, якщо він у PATH), без аргументів
СередовищеНеобов’язково: KADR_ADDR, KADR_DATA_DIR, KADR_TOKEN
Версія протоколу2025-06-18
Інструменти178: по одному на команду плюс kadr_batch; команди лише для читання мають readOnlyHint, project_delete — destructiveHint

Якщо рушій не запущено, kadr-mcp запускає kadr-server.exe зі своєї папки й чекає на нього до 10 секунд. Токен API він читає з папки даних Kadr, тож жодних секретів у конфігурації клієнта.

Фрагменти конфігурації

Імена файлів і структура нижче — такі, як у цих клієнтах на момент написання; якщо ключ змінився, звірте з документацією свого клієнта. Коментарі — для орієнтації; приберіть їх, якщо клієнт не приймає коментарів у JSON.

// %USERPROFILE%\.cursor\mcp.json (all projects) or .cursor\mcp.json (one project)
{
  "mcpServers": {
    "kadr": { "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe" }
  }
}
// .vscode\mcp.json (VS Code agent mode)
{
  "servers": {
    "kadr": { "type": "stdio", "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe" }
  }
}
// %USERPROFILE%\.codeium\windsurf\mcp_config.json
{
  "mcpServers": {
    "kadr": { "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe" }
  }
}
# %USERPROFILE%\.codex\config.toml (Codex CLI)
[mcp_servers.kadr]
command = 'C:\Users\you\AppData\Local\Programs\Kadr\kadr-mcp.exe'
// %USERPROFILE%\.gemini\settings.json (Gemini CLI)
{
  "mcpServers": {
    "kadr": { "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe" }
  }
}

Перевірка мосту вручну

MCP через stdio — це одне JSON-RPC повідомлення на рядок, тож PowerShell може говорити з мостом напряму. Це корисно, коли клієнт пише лише «failed to start»:

@'
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"test","version":"1"}}}
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"project_list","arguments":{}}}
'@ | & "$env:LOCALAPPDATA\Programs\Kadr\kadr-mcp.exe"

Другий рядок виводу — результат project_list. Помилки повертаються як результати інструментів з "isError": true і JSON-помилкою рушія (code, message, hint, field), тож агент може прочитати підказку й повторити.

Агенти без MCP

  • Function calling. Згенеруйте описи інструментів з openapi.json (тіло запиту кожної команди — JSON Schema) і виконуйте виклики через POST /api/v1/commands/<name> — див. REST API.
  • Агенти лише з оболонкою. Нехай агент читає документацію через kadrctl describe <command> і виконує команди через kadrctl run — див. kadrctl.
  • Контекст. Дайте моделі llms.txt або повний llms-full.txt.

Kadr на іншому комп’ютері

API навмисно приймає лише запити, адресовані localhost. Щоб керувати Kadr на іншому ПК, прокиньте до нього локальний порт (наприклад, ssh -L 7777:127.0.0.1:7777 user@editing-pc), скопіюйте api-token того ПК у KADR_TOKEN і пам’ятайте, що шляхи до файлів стосуються віддаленого диска.
