Claude Desktop сам запускає kadr-mcp.exe і показує інструменти Kadr у кожному чаті. Потрібен лише один запис у JSON-файлі та перезапуск.

  1. Відкрийте файл конфігурації

    У Claude Desktop відкрийте Settings → Developer → Edit Config. Відкриється claude_desktop_config.json — зазвичай %APPDATA%\Claude\claude_desktop_config.json. Якщо файлу немає, створіть його.

  2. Додайте Kadr

    Вставте це, підставивши своє ім’я користувача в шлях (розділ Налаштування → API & automation у Kadr показує точний фрагмент для вашого ПК). У JSON кожна зворотна коса риска пишеться двічі.

    {
  "mcpServers": {
    "kadr": {
      "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe"
    }
  }
}

    Якщо у файлі вже є розділ mcpServers, додайте всередину лише запис "kadr": { … }, відокремивши його від сусідів комою.

  3. Повністю перезапустіть Claude Desktop

    Закрити вікно замало: клацніть правою кнопкою іконку Claude в області сповіщень, виберіть Quit і знову запустіть Claude Desktop. Якщо хочете бачити правки, спершу відкрийте Kadr.

  4. Перевірте, що все працює

    Інструменти Kadr тепер є в меню інструментів чату. Почніть новий чат і попросіть:

    Покажи мої проєкти в Kadr.

    Claude викличе project_list і відповість. Потім спробуйте правку й дивіться в редактор:

    Створи в Kadr проєкт 9:16 «Desktop test», відкрий його у вікні Kadr, згенеруй 4-секундне тло sunset_gradient, додай титр «Привіт» шаблоном title_bold і покажи кадр на першій секунді.

Що отримує Claude

  • По інструменту на кожну команду Kadr (timeline_segment_split для timeline.segment.split) з повним описом, одиницями параметрів і прикладами, плюс kadr_batch для атомарних багатокрокових правок. Див. Інструменти MCP.
  • Інструкції сервера з основами: проєкти → доріжки → сегменти, мікросекунди, спершу читати стан, правки пакетами, дивитися на кадри.
  • Зображення: preview_frame і preview_contact_sheet повертають вміст-зображення, тож Claude справді бачить результат своєї правки.

Інший порт або папка даних

Типово міст звертається до 127.0.0.1:7777 і читає токен із %APPDATA%\Kadr. Для окремого рушія додайте блок env:

{
  "mcpServers": {
    "kadr": {
      "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe",
      "env": {
        "KADR_ADDR": "127.0.0.1:7790",
        "KADR_DATA_DIR": "D:\\kadr-automation"
      }
    }
  }
}

Замість KADR_DATA_DIR можна задати KADR_TOKEN.

«Server disconnected» або сервер не стартуєНеправильний шлях до kadr-mcp.exe.Візьміть повний шлях із Налаштування → API & automation у Kadr. Журнал сервера — у %APPDATA%\Claude\logs\ (mcp-server-kadr.log).
Kadr engine did not start … within 10 sПоруч із kadr-mcp.exe немає kadr-server.exe або його заблоковано.Запустіть Kadr самі й повторіть запит.
Правки не з’являються у відкритому вікні KadrМіст запустив «безголовий» kadr-server.exe ще до відкриття Kadr; порт 7777 зайнятий ним.Завершіть kadr-server.exe у Диспетчері завдань, лишіть Kadr відкритим, перезапустіть Claude Desktop.
