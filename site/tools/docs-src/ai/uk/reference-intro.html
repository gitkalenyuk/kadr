Що містить кожен запис

  • Назва й заголовок — назва команди з крапками (timeline.segment.split), назва інструмента MCP (timeline_segment_split) і короткий заголовок.
  • Опис — що робить команда, як вона відтворює поведінку CapCut, граничні випадки та помилки, які може повернути.
  • Параметри — назва, тип, обов’язковість, типове значення, допустимі значення чи діапазон і одиниця. Кожен параметр *_us — ціле число мікросекунд.
  • Результат — структура відповіді.
  • Позначки — скасовується чи лише читає, проєктна чи глобальна, місце в інтерфейсі й гаряча клавіша.
  • Приклади — готові JSON-аргументи, кожен перевірено за схемою параметрів.

Як читати назви команд

Частина до першої крапки — простір імен, тобто об’єкт, з яким працює команда: project., media., timeline. (кліпи, доріжки, маркери), segment. (властивості одного кліпу), keyframe., animation., text., captions., transcript., audio., tts., sfx., effect., filter., adjustment., transition., library., preview., playback., export., ai. (розумні інструменти), presets., edit., clipboard., ui., tools., update., app.. Дієслова послідовні: add створює новий сегмент, apply змінює наявний кліп, set/set_* замінює значення, get/list лише читають.
