Кожна команда Kadr доступна через HTTP на вашому ПК. Надішліть POST із JSON-об’єктом аргументів на /api/v1/commands/<name> — і отримаєте рівно те, що отримують кнопки редактора.

Базова адреса

http://127.0.0.1:7777/api/v1

Її обслуговують і редактор (Kadr.exe), і «безголовий» kadr-server.exe. Щоб змінити адресу, задайте KADR_ADDR (наприклад, 127.0.0.1:7790) до запуску Kadr. Без токена доступні GET /api/v1/health → {"ok":true,"result":{"status":"ok","version":"…"}}, GET /api/v1/openapi.json і HTML-довідник GET /docs.

Автентифікація

Усе інше потребує токена API, що створюється під час першого запуску й зберігається в %APPDATA%\Kadr\api-token (Kadr показує шлях у Налаштування → API & automation). Надсилайте його як bearer-токен: Authorization: Bearer <token>.

$env:KADR_TOKEN = (Get-Content "$env:APPDATA\Kadr\api-token" -Raw).Trim()
set /p KADR_TOKEN=<"%APPDATA%\Kadr\api-token"
export KADR_TOKEN=$(cat "$APPDATA/Kadr/api-token")

Браузери не можуть ставити заголовки для запитів <img>, <audio> чи WebSocket, тож там можна передати ?token=<token>. KADR_TOKEN, заданий до запуску Kadr, має пріоритет над файлом; щоб змінити токен, закрийте Kadr, видаліть api-token і запустіть Kadr знову.

Виклик команди

POST /api/v1/commands/{name} із JSON-об’єктом аргументів (порожнє тіло — без аргументів). Назви однакові всюди — у довіднику, у kadrctl і в MCP (з підкресленнями).

curl -s http://127.0.0.1:7777/api/v1/commands/text.add -H "Authorization: Bearer $KADR_TOKEN" -d '{"project_id":"prj_a049124a748a","text":"Day one","template_id":"title_bold","at_us":0,"duration_us":2000000}'
kadrctl run text.add --project_id prj_a049124a748a --text "Day one" --template_id title_bold --at_us 0 --duration_us 2s
{"name": "text_add", "arguments": {"project_id": "prj_a049124a748a", "text": "Day one", "template_id": "title_bold", "at_us": 0, "duration_us": 2000000}}

У PowerShell Invoke-RestMethod одразу перетворює відповідь на об’єкти. Лишайте charset=utf-8 у типі вмісту — без нього Windows PowerShell 5.1 псує неанглійський текст.

function Invoke-Kadr($Command, $Arguments = @{}) {
  $body = $Arguments | ConvertTo-Json -Depth 10 -Compress
  $r = Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:7777/api/v1/commands/$Command" `
    -Headers @{ Authorization = "Bearer $env:KADR_TOKEN" } `
    -ContentType 'application/json; charset=utf-8' -Body $body
  $r.result
}

$p = Invoke-Kadr project.create @{ name = 'Подорож'; ratio = '9:16' }
Invoke-Kadr timeline.get @{ project_id = $p.id }

У Windows PowerShell 5.1 curl — це псевдонім Invoke-WebRequest; викликайте curl.exe повним ім’ям або користуйтеся Invoke-RestMethod.

Конверт відповіді

Кожна відповідь — JSON. Успіх:

{ "ok": true, "result": { … результат команди … } }

Помилка — message пояснює, що пішло не так, hint — як виправити виклик, field — який параметр винен (якщо є):

{
  "ok": false,
  "error": {
    "code": "invalid_argument",
    "message": "parameter \"ratio\": must be one of [16:9 9:16 1:1 4:3 3:4 21:9 2.35:1 2:1 1.85:1 5.8-inch]",
    "hint": "Canvas aspect ratio. 9:16 is vertical (TikTok/Reels/Shorts), 16:9 is landscape (YouTube), 1:1 is square.",
    "field": "ratio"
  }
}

Час — у мікросекундах

Будь-який час і тривалість — ціле число мікросекунд, а такі параметри закінчуються на _us: один кадр при 30 fps = 33333, 0,5 с = 500000, 1 хв 30 с = 90000000. REST приймає лише цілі числа; kadrctl розуміє ще й 2.5s, 1500ms і 00:01:02.5. Інші одиниці вказано в описі кожного параметра (децибели, непрозорість 0–1, частки полотна…).

Пакети й пробні запуски

POST /api/v1/projects/{id}/batch виконує кілька проєктних команд як одну атомарну правку й один крок скасування («Batch (N actions)»). Якщо виклик падає, нічого не зберігається. З "dry_run": true кожен виклик виконується на копії й ви бачите результати, але нічого не зберігається. project_id підставляється в кожен виклик.

[
  {"command": "segment.set_background", "args": {"segment_id": "seg_a049124a748b", "type": "blur", "blur": 0.75}},
  {"command": "text.add", "args": {"text": "День перший", "at_us": 0, "duration_us": 2000000}}
]
curl -s http://127.0.0.1:7777/api/v1/projects/prj_a049124a748a/batch -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"dry_run":false,"calls":[{"command":"segment.set_background","args":{"segment_id":"seg_a049124a748b","type":"blur","blur":0.75}},{"command":"text.add","args":{"text":"День перший","at_us":0,"duration_us":2000000}}]}'
kadrctl batch prj_a049124a748a demo.json --dry-run
kadrctl batch prj_a049124a748a demo.json
{"name": "kadr_batch", "arguments": {"project_id": "prj_a049124a748a", "calls": [
  {"command": "segment.set_background", "args": {"segment_id": "seg_a049124a748b", "type": "blur", "blur": 0.75}},
  {"command": "text.add", "args": {"text": "День перший", "at_us": 0, "duration_us": 2000000}}
]}}

Відповідь — {"ok": true, "result": {"results": [ … по одному на виклик … ], "dry_run": false}}. Виклики виконуються по черзі й бачать наслідки попередніх, але аргументи фіксуються заздалегідь, тож виклик не може використати id, створений раніше в тому самому пакеті. Пакетувати можна лише проєктні команди; глобальні команди та edit.undo/edit.redo відхиляються з invalid_argument («call 0: …», нумерація з 0).

Довгі завдання

Експорт, автосубтитри, транскрипція й видалення фону одразу повертають завдання і працюють у фоні. Опитуйте export.status, captions.status (з wait_s — довге опитування до 600 с) чи ai.jobs — або слухайте події нижче. Завдання живуть у пам’яті й забуваються після перезапуску Kadr.

Події WebSocket

Під’єднайтеся до ws://127.0.0.1:7777/api/v1/events?token=<token>, щоб отримувати JSON-повідомлення щоразу, коли щось стається — у редакторі, через API, з CLI чи від агента. Додайте &project_id=prj_…, щоб отримувати лише події цього проєкту (плюс події, що не належать жодному проєкту).

{
  "type": "project.changed",
  "project_id": "prj_1a347e3a7883",
  "source": "mcp",
  "data": { "commands": ["transition.apply_all"] },
  "time": "2026-10-01T16:47:42.9702474+02:00"
}

source — це ui, api, mcp чи cli, або модуль, що виконав фонову роботу (media, ai, tools, update).

Слухач на Node.js 22+ (вбудований WebSocket, без пакетів):

const token = require('fs').readFileSync(process.env.APPDATA + '/Kadr/api-token', 'utf8').trim();
const ws = new WebSocket('ws://127.0.0.1:7777/api/v1/events?token=' + token);
ws.onmessage = (m) => {
  const e = JSON.parse(m.data);
  if (e.type === 'export.progress') console.log(e.data.job_id, Math.round(e.data.progress * 100) + '%');
  else console.log(e.type, e.source, e.project_id || '');
};

Події повідомляють, що щось змінилося; новий стан читайте через timeline.get. Повільні клієнти втрачають події, а не гальмують редактор, тож після перепід’єднання перечитуйте стан.

Модель безпеки

  • Лише локально. Kadr слухає на 127.0.0.1; інші комп’ютери під’єднатися не можуть.
  • Перевірка хоста. Запити мають бути адресовані localhost, 127.0.0.1 або ::1; усе інше отримує 403 forbidden. Це блокує атаки DNS rebinding з вебсторінок.
  • Origin браузера. CORS і WebSocket приймаються лише з loopback-origin, і токен однаково потрібен.
  • Токен. Зберігається у вашому профілі; хто його має, той керує вашими проєктами. Ніколи не вставляйте його в запити до ШІ й не комітьте.
  • Ваші файли лишаються на місці. Команди читають і записують файли за вказаними шляхами на тому ПК, де працює Kadr.
