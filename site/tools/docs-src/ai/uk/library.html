Усе, що агент може додати до відео, — переходи, ефекти, фільтри, анімації, текстові стилі, стікери, згенеровані фони, шрифти, звуки — береться з вбудованої бібліотеки. Знаходьте ідентифікатори через library.list, дивіться на кандидатів через library.preview і лише тоді застосовуйте той, що пасує. Ніколи не вгадуйте id.

Поле preview і мініатюри

Кожен рухомий елемент має поле preview у результатах library.list і library.get — редактор використовує його для прев’ю під вказівником миші:

"preview": {"url": "/api/v1/library/transition/mix/preview", "frames": 24, "fps": 12, "width": 192, "height": 108}

GET на url (з токеном API) повертає JPEG-спрайт: frames плиток розміром width×height поруч, зліва направо, один безшовний цикл із частотою fps. Немає поля preview — елемент статичний. Кожен елемент має також шлях thumbnail (нерухомий PNG). Агентам зазвичай зручніший library.preview; спрайт — для вашого власного інтерфейсу. Спрайти кешуються в пам’яті та в <DataDir>/library/previews/.

Параметри: напрямок, м’якість і повзунки ефектів

Елемент-перехід перелічує, що він приймає: params.directions і default_direction, params.softness і default_softness. Передайте їх у transition.set (direction — куди рухається зміна кадру; softness 0–1). Елемент-ефект перелічує свої повзунки в params.schema ({id, label, min, max, default}); значення передавайте в params команд effect.add / effect.apply або пізніше через effect.set_params.

{"name": "effect_add", "arguments": {"project_id": "prj_e21b467917e3", "effect_id": "rain_glass", "at_us": 3000000, "duration_us": 3000000, "params": {"density": 0.7, "fog": 0.3}}}
kadrctl run transition.set --project_id prj_e21b467917e3 --segment_id seg_3ccd6c9e2cbe --type tide_wipe --duration_us 0.8s --direction left --softness 0.3

Шрифти: каталог, установлення, імпорт

library.list з kind: "font" перелічує шрифти, готові до роботи. Вкладки-категорії кажуть, звідки шрифт, — Built-in (4 шрифти Go, однакові всюди), Downloaded (установлені через Kadr), Bundled (постачаються поруч із застосунком), System (установлені в ОС) — і який у нього стиль: Sans, Serif, Display, Handwriting, Monospace, Pixel, Symbol. У params є source, styles, cyrillic, ukrainian (Ґ Є І Ї) і variable.

Додаткові шрифти — у font.catalog: 146 безкоштовних родин під ліцензією SIL OFL з репозиторію google/fonts, 123 з них із кирилицею, кожна з приміткою про вигляд і доречне застосування. Каталог лише для читання й працює офлайн; font.install завантажує родину в <DataDir>/fonts/<id>/, після чого її id працює в параметрі font команди text.update.

  1. Оберіть родину

    {"name": "font_catalog", "arguments": {"category": "handwriting", "cyrillic": true}}
    kadrctl run font.catalog --category handwriting --cyrillic
    13 of 146 families
caveat        Caveat        Natural quick handwriting with Cyrillic; notes, annotations and vlogs.   394 KB  installed: false
marck_script  Marck Script  Casual flowing script with Cyrillic; greetings and personal stories.      82 KB
bad_script    Bad Script    Thin lively handwriting with Cyrillic; diaries and travel notes.          180 KB

  2. Установіть її

    Завантаження йде у фоні й надсилає події font.progress, а потім fonts.changed. З wait: true виклик повертається, коли шрифт готовий. Без інтернету команда завершується помилкою not_available; для вже встановленої родини повертається already_installed: true.

    {"name": "font_install", "arguments": {"id": "caveat", "wait": true}}
    kadrctl run font.install --id caveat --wait

  3. Застосуйте її

    {"name": "text_update", "arguments": {"project_id": "prj_e21b467917e3", "segment_id": "seg_c39f3546d148", "font": "caveat"}}
    kadrctl run text.update --project_id prj_e21b467917e3 --segment_id seg_c39f3546d148 --font caveat
  • id з каталогу не працює, доки шрифт не встановлено. text.update з невідомим шрифтом повертає not_found із підказкою викликати font.catalog / font.install. Спершу перевірте installed у каталозі.
  • Шрифти належать комп’ютеру, а не проєкту. Проєкт (або текстовий пресет My kit), що посилається на відсутній на цій машині шрифт, рендериться шрифтом Go Sans. Шрифти з каталогу легко відтворити — один font.install на іншій машині; шрифти sys_* залежать від тамтешньої ОС.
  • font.import {path} установлює локальний .ttf/.otf/.ttc (назва родини стає id); font.remove видаляє лише шрифти, встановлені через Kadr; font.rescan підхоплює шрифти, скопійовані в теки шрифтів, поки Kadr працює.
  • Для українського тексту обирайте шрифти з ukrainian: true; відсутні літери позичаються в системного шрифту — це працює, але літери можуть не пасувати.
  • GET /api/v1/fonts/{id}/preview?text=&h=&color= повертає прозорий PNG зі зразком тексту цим шрифтом.
