Одна команда реєструє MCP-сервер Kadr у Claude Code для всіх проєктів на вашому ПК. Після цього просто опишіть потрібне відео — Claude змонтує його в Kadr, перевірить себе за відрендереними кадрами, а будь-яку зміну можна скасувати.

Перш ніж почати

  • Kadr встановлено. Інсталятор кладе kadr-mcp.exe у %LOCALAPPDATA%\Programs\Kadr\ поруч із Kadr.exe і kadr-server.exe. У Kadr розділ Налаштування → API & automation показує точний шлях і готову команду.
  • Claude Code встановлено, і claude запускається у вашому терміналі.
  • Kadr не обов’язково має бути запущений. Якщо ні редактор, ні сервер не відповідають, kadr-mcp сам запускає «безголовий» kadr-server.exe (приблизно за 2 секунди). Щоб бачити правки, відкрийте Kadr до першого виклику — див. примітку нижче.

1. Додайте сервер

Зареєструйте Kadr один раз для свого облікового запису (--scope user), щоб він був доступний у будь-якій папці. Усе після -- — це команда, яку запускає Claude Code.

claude mcp add --scope user kadr -- "%LOCALAPPDATA%\Programs\Kadr\kadr-mcp.exe"
claude mcp add --scope user kadr -- "$env:LOCALAPPDATA\Programs\Kadr\kadr-mcp.exe"

Якщо ви лишили в інсталяторі опцію Додати kadrctl і kadr-mcp до PATH, працює й коротка форма: claude mcp add --scope user kadr -- kadr-mcp.

2. Перевірте з’єднання

claude mcp list
claude mcp get kadr

kadr має бути в списку як під’єднаний. Усередині сесії /mcp показує сервер, його 178 інструментів (по одному на команду плюс kadr_batch) і дає змогу перепід’єднатися після збою.

3. Заздалегідь дозвольте інструменти (необов’язково)

Claude Code питає дозволу перед використанням інструмента. Щоб прибрати ці запити для Kadr, дозвольте весь сервер у .claude/settings.json (один проєкт) або ~/.claude/settings.json (усюди):

{
  "permissions": {
    "allow": ["mcp__kadr"]
  }
}

Хочете суворіше? Дозвольте лише інструменти читання, наприклад "mcp__kadr__project_list", "mcp__kadr__timeline_get", "mcp__kadr__preview_frame" і "mcp__kadr__preview_contact_sheet", а правки підтверджуйте по одній. Утім, будь-яку правку однаково можна скасувати.

4. Перші запити, які варто спробувати

Повніші сценарії з кожним викликом — у рецептах.

Щоб дивитися наживо, потрібен рушій редактора. Якщо під час першого виклику Claude Kadr був закритий, kadr-mcp запустив «безголовий» kadr-server.exe, і той працює й після завершення чату. Якщо потім відкрити Kadr, вікно не зможе зайняти порт 7777 і не показуватиме правок агента. Завершіть kadr-server.exe (Диспетчер завдань → Подробиці) перед відкриттям Kadr, а потім виконайте /mcp, щоб перепід’єднатися.

Спільне налаштування для репозиторію

Для папки, яка завжди працює з Kadr, закомітьте .mcp.json у її корінь. Claude Code один раз питає кожну людину, перш ніж завантажити сервер рівня проєкту. Якщо kadr-mcp є в PATH, файл однаковий для всіх:

{
  "mcpServers": {
    "kadr": { "type": "stdio", "command": "kadr-mcp", "args": [] }
  }
}

Кілька рядків у CLAUDE.md цієї папки позбавлять агента багатьох здогадок:

## Монтаж відео
- Монтуй через MCP-сервер kadr. Час — цілі мікросекунди (1 с = 1000000).
- Спершу читай стан (timeline_get), пов’язані правки застосовуй одним kadr_batch, потім перевіряй через preview_frame або preview_contact_sheet.
- Показуй роботу: на початку виклич ui_open_project; експортуй через export_start і опитуй export_status.
- Медіа лежать у ./footage; експорт — у ./exports.

Інший порт або папка даних

Щоб керувати окремим рушієм (наприклад, тестовим kadr-server.exe на порту 7790 із власними проєктами), передайте змінні середовища під час додавання сервера:

claude mcp add --scope user --env KADR_ADDR=127.0.0.1:7790 --env KADR_DATA_DIR=D:\kadr-automation kadr-test -- "$env:LOCALAPPDATA\Programs\Kadr\kadr-mcp.exe"

Видалити сервер: claude mcp remove kadr --scope user.

Поради для Claude Code

  • Великі результати. Claude Code типово обмежує результат інструмента приблизно 25 000 токенів (MAX_MCP_OUTPUT_TOKENS піднімає ліміт). Віддавайте перевагу timeline_get замість project_get, передавайте include_words: false у captions_list і тримайте плитки контактного аркуша невеликими (240–320 px).
  • Довгі завдання. Субтитри, транскрипція й експорт ідуть у фоні. Просити wait: true нормально для кількох хвилин медіа; для довших завдань попросіть Claude опитувати captions_status (з wait_s) або export_status.
  • Повільний перший запуск. Якщо сервер не встигає, поки стартує рушій, збільште MCP_TIMEOUT (у мілісекундах) під час запуску Claude Code.
  • Файли. Шляхи — на тому ПК, де працює Kadr. Власні файлові інструменти Claude Code і Kadr бачать той самий диск, тож Claude може записати пакетний файл чи SRT і передати шлях у Kadr.
