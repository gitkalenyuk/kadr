Результат — кліп, у якому кожна склейка припадає на долю, з білим спалахом на кожній склейці, бірюзово-помаранчевим грейдом поверх усього, punch-zoom на дропі та титром на першому такті. Долі шукаються на вашому ПК, а весь список склейок застосовується одним кроком скасування.

  • Час: ~2 хв
  • Що потрібно: Пісня і папка кліпів
  • Основні команди: audio.detect_beats, timeline.segment.add, timeline.segment.trim, segment.set_volume, transition.apply_all, filter.add, effect.add, text.add, export.start

Крок за кроком

Кожен крок показує ті самі виклики двічі. Вкладка kadrctl — для PowerShell: рядок, що починається з kadrctl --%, передає JSON, а без --% той самий рядок працює і в командному рядку (cmd). Вкладка MCP — це виклик інструмента, який надсилає агент: назва інструмента та його аргументи. Ідентифікатори на кшталт prj_…, mat_… і seg_… беруться з результатів попередніх кроків, тож у вас вони будуть інші. Шляхи в C:/Users/you — лише приклад.

Варіації

Один довгий кліп, розрізаний на кожній долі

timeline.segment.split не потребує segment_id, якщо передати лише at_us: він ріже той кліп основної доріжки, що опинився під цим часом. Пакет розрізів, по одному на точку склейки, ділить один довгий дубль на шматки завдовжки в такт, які потім можна видаляти, реверсувати чи прискорювати поодинці.

[
  { "command": "timeline.segment.split", "args": { "at_us": 2001270 } },
  { "command": "timeline.segment.split", "args": { "at_us": 4001088 } },
  { "command": "timeline.segment.split", "args": { "at_us": 6001270 } }
]

Інші ідеї

  • Частіші склейки. Беріть кожну 4-ту атаку (склейка на кожну долю) для приспіву і кожну 8-му для куплету.
  • Інший стиль склейок. Спробуйте переходи flash_zoom, glitch, whip_pan чи zoom_blur_through, а для дропу — ефекти rgb_pulse або hard_shake. library.list з kind transition чи effect покаже всі.
  • Вертикальна версія. Див. Один проєкт — три формати.

Поради

  • sensitivity — від 0 до 1: 0.7–0.9 для насиченої перкусії, 0.2–0.4, щоб лишити тільки сильні удари. strengths дає силу кожної долі (0–1) — так легше відрізнити сильні долі від слабких.
  • Час доль — це вже час на таймлайні (позицію та швидкість пісні враховано), тож його можна одразу підставляти в at_us і duration_us.
  • audio.detect_beats записується як крок скасування навіть без add_markers; це нешкідливо.
