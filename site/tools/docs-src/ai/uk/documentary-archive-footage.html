Крок за кроком

Кожен крок показує ті самі виклики двічі. Вкладка kadrctl — для PowerShell: рядок, що починається з kadrctl --%, передає JSON, а без --% той самий рядок працює і в командному рядку (cmd). Вкладка MCP — це виклик інструмента, який надсилає агент: назва інструмента та його аргументи. Ідентифікатори на кшталт prj_…, mat_… і seg_… беруться з результатів попередніх кроків, тож у вас вони будуть інші. Шляхи в C:/Users/you — лише приклад.

  1. Знайдіть хроніку в суспільному надбанні

    API розширеного пошуку Internet Archive повертає JSON, тож агент із доступом до оболонки може шукати напряму. Запитуйте поля прав і лишайте тільки записи, що явно в суспільному надбанні:

    $q = '("d-day" OR normandy) AND year:1944 AND mediatype:movies'
$url = "https://archive.org/advancedsearch.php?q=$([uri]::EscapeDataString($q))" +
       "&fl[]=identifier&fl[]=title&fl[]=year&fl[]=licenseurl&fl[]=rights&rows=50&output=json"
(Invoke-RestMethod $url).response.docs | Format-Table identifier, year, licenseurl, title -AutoSize

    Потім перелічіть відеофайли обраного запису (length — у секундах):

    $item = 'ITEM_ID'   # an identifier from the search
(Invoke-RestMethod "https://archive.org/metadata/$item").files |
  Where-Object { $_.name -like '*.mp4' } | Format-Table name, size, length

    Щоб вибрати кадри, агент може імпортувати копію низької роздільності в чернетковий проєкт і за допомогою ai.detect_scenes та preview.contact_sheet побачити, де починається кожен план.

  2. Виріжте лише потрібні кадри через ffmpeg

    ffmpeg уміє читати прямо з URL завантаження: з -ss перед -i він перемотує HTTP-запитами діапазонів, тож на кожен кадр завантажується лише кілька мегабайтів. Перекодування робить кожен розріз точним до кадру, а -an прибирає оригінальний коментар. Таймкоди нижче — заглушки, підставте свої.

    $src = 'https://archive.org/download/ITEM_ID/FILE.mp4'
$dst = "$env:USERPROFILE\Videos\dday"
New-Item -ItemType Directory -Force $dst | Out-Null
# -ss before -i seeks over HTTP (only the needed bytes are fetched); -t = length; -an drops the old soundtrack
ffmpeg -ss 00:01:12 -i $src -t 14 -c:v libx264 -crf 18 -pix_fmt yuv420p -an "$dst\01_fleet.mp4"
ffmpeg -ss 00:03:40 -i $src -t 14 -c:v libx264 -crf 18 -pix_fmt yuv420p -an "$dst\02_landing_craft.mp4"
ffmpeg -ss 00:05:05 -i $src -t 14 -c:v libx264 -crf 18 -pix_fmt yuv420p -an "$dst\03_beach.mp4"
ffmpeg -ss 00:06:30 -i $src -t 14 -c:v libx264 -crf 18 -pix_fmt yuv420p -an "$dst\04_inland.mp4"
ffmpeg -ss 00:08:15 -i $src -t 14 -c:v libx264 -crf 18 -pix_fmt yuv420p -an "$dst\05_crowds.mp4"

  4. Підключіть ElevenLabs і виберіть голос

    tts.set_api_key зберігає ключ лише на цьому ПК (у папці даних Kadr); жодна команда його не повертає і він не потрапляє в проєкти. Результат показує, чи ключ працює і скільки голосів він відкрив. Потім tts.voices з refresh перелічує їх з ідентифікаторами виду elevenlabs:<voice_id>. Крок із ключем виконайте самі (або задайте KADR_ELEVENLABS_API_KEY до запуску Kadr), а не вставляйте ключ у чат — усе, що є в запиті, потрапляє до вашого ШІ-провайдера.

    kadrctl run tts.set_api_key --provider elevenlabs --api_key sk_...
kadrctl run tts.voices --refresh

    Голоси ElevenLabs багатомовні: модель eleven_multilingual_v2 читає український текст будь-яким голосом, навіть якщо голос позначено en. Передавайте повний ідентифікатор (elevenlabs:…); голий код мови на кшталт uk вибирає локальний голос. Без ключа використовуйте espeak:uk — роботизовано, зате офлайн.

Варіації

  • Без ключа ElevenLabs. Використайте в tts.speak espeak:uk (чи будь-який голос із tts.voices); усе інше лишається так само. Видалити збережений ключ можна через tts.set_api_key з clear.
  • Довші фільми. Озвучуйте по абзацах (до 5000 символів на виклик) і тримайте по кадру на речення; список кадрів будуйте одним пакетом dday-shots.json.
  • Музична підкладка. Музика в суспільному надбанні чи під CC0 з того самого архіву, додана через timeline.segment.add на −20 дБ (segment.set_volume) під голосом.
  • Звук проєктора. sfx.add з film_advance на 0 с додає запуск кінопроєктора.
  • Вертикальна версія. Дублюйте проєкт, перемкніть на 9:16 і перекадруйте кожен план — див. Один проєкт — три формати.

Поради

  • tts.speak падає з not_found «voice … is not installed», якщо ключа ElevenLabs немає або голосу немає у списку вашого акаунта — викличте tts.voices з refresh і скопіюйте ідентифікатор звідти.
  • Швидкість мови для ElevenLabs обмежена 0.7–1.2 (rate); сповільнюйте озвучку там, а не розтягуванням кліпу.
  • Текст, який ви синтезуєте, надсилається в ElevenLabs; усе інше — хроніка, монтаж, субтитри — лишається на вашому ПК.
  • Плануйте кадри як дані. Тримайте поруч із кліпами невеликий shots.json — сцена, порядок, файл, тривалість — і називайте кожен файл за джерелом і таймкодом (наприклад, s2_1_B991.mp4 — сцена 2, перший кадр, джерело B на 991-й секунді). План одразу перетворюється на пакет dday-shots.json, а назви спрощують перемонтаж і титри. Довгий рядок озвучки можна покрити двома кадрами, що ділять його час (скажімо, 4,0 с + 3,95 с).
  • Зберігайте ідентифікатори архівних записів і таймкоди; у фінальних титрах варто назвати джерело.
