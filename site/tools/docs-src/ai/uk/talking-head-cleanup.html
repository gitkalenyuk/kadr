Крок за кроком

Кожен крок показує ті самі виклики двічі. Вкладка kadrctl — для PowerShell: рядок, що починається з kadrctl --%, передає JSON, а без --% той самий рядок працює і в командному рядку (cmd). Вкладка MCP — це виклик інструмента, який надсилає агент: назва інструмента та його аргументи. Ідентифікатори на кшталт prj_…, mat_… і seg_… беруться з результатів попередніх кроків, тож у вас вони будуть інші. Шляхи в C:/Users/you — лише приклад.

  1. Створіть проєкт, імпортуйте й покладіть дубль

    Почніть із проєкту 16:9; крок перекадрування сам перемкне полотно на 9:16.

    kadrctl run project.create --name "Tips short" --ratio 16:9
kadrctl --% run media.import --project_id prj_ed95831b1bf0 --paths "[\"C:/Users/you/Videos/tips-take3.mp4\"]"
kadrctl run timeline.segment.add --project_id prj_ed95831b1bf0 --material_id mat_745ea2a4d7e6

    Задайте це до різання: кожен шматок, що з’явиться після розрізів, успадкує налаштування кліпу, тож задаєте один раз. segment.set_audio вмикає шумозаглушення й нормалізацію гучності; segment.set_video_cleanup застосовує легке знешумлення (0–1) під час декодування відео.

  3. Перекадруйте у 9:16

    ai.auto_reframe із set_canvas перемикає проєкт на 9:16 і анімує кадрування, стежачи за мовцем. Якщо зробити це до розрізів, один виклик охопить увесь дубль.

    kadrctl run ai.auto_reframe --project_id prj_ed95831b1bf0 --segment_id seg_997808f11662 --ratio 9:16 --set_canvas
    {"name": "ai_auto_reframe", "arguments": {"project_id": "prj_ed95831b1bf0", "segment_id": "seg_997808f11662", "ratio": "9:16", "set_canvas": true}}

  4. Виріжте тишу

    ai.remove_silence вимірює рівень звуку й вирізає кожну ділянку, тихішу за −40 dBFS і довшу за 0,7 с, лишаючи по 120 мс запасу з кожного боку, щоб не обрізати слова, і закриває проміжки. У результаті — що саме вирізано та ідентифікатори шматків, що лишилися (segment_ids).

    kadrctl run ai.remove_silence --project_id prj_ed95831b1bf0 --segment_id seg_997808f11662 --threshold_db -40 --min_silence_us 0.7s --padding_us 120ms
    {"name": "ai_remove_silence", "arguments": {"project_id": "prj_ed95831b1bf0", "segment_id": "seg_997808f11662", "threshold_db": -40, "min_silence_us": 700000, "padding_us": 120000}}

  5. Розпізнайте мову

    transcript.transcribe локально запускає Whisper і зберігає кожне слово з таймінгом у матеріалі. Kadr сам проєктує слова на шматки, що лишилися після розрізів, тож транскрипт завжди відповідає таймлайну. Без segment_id розпізнаються всі кліпи, які чути.

    kadrctl run transcript.transcribe --project_id prj_ed95831b1bf0 --language en --wait
    {"name": "transcript_transcribe", "arguments": {"project_id": "prj_ed95831b1bf0", "language": "en", "wait": true}}
    Hi everyone. Um, today I want to show you three quick editing tips. Uh, the first one is simple,
cut your pauses. The second one is, um, add captions to every video. And the third is to keep it
short and punchy. Thanks for watching.

  6. Приберіть слова-паразити

    transcript.remove_fillers із preview лише показує знайдене (тут Um, Uh, і um,). Без preview він вирізає їх, і решта таймлайну зсувається, закриваючи проміжки.

{"name": "transcript_remove_fillers", "arguments": {"project_id": "prj_ed95831b1bf0"}}

  7. Скоротіть паузи, що лишилися

    transcript.remove_pauses працює з таймінгом слів, а не з рівнем звуку: кожен проміжок між словами, довший за 0,6 с, скорочується до 0,25 с. Після ai.remove_silence він ловить паузи, заповнені диханням чи шумом кімнати. У нашому чистому тестовому записі прибирати вже не було чого.

    kadrctl run transcript.remove_pauses --project_id prj_ed95831b1bf0 --min_pause_us 0.6s --keep_us 250ms

Варіації

  • Вирізати фразу за текстом. transcript.delete_text з text «thanks for watching» знаходить слова в транскрипті й вирізає їх із відео; субтитри зсуваються слідом.
  • Власні паразити. transcript.remove_fillers приймає додаткові words, наприклад ["типу", "коротше"]. Вбудовані списки є для англійської, української та російської.
  • Лишити 16:9. Для YouTube пропустіть крок перекадрування.
  • Лише звук. Експортуйте почищений голос для подкасту: export.start з audio_only і audio_format mp3.

Поради

  • У шумній кімнаті підніміть threshold_db до −30, щоб гул вважався тишею; у дуже тихій — опустіть до −50.
  • Спершу запускайте transcript.remove_fillers і transcript.remove_pauses з preview. Будь-який розріз можна скасувати, але переглянути список швидше.
  • Транскрипти належать медіа, а не таймлайну. Після подальших правок captions.from_transcript перебудує субтитри без повторного розпізнавання.
  • Імена розпізнаються з помилками? Передайте prompt «Kadr, Київ, Олена» в transcript.transcribe (додайте force, щоб переробити наявний транскрипт).
