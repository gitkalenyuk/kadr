The command reference documents all 177 commands — the same text an agent receives as MCP tool descriptions, generated from the engine’s own registry. Command descriptions are in English in both languages.

Open the full command reference →

What each entry contains

  • Name and title — the dotted command name (timeline.segment.split), its MCP tool name (timeline_segment_split) and a short title.
  • Description — what the command does, how it mirrors CapCut, edge cases and the errors it can return.
  • Parameters — name, type, required or optional, default, allowed values or range, and unit. Every *_us parameter is an integer in microseconds.
  • Returns — the shape of the result.
  • Flags — undoable or read-only, project or global scope, UI location and hotkey.
  • Examples — ready JSON arguments, each checked against the parameter schema.

Reading command names

The part before the first dot is the namespace — the subject the command acts on: project., media., timeline. (clips, tracks, markers), segment. (one clip’s properties), keyframe., animation., text., captions., transcript., audio., tts., sfx., effect., filter., adjustment., transition., library., preview., playback., export., ai. (smart tools), presets., edit., clipboard., ui., tools., update., app.. Verbs are consistent: add creates a new segment, apply changes an existing clip, set/set_* replaces values, get/list only read.
