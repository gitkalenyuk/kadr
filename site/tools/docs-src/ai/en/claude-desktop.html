Claude Desktop starts kadr-mcp.exe for you and shows Kadr’s tools in every chat. It takes one entry in a JSON file and a restart.

  1. Open the config file

    In Claude Desktop open Settings → Developer → Edit Config. This opens claude_desktop_config.json — normally %APPDATA%\Claude\claude_desktop_config.json. Create the file if it does not exist.

  2. Add Kadr

    Paste this, with your own user name in the path (Kadr’s Settings → API & automation shows the exact snippet for your PC). In JSON every backslash is written twice.

    {
  "mcpServers": {
    "kadr": {
      "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe"
    }
  }
}

    If the file already has an mcpServers section, add only the "kadr": { … } entry inside it, separated from its neighbours by a comma.

  3. Restart Claude Desktop completely

    Closing the window is not enough: right-click the Claude icon in the notification area and choose Quit, then start Claude Desktop again. Open Kadr first if you want to watch the edits.

  4. Check that it works

    Kadr’s tools now appear in the chat’s tools menu. Start a new chat and ask:

    List my Kadr projects.

    Claude calls project_list and answers. Then try an edit and watch the editor:

    Create a 9:16 Kadr project called "Desktop test", open it in the Kadr window, generate a 4-second sunset_gradient background, add the title "Hello" with the title_bold template and show me the frame at 1 second.

What Claude gets

  • One tool per Kadr command (timeline_segment_split for timeline.segment.split) with the full description, parameter units and examples, plus kadr_batch for atomic multi-step edits. See MCP tools.
  • Server instructions that explain the basics: projects → tracks → segments, microseconds, read state first, batch edits, look at frames.
  • Pictures: preview_frame and preview_contact_sheet return image content, so Claude actually sees the result of its edit.

Another port or data folder

By default the bridge talks to 127.0.0.1:7777 and reads the token from %APPDATA%\Kadr. For a separate engine, add an env block:

{
  "mcpServers": {
    "kadr": {
      "command": "C:\\Users\\you\\AppData\\Local\\Programs\\Kadr\\kadr-mcp.exe",
      "env": {
        "KADR_ADDR": "127.0.0.1:7790",
        "KADR_DATA_DIR": "D:\\kadr-automation"
      }
    }
  }
}

KADR_TOKEN can be set instead of KADR_DATA_DIR.

Troubleshooting

SymptomCauseFix
No Kadr tools in the chatThe config was not reloaded, or the JSON is invalid.Quit Claude Desktop from the tray and start it again. Check the JSON (commas, doubled backslashes).
“Server disconnected” or the server fails to startWrong path to kadr-mcp.exe.Use the full path from Kadr’s Settings → API & automation. The server’s log is in %APPDATA%\Claude\logs\ (mcp-server-kadr.log).
Kadr engine did not start … within 10 skadr-server.exe is missing next to kadr-mcp.exe, or blocked.Start Kadr yourself and ask again.
Edits don’t appear in the open Kadr windowThe bridge started a headless kadr-server.exe before Kadr was opened; it owns port 7777.Quit kadr-server.exe in Task Manager, keep Kadr open, restart Claude Desktop.
unauthorized: missing or invalid API tokenAn old KADR_TOKEN or a different KADR_DATA_DIR in env.Remove them, or copy the token from %APPDATA%\Kadr\api-token.
A call stops after 5 minutesThe bridge waits at most 5 minutes per call (for example wait: true on long captions).Run long jobs without wait and poll captions_status or export_status.
