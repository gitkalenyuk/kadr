Each recipe is a complete job: a prompt you can paste into Claude, then every call the agent makes, in order, as kadrctl and as an MCP tool call. All of them were run end to end against a real Kadr engine — with generated stand-in media — before publishing.

How to use a recipe

  1. Connect an agent — Claude Code, Claude Desktop or another client — and open Kadr so you can watch.
  2. Paste the prompt from “Ask Claude”, with your own paths and wording. The agent works out the calls; the steps show what it will do.
  3. Or run the steps yourself with kadrctl (PowerShell) — copy each id from the previous result.

Every recipe ends with a check (preview.contact_sheet, preview.frame or preview.layout) before exporting. Keep that step when you adapt a recipe — it is how the agent catches its own mistakes. See the review loop.
