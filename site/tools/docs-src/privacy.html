Kadr is built to run on your own computer. There is no account and no sign-in, and no telemetry, analytics or crash reporting. Your videos and projects never leave your PC unless you send them somewhere yourself.

Last updated: 1 October 2026.

What stays on your computer

Everything you work with stays on your PC and is never uploaded by Kadr: media files, projects, captions and transcripts, speech generated by text-to-speech, exports, settings, My kit presets and the API token. By default these are in %APPDATA%\Kadr, %LOCALAPPDATA%\Kadr and the folders you choose for imports and exports.

Network requests the app makes

These are the only connections Kadr makes on its own. Nothing else is contacted unless you turn on an optional cloud voice (see Local AI). The requests carry no information about you or your projects. They identify themselves only as Kadr and its version number, for example the User-Agent Kadr/0.1.0-beta.1.

Local AI

Auto captions and transcripts (faster-whisper), background removal (rembg or onnxruntime) and text-to-speech (Windows voices or eSpeak NG) all run on your PC. Kadr runs Whisper with Hugging Face access switched off and never downloads models. You install these optional tools yourself, for example with pip, and the one-time model download you start then happens between you and that package's source, not through Kadr.

Optional cloud voices: if you add your own ElevenLabs API key for text-to-speech, the text you voice is sent to ElevenLabs under their terms. Without a key, nothing is sent.

The local API and AI agents

Kadr's API only listens on 127.0.0.1, which other computers can't reach, and it requires a random token stored in your user profile. If you connect an AI agent such as Claude, the agent's client sends what it asks for to its own AI service, under that service's terms. That can include project details, transcript text and rendered frames from preview.frame. You choose which agent to connect and can approve its tool calls one by one. Kadr itself doesn't send anything to any AI service.

This website

This website is a static site hosted on GitHub Pages. It sets no cookies and uses no analytics, trackers or advertising. Its fonts are served from the site itself. It remembers your language, theme and code-example choices in your browser's local storage, which never leaves your device. The download section asks the GitHub API (api.github.com) from your browser for the latest release, to show its version, size and date. GitHub's privacy statement applies to that request and to GitHub Pages hosting.

Changes

If a future version of Kadr changes what is described here, this page is updated and the change is noted in the changelog.

Contact

Questions about privacy go to GitHub Issues. Issues are public, so don't include personal data, private media or your API token.
