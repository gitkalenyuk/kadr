Kadr створено для роботи на вашому власному комп’ютері. Немає облікового запису й входу, немає телеметрії, аналітики чи звітів про збої. Ваші відео й проєкти ніколи не залишають ПК, якщо ви самі їх кудись не надішлете.

Останнє оновлення: 1 жовтня 2026 року.

Це переклад для зручності. Якщо українська й англійська версії розходяться, чинною є англійська.

Що залишається на вашому комп’ютері

Усе, з чим ви працюєте, залишається на ПК, і Kadr нічого з цього не вивантажує: медіафайли, проєкти, субтитри й транскрипти, мовлення, синтезоване з тексту, експортовані файли, налаштування, пресети «Мій набір» і токен API. Типово все це зберігається в %APPDATA%\Kadr, %LOCALAPPDATA%\Kadr і в теках, які ви обираєте для імпорту та експорту.

Мережеві запити застосунку

Це єдині з’єднання, які Kadr встановлює самостійно. Нічого іншого він не викликає, якщо ви не ввімкнете необов’язковий хмарний голос (див. Локальний ШІ). Запити не містять жодних відомостей про вас чи ваші проєкти. Вони представляються лише як Kadr із номером версії, наприклад User-Agent Kadr/0.1.0-beta.1.

Локальний ШІ

Автоматичні субтитри й транскрипти (faster-whisper), прибирання фону (rembg або onnxruntime) і синтез мовлення (голоси Windows або eSpeak NG) працюють на вашому ПК. Kadr запускає Whisper із вимкненим доступом до Hugging Face і ніколи не завантажує моделі. Ці необов’язкові інструменти ви встановлюєте самі, наприклад через pip, і одноразове завантаження моделі, яке ви тоді запускаєте, відбувається між вами та джерелом пакета, а не через Kadr.

Необов’язкові хмарні голоси: якщо ви додасте власний ключ API ElevenLabs для синтезу мовлення, текст, який ви озвучуєте, надсилається до ElevenLabs відповідно до їхніх умов. Без ключа нічого не надсилається.

Локальний API та ШІ-агенти

API Kadr слухає лише 127.0.0.1 — до цієї адреси не можуть дістатися інші комп’ютери — і вимагає випадковий токен, що зберігається у вашому профілі користувача. Якщо ви підключаєте ШІ-агента, наприклад Claude, клієнт агента надсилає запитане до свого ШІ-сервісу на умовах цього сервісу. Це можуть бути відомості про проєкт, текст транскрипту й відрендерені кадри з preview.frame. Ви самі обираєте, якого агента підключити, і можете схвалювати його виклики інструментів по одному. Сам Kadr нічого не надсилає жодному ШІ-сервісу.

Ваш вибір мови, теми та формату прикладів коду сайт запам’ятовує в локальному сховищі браузера — ці дані не залишають ваш пристрій. Розділ завантаження запитує в GitHub API (api.github.com) з вашого браузера відомості про останній випуск, щоб показати його версію, розмір і дату. На цей запит і на хостинг GitHub Pages поширюється заява GitHub про конфіденційність.
