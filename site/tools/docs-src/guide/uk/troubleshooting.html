Щось не працює? Знайдіть свою ситуацію нижче — більшість проблем розв’язується за хвилину.

Встановлення

«Windows protected your PC» («Windows захистив ваш ПК»)

Це Windows SmartScreen. Він попереджає про нові програми без цифрового підпису — а поки Kadr у беті, підпису ще немає. Натисніть More info («Докладніше»), потім Run anyway («Усе одно запустити»). Щоб переконатися, що файл справжній, порівняйте його контрольну суму з SHA256SUMS.txt зі сторінки релізу: у PowerShell виконайте Get-FileHash .\Kadr-Setup-X.Y.Z-x64.exe.

Браузер блокує завантаження

Браузери насторожено ставляться до програм, які ще мало хто завантажував. У Microsoft Edge відкрийте меню … біля завантаження й оберіть Зберегти → Показати більше → Усе одно зберегти. У Chrome відкрийте список завантажень і оберіть Зберегти.

Вікно порожнє або Kadr просить WebView2

Вікно Kadr використовує Microsoft Edge WebView2 Runtime. У Windows 11 він вбудований; для Windows 10 встановіть безкоштовний «Evergreen» WebView2 Runtime із сайту Microsoft і запустіть Kadr знову.

FFmpeg

Постійно з’являється «Set up FFmpeg» або не працюють імпорт, перегляд чи експорт

Kadr не знаходить FFmpeg. Відкрийте Settings → FFmpeg і натисніть Download FFmpeg або вкажіть FFmpeg, що вже є у вас (папку з ffmpeg.exe і ffprobe.exe). Див. Налаштування → FFmpeg.

Не вдається завантажити FFmpeg

Перевірте інтернет і натисніть Retry. Якщо мережа блокує GitHub (буває в офісах і навчальних закладах), завантажте збірку FFmpeg для Windows через інше підключення, розпакуйте її й вкажіть папку bin у полі Use my FFmpeg.

Монтаж

Перегляд повільний або смикається

  1. Знизьте якість перегляду: натисніть Full під плеєром і оберіть Half або Quarter. На експорт це не впливає. Див. Якість перегляду.
  2. Для 4K, HEVC та іншого важкого відео створіть проксі (правий клік по відео в Media → Create proxy).
  3. Закрийте інші важкі програми; за можливості тримайте проєкти й медіа на SSD.

Файл не імпортується

Переконайтеся, що FFmpeg налаштовано (див. вище). Перевірте, чи файл відкривається в іншому плеєрі: пошкоджені чи недозавантажені файли прочитати неможливо. Дуже рідкісні формати можна спершу конвертувати в MP4. Список підтримуваних форматів охоплює майже всі камери й телефони.

Кліп позначено як відсутній

Оригінальний файл перемістили, перейменували чи видалили. Клацніть його правою кнопкою на вкладці Media, оберіть Link media… і вкажіть нове розташування. Див. Відсутні файли.

Не вдається виділити чи перемістити кліп

Найімовірніше, доріжку заблоковано — клацніть замок на її початку. Також перевірте, що активний інструмент виділення (A), у плеєрі — інструмент переміщення (V), а відтворення стоїть на паузі.

Гарячі клавіші не працюють

Перемкніть розкладку клавіатури на англійську: літерні комбінації (Ctrl+B, Q, W, M…) в українській розкладці не розпізнаються. Також клацніть порожнє місце таймлайна: поки курсор стоїть у текстовому полі, гарячі клавіші вимкнені. Повний список — на сторінці Гарячі клавіші.

З’являється повідомлення «Edited via API» або «Edited via MCP»

Проєкт змінила інша програма — зазвичай під’єднаний вами ШІ-асистент або скрипт. Це нормально, коли ви працюєте з Kadr разом зі ШІ. Будь-яку таку зміну можна скасувати через Ctrl+Z.

Розумні функції

Автосубтитри пишуть «Speech recognition is not set up»

Автосубтитрам і транскрипту потрібні Python із faster-whisper та завантажена модель. Виконайте кроки з розділу Субтитри → Що потрібно і натисніть Check again. Типові причини:

  • Python не знайдено. Запустіть інсталятор Python ще раз, оберіть Modify, увімкніть Add Python to environment variables і перезапустіть Kadr.
  • Встановлено кілька версій Python, і Kadr використовує не ту, куди ви встановили faster-whisper. Підкажіть Kadr потрібну: створіть змінну середовища користувача KADR_PYTHON зі шляхом до потрібного python.exe (меню «Пуск» → «Змінити змінні середовища для облікового запису») і перезапустіть Kadr.
  • Модель неактивна з позначкою «not downloaded». Завантажте її один раз, як у кроці 3 налаштування, замінивши small на назву моделі.
  • Дуже повільно. Обирайте модель small або base; для large-v3 справді потрібна відеокарта NVIDIA.

«Auto removal is not available on this computer»

Для видалення фону потрібен Python із rembg. Повідомлення точно каже, чого бракує. Встановіть пакет командою pip install rembg onnxruntime (див. ШІ-інструменти → Що потрібно) і натисніть Check again. Порада про KADR_PYTHON вище стосується й цього. Для запису на зеленому фоні нічого з цього не потрібно — скористайтеся Chroma key.

Озвучення тексту показує «No speech voices found»

Додайте голос у Windows: Параметри → Час і мова → Мовлення → Додати голоси, а потім натисніть у Kadr Detect again. Якщо не з’являються голоси ElevenLabs, перевірте, що файл ключа називається саме elevenlabs.key (а не elevenlabs.key.txt), лежить у папці даних і що ви натиснули стрілку оновлення — див. Голоси ElevenLabs.

Часті запитання

Kadr справді безкоштовний?

Так. Kadr — безкоштовна програма (freeware): її можна використовувати на будь-якій кількості комп’ютерів, зокрема й комерційно, без облікового запису, водяних знаків, реклами й телеметрії.

Kadr працює без інтернету?

Так. Монтаж, експорт, автосубтитри, видалення фону й інші розумні інструменти працюють на вашому комп’ютері. Інтернет потрібен лише для одноразового завантаження FFmpeg, перевірки оновлень (її можна вимкнути) і — тільки якщо ви їх оберете — голосів ElevenLabs.

Де зберігаються мої проєкти?

ЩоДе
Проєкти, налаштування, My kit%APPDATA%\Kadr — проєкти в її підпапці projects, кожен в окремій папці
Портативна версіяпапка data поруч із Kadr.exe
Експортовані відеоVideos\Kadr у вашій папці користувача («Відео» → Kadr), якщо ви не обрали іншу

Щоб відкрити %APPDATA%\Kadr, вставте цей рядок в адресний рядок Провідника. Settings → About → Data folder завжди показує папку, яку використовує саме ваша копія Kadr.

Як перенести проєкт на інший комп’ютер?

Скопіюйте папку проєкту з %APPDATA%\Kadr\projects у таке саме місце на іншому комп’ютері, а також скопіюйте медіафайли. Якщо там медіа опиняться в іншій папці, вкажіть нове розташування. Найнадійніше — передати вже експортоване відео.

Kadr несподівано закрився. Робота пропала?

Ні. Kadr зберігає проєкт після кожної зміни, тож усе на місці. Заново доведеться запустити лише експорт, якщо він тоді тривав.

Чи є інтерфейс українською?

Кнопки й меню редактора поки що англійською; цей посібник і сайт доступні українською. Автосубтитри та озвучення тексту працюють українською й ще приблизно сотнею мов.

Чи є версія для Mac?

Наразі Kadr працює у Windows 10 і 11 (64-розрядних). Версія для macOS готується — стежте за сторінкою релізів.

Чи може ШІ-асистент монтувати замість мене?

Так — саме цим Kadr і особливий. Claude та інші ШІ-асистенти можуть користуватися всіма функціями Kadr, а ви спостерігаєте. Див. документацію для ШІ-агентів.

Як повідомити про помилку чи запропонувати ідею?

Створіть issue на GitHub. Вкажіть версію Kadr із Settings → About і опишіть кроки, що призводять до проблеми.
