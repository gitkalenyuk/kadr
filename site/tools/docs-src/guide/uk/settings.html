Налаштувань у Kadr небагато — більшість рішень ухвалюється там, де ви працюєте. Вікно Settings відповідає за оновлення, FFmpeg і відомості про вашу інсталяцію.

Як відкрити Settings

  • На головному екрані: Settings ліворуч унизу.
  • У редакторі: Menu → Settings… або Menu → Check for updates… — одразу до оновлень.

Вікно має чотири розділи: About, Updates, FFmpeg і API & automation.

About — про програму

Показує Version — версію Kadr (з позначкою Beta чи Portable, якщо це так), збірку, платформу й версію FFmpeg. Особливо корисні два рядки:

  • Data folder — папка даних, де зберігаються ваші проєкти, налаштування й пресети. Кнопка копіювання копіює шлях.
  • Program — де встановлено сам Kadr.

Нижче — посилання на сайт, нотатки до релізів, ліцензію та сторонні ліцензії. Повідомляючи про проблему, вказуйте версію звідси.

Updates — оновлення

Kadr уміє оновлюватися сам. Після запуску він у фоні перевіряє GitHub — не частіше ніж раз на день і нічого не сповільнюючи. Коли нова версія готова, на кнопці Menu (і на Settings на головному екрані) з’являється крапка, а пункт меню змінюється на Update available….

  1. Подивіться, що нового

    Відкрийте Settings → Updates. Там показано нову версію з датою, розміром і нотатками до релізу. Check now перевіряє негайно.

  2. Завантажте

    Натисніть Download & install. Смуга прогресу показує завантаження. Потім Kadr перевіряє цифровий підпис і контрольну суму файлу — оновлення, що не пройшло перевірку, ніколи не встановлюється.

  3. Встановіть

    Натисніть Install & restart і підтвердьте. Kadr закриється, встановить нову версію й запуститься знову. Проєкти вже збережено; зупиниться лише експорт, якщо він саме триває, — тож дочекайтеся його завершення. Later відкладає встановлення.

  • Skip this version — приховати конкретне оновлення до виходу новішого (Don't skip скасовує це).
  • Automatic checks — вимкніть, якщо волієте перевіряти вручну.
  • Channel — Stable releases (стабільні) або Beta (includes pre-releases), щоб отримувати нові функції раніше. Поки Kadr у публічній беті, бета-збірки за замовчуванням використовують канал Beta.

FFmpeg

Kadr потрібен FFmpeg для імпорту, перегляду й експорту. Цей розділ показує, чи його знайдено і де:

  • Download FFmpeg (~100 MB) — завантажує FFmpeg у власну папку інструментів Kadr (%LOCALAPPDATA%\Kadr\tools\ffmpeg\bin). Після встановлення кнопка пропонує Download again.
  • Choose folder… або Use my FFmpeg — використати FFmpeg, який у вас уже є: оберіть або введіть папку з ffmpeg.exe і ffprobe.exe та натисніть Use folder. Forget скасовує цей вибір.

Коли FFmpeg знайдено, рядок стану показує його версію та джерело: Downloaded by Kadr (завантажив Kadr), Folder you chose (обрана вами папка), Next to Kadr (поруч із Kadr) або System PATH. FFmpeg — вільна програма під ліцензією GPL; це окремий продукт, не частина Kadr.

API & automation

Усе, що ви клацаєте в Kadr, можуть робити й скрипти та ШІ-асистенти. Тут показано локальну API address (http://127.0.0.1:7777), посилання на вбудовану Documentation, Token file — файл токена, що захищає API, — і готові до копіювання налаштування для під’єднання Claude Desktop та Claude Code. API доступний лише на вашому комп’ютері. Для монтажу все це не потрібне, але якщо цікаво — читайте документацію для ШІ.

Портативний режим

Портативний архів (Kadr-X.Y.Z-windows-x64-portable.zip) працює без встановлення — з будь-якої папки чи флешки. Розпакуйте його й запустіть Kadr.exe.

  • Файл portable.txt поруч із Kadr.exe позначає копію як портативну; у Settings видно позначку Portable.
  • Проєкти й налаштування зберігаються в папці data поруч із Kadr.exe, тож «подорожують» разом із програмою. Щоб переконатися, гляньте Settings → About → Data folder.
  • Портативна копія повідомляє про нову версію, але не встановлює її. Завантажте новий архів і розпакуйте його поверх старої папки, зберігши папку data.
  • Портативній версії так само потрібні Microsoft Edge WebView2 Runtime (є у Windows 11) і FFmpeg.

Видалення

Відкрийте у Windows Параметри → Програми → Інстальовані програми (Settings → Apps → Installed apps), знайдіть Kadr і оберіть Видалити. Деінсталятор поставить два запитання:

  • Також видалити мої проєкти та налаштування? — відповідайте Ні, щоб зберегти їх для майбутнього встановлення;
  • Також видалити інструменти, які завантажив Kadr (наприклад, FFmpeg)?

Ваші оригінальні медіафайли ніколи не зачіпаються. Щоб прибрати портативну копію, просто видаліть її папку.
