Kadr може прослухати відео й написати субтитри замість вас — на вашому комп’ютері, нічого нікуди не завантажуючи. Далі субтитри можна перестилізувати, виправити слова, зберегти у файл SRT або навіть змонтувати відео, видаляючи слова з його транскрипту.

Що потрібно

Розпізнавання мовлення працює на Whisper (через безкоштовний пакет faster-whisper), якому потрібен Python. Налаштувати це треба один раз:

  1. Встановіть Python

    Завантажте Python 3.9 або новіший із python.org і запустіть інсталятор. На першому екрані поставте позначку Add python.exe to PATH.

  2. Встановіть faster-whisper

    Відкрийте PowerShell (меню «Пуск» → введіть «PowerShell») і виконайте:

    pip install faster-whisper

  3. Один раз завантажте модель мовлення

    У тому ж PowerShell виконайте рядок нижче — він завантажить рекомендовану модель small (близько 500 МБ). Лише для цього кроку потрібен інтернет.

    python -c "from faster_whisper import WhisperModel; WhisperModel('small')"

  4. Перевірте в Kadr

    Відкрийте Captions → Auto captions. Якщо там досі написано Speech recognition is not set up, натисніть Check again (або перезапустіть Kadr). Коли все працює, панель повідомляє, що розпізнавання йде офлайн через Whisper на процесорі чи відеокарті NVIDIA.

Відеокарта NVIDIA пришвидшує розпізнавання в кілька разів. Без неї обирайте модель small або base. Якщо Kadr бере не той Python, див. Проблеми та запитання.

Автоматичні субтитри

  1. Відкрийте вкладку Captions; ліворуч уже обрано Auto captions.
  2. Language used in video — залиште Detect automatically (визначити автоматично) або оберіть мову: їх близько сотні, зокрема українська та англійська. З явно вказаною мовою точність трохи вища.
  3. Model — tiny найшвидша, small — збалансована (за замовчуванням), medium і large-v3 найточніші, але без відеокарти повільні. Незавантажені моделі в списку неактивні.
  4. Style — вигляд субтитрів (його можна змінити й пізніше).
  5. Залиште позначку Replace existing captions, щоб почати з чистого аркуша, і натисніть Generate.

Смуга прогресу показує кожен етап (видобування звуку, завантаження моделі, розпізнавання). Тим часом можна далі монтувати або скасувати кнопкою ×. Субтитри з’являються на окремій доріжці Captions, із таймінгом кожного слова.

Автосубтитри прослуховують усі кліпи зі звуком на таймлайні. Та сама команда є в меню Smart tools на панелі інструментів; якщо там виділено відео- чи аудіокліп, субтитри створюються лише для нього.

Оберіть ліворуч Edit captions. Кожну репліку подано з часом початку й кінця. Клацніть у текст, щоб виправити його:

Стилі субтитрів і підсвічування слів

Оберіть ліворуч Styles і клацніть стиль — він застосується до всіх субтитрів. Кнопки-фільтри розкладають 15 стилів на групи: Trending, Basic, Word highlight, Social і Boxed.

Стилі з позначкою word підсвічують кожне слово в момент, коли його вимовляють, — популярний у TikTok і Reels «караоке»-ефект. Це можливо, бо автосубтитри знають таймінг кожного слова.

Щоб налаштувати підсвічування, виділіть репліку на таймлайні й відкрийте Text → Animate в інспекторі. У розділі Caption highlight оберіть Colour, Box, Grow, Underline чи Karaoke і колір підсвічування.

Імпорт і експорт файлів субтитрів

Upload file імпортує наявні субтитри: введіть повний шлях до файлу, оберіть стиль, за потреби — Offset (зсув у секундах), поставте позначку Replace the current captions, якщо треба замінити поточні, і натисніть Import. Підтримуються SubRip .srt, WebVTT .vtt, Advanced SubStation .ass/.ssa і тексти пісень .lrc (пословні мітки LRC перетворюються на караоке-таймінг).

Download зберігає субтитри у форматі SubRip (.srt), WebVTT (.vtt), простого тексту (.txt) або .lrc. Вкажіть, куди зберегти, і натисніть Save — або Copy text, щоб вставити деінде. Завантажте SRT на YouTube — і глядачі зможуть вмикати й вимикати субтитри.

Монтаж відео через редагування тексту

Вкладка Transcript показує все, що звучить у відео, як текст. Видалення слів тут вирізає їх із відео — найпростіший спосіб почистити інтерв’ю, влоги й подкасти.

  1. Відкрийте вкладку Transcript. Якщо кліпи ще не мають транскрипту, оберіть Spoken language (мову мовлення) і натисніть Transcribe. (Кліпи з автосубтитрами вже розшифровані.)
  2. Клацніть слово, щоб перейти до нього у відео.
  3. Протягніть по словах або клацніть одне й Shift+клацніть інше, щоб виділити фрагмент.
  4. Натисніть Delete (або кнопку Delete, що з’явиться) — відео й субтитри обріжуться відповідно. Esc знімає виділення.

Прибрати слова-паразити й паузи

  • Fillers — вирізає вагання на кшталт «е-е», «ем», «м-м», «ну», а також «типу», «коротше», «значить», коли вони вжиті як паразити. Розпізнаються українська, англійська й російська. Число на кнопці — скільки їх знайдено; у тексті вони підкреслені пунктиром.
  • Remove pauses — скорочує кожну паузу, довшу за вказане число секунд, до 0,3 с. Паузи позначено маленькими сірими мітками між словами.
  • Captions — створює субтитри з транскрипту без повторного розпізнавання.

Кожна з цих дій — один крок, який скасовується через Ctrl+Z. Бліді слова — ті, у яких розпізнавач не впевнений; їх варто перевірити.

Приватність закладено в основу. Розпізнавання повністю відбувається на вашому комп’ютері; звук нікуди не надсилається. Kadr ніколи не завантажує моделі сам — лише команда з кроку 3 вище.
