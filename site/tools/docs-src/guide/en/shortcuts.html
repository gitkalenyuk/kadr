Shortcuts make editing much faster. You can always see the list inside Kadr: click Shortcuts in the top bar or press Ctrl+/.

The ones to learn first

Space play / pause · Ctrl+B split · Delete delete · Q / W delete left / right · Ctrl+Z undo
← → one frame · Ctrl+C / Ctrl+V copy / paste · M marker · Ctrl+E export

Shortcuts are ignored while you type in a text box, so typing an “m” in a caption never adds a marker. Letter shortcuts follow the active keyboard layout: if you type in another alphabet, switch to the English layout for Ctrl+B, Q, W and the like. On a Mac, Cmd takes the place of Ctrl.
