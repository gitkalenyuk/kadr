Exporting turns your project into a video file you can upload or share. The defaults suit almost every platform, so in most cases you just click Export.

Export in three clicks

  1. Open the Export window

    Click Export in the top-right corner of the editor, or press Ctrl+E.

  2. Check the name and folder

    Name is the file name; Export to is the folder — by default Videos\Kadr in your user folder. To save elsewhere, type another folder path. The line Saved as … shows the final file name.

  3. Click Export

    Progress and the time left are shown. Click Hide to keep editing while the export runs in the background — a message appears when it is finished.

When it is done, click Open folder to see the file in File Explorer, Export again to make another version, or Close. If a file with the same name already exists, Kadr adds “ (1)”, “ (2)”… instead of overwriting it.

Fast export with your graphics card

If your computer has an NVIDIA, Intel or AMD graphics chip with a video encoder (NVENC, Quick Sync or AMF), Kadr uses it automatically — exports are then several times faster. Next to Codec the window shows which encoder will be used, for example GPU · h264_nvenc. Without a suitable graphics chip, Kadr uses the processor; the result looks the same, it just takes longer.

Audio-only and GIF

Three switches choose what to export — you can turn on more than one at a time:

  • Video — the normal video file.
  • Audio — the soundtrack as MP3, WAV, AAC or FLAC. With Video on, it is saved as an extra file; switch Video off to export the sound only — for example a podcast episode.
  • GIF — an animated GIF (up to 720 pixels, 15 frames per second, no sound) for chats and websites. Keep GIFs short: they get big quickly.

Where the files go

Unless you type another folder, exports are saved in C:\Users\<you>\Videos\Kadr. Missing folders are created automatically. The export uses your original media at full quality — proxies and the preview quality setting don't affect it.

Need several versions — vertical and horizontal, or a short excerpt only? An AI assistant can export a time range or a batch of variants for you with export.start.
