From download to your first project in about five minutes. Kadr is free, needs no account and works offline.

1. Download Kadr

Kadr is published on its GitHub Releases page. Open the newest release and, under Assets, download the installer:

FileWhat it is
Kadr-Setup-X.Y.Z-x64.exeThe installer — choose this one. It installs Kadr for your user account (no administrator rights needed), adds a Start menu entry and keeps Kadr up to date.
Kadr-X.Y.Z-windows-x64-portable.zipThe portable version: unzip and run, nothing is installed. See Portable mode.
SHA256SUMS.txtChecksums, if you want to verify that the download is genuine.

While Kadr is in beta, releases are marked Pre-release. If the page shows no “Latest” release, simply take the newest pre-release at the top.

Your browser may say the file “isn't commonly downloaded”. That only means Kadr is new. In Microsoft Edge, open the … menu next to the download, choose Keep, then Show more → Keep anyway.

2. Install

  1. Run the installer

    Double-click Kadr-Setup-…-x64.exe in your Downloads folder.

  2. Get past SmartScreen

    Kadr is not code-signed yet, so Windows may show a blue window saying “Windows protected your PC”. Click More info, then Run anyway. This warning appears for most new apps from small publishers.

  3. Click through the installer

    The installer speaks English and Ukrainian. Accept the licence; Kadr installs into your user folder (%LOCALAPPDATA%\Programs\Kadr). Two options are ticked by default: Create a desktop shortcut, and Add kadrctl and kadr-mcp to PATH — the second one is only needed if you plan to connect an AI assistant, but leaving it on does no harm.

  4. WebView2 check

    The editor window uses Microsoft Edge WebView2, which is already part of Windows 11 and most Windows 10 PCs. If it is missing, the installer points you to Microsoft's free download.

  5. Launch Kadr

    Leave Launch Kadr ticked on the last page, or start Kadr from the Start menu later.

Want to be extra sure the file is genuine? In PowerShell run Get-FileHash .\Kadr-Setup-X.Y.Z-x64.exe and compare the result with the matching line in SHA256SUMS.txt.

3. First launch: set up FFmpeg

Kadr reads and writes video with FFmpeg, a free program that is not bundled with Kadr. The first time you start Kadr, it checks for FFmpeg. If it can't find one, the Set up FFmpeg window appears:

  • Download now (recommended) — Kadr downloads FFmpeg 7.1 for Windows (about 100 MB), checks that the file is intact and keeps it in its own tools folder. When the window says FFmpeg is ready, click Continue.
  • I have FFmpeg — choose folder — if FFmpeg is already on your computer, pick the folder that contains ffmpeg.exe and ffprobe.exe. An FFmpeg that is already on your system PATH is found automatically and the window never appears.
  • Later — closes the window. Importing, previewing and exporting will not work until FFmpeg is set up; you can do it any time in Settings → FFmpeg.

4. Create your first project

  1. Create a project

    Click Create project (or press Ctrl+N) for a normal 16:9 video. For TikTok, Reels or Shorts click Vertical 9:16; for an Instagram post, Square 1:1. The editor opens right away. You can change the shape later — see Projects.

  2. Bring in your media

    In the Media tab click Import (Ctrl+I) or drag files from File Explorer onto the window. More in Import media.

  3. Put clips on the timeline

    Click the + on a media card, or drag the card down onto the timeline. Clips on the main track line up one after another automatically.

  4. Edit

    Move the playhead (the white line) to a spot and press Ctrl+B to cut, select the unwanted part and press Delete. Add a title from the Text tab and music from Media. The Timeline editing page has all the details.

  5. Export

    Click Export in the top-right corner (Ctrl+E), keep the suggested settings and click Export. Your video lands in Videos\Kadr. See Export.

Kadr saves every change immediately — there is no Save button. Made a mistake? Ctrl+Z undoes it.

Optional extras

Almost everything works straight after installation. Two smart features use free AI models that run on your own computer and need a one-time setup with Python:

  • Automatic captions and transcript editing — needs Python and faster-whisper. See Captions → What you need.
  • Background removal — needs Python and rembg. See AI tools.
