Something not working? Find your problem below. Most issues are solved in a minute.

Installing

“Windows protected your PC”

This is Windows SmartScreen. It warns about new apps that aren't code-signed yet, which is the case for Kadr during the beta. Click More info, then Run anyway. To make sure the file is genuine, compare its checksum with SHA256SUMS.txt from the release page: in PowerShell, Get-FileHash .\Kadr-Setup-X.Y.Z-x64.exe.

The browser blocks the download

Browsers are cautious with programs that few people have downloaded yet. In Microsoft Edge, open the … menu next to the download and choose Keep → Show more → Keep anyway. In Chrome, open the downloads list and choose Keep.

The window stays empty or Kadr asks for WebView2

Kadr's window uses the Microsoft Edge WebView2 Runtime. Windows 11 has it built in; on Windows 10 install the free “Evergreen” WebView2 Runtime from Microsoft's website, then start Kadr again.

FFmpeg

“Set up FFmpeg” keeps appearing, or import, preview and export don't work

Kadr can't find FFmpeg. Open Settings → FFmpeg and click Download FFmpeg, or point Kadr to an FFmpeg you already have (the folder with ffmpeg.exe and ffprobe.exe). See Settings → FFmpeg.

The FFmpeg download fails

Check your internet connection and click Retry. On networks that block GitHub (some offices and schools), download a Windows build of FFmpeg on another connection, unzip it, and choose its bin folder with Use my FFmpeg.

Editing

The preview is slow or stutters

  1. Lower the preview quality: click Full under the player and choose Half or Quarter. This doesn't affect the export. See Preview quality.
  2. For 4K, HEVC or other heavy footage, create proxies (right-click the video in Media → Create proxy).
  3. Close other heavy programs, and keep projects and media on an SSD if you can.

A file won't import

Make sure FFmpeg is set up (see above). Check that the file plays in another player — damaged or incomplete downloads can't be read. Very unusual formats can be converted to MP4 first. The list of supported formats covers almost every camera and phone.

A clip shows as missing

The original file was moved, renamed or deleted. Right-click it in the Media tab, choose Link media… and enter its new location. See Missing files.

I can't select or move a clip

Its track is probably locked — click the padlock at the start of the track. Also check that the Select tool is active (press A) and, in the player, the Move tool (V), and that playback is paused.

Keyboard shortcuts don't work

Click an empty part of the timeline first: while the cursor is in a text box, shortcuts are switched off so you can type. If you use a non-Latin keyboard layout (for example Ukrainian), switch to the English layout — letter shortcuts such as Ctrl+B, Q and M follow the active layout. See Keyboard shortcuts.

A message says “Edited via API” or “Edited via MCP”

Another program — usually an AI assistant you connected, or a script — changed the project. That is expected when you use Kadr with AI. Any such change can be undone with Ctrl+Z.

Smart features

Auto captions say “Speech recognition is not set up”

Auto captions and the transcript need Python with faster-whisper and a downloaded model. Follow Captions → What you need, then click Check again. Common causes:

  • Python isn't found. Re-run the Python installer, choose Modify and enable Add Python to environment variables, then restart Kadr.
  • Several Pythons are installed and Kadr uses another one than you installed faster-whisper into. Tell Kadr which one to use: create a user environment variable named KADR_PYTHON containing the full path of the right python.exe (Start menu → “Edit environment variables for your account”), then restart Kadr.
  • A model is greyed out as “not downloaded”. Download it once, as in step 3 of the setup, replacing small with the model name.
  • It is very slow. Use the small or base model; large-v3 really needs an NVIDIA graphics card.

“Auto removal is not available on this computer”

Background removal needs Python with rembg. The message tells you exactly what is missing. Install it with pip install rembg onnxruntime (see AI tools → What you need) and click Check again. The KADR_PYTHON tip above applies here too. For a green-screen recording you don't need any of this — use Chroma key.

Text to speech shows “No speech voices found”

Add a voice in Windows: Settings → Time & language → Speech → Add voices, then click Detect again in Kadr. For ElevenLabs voices that don't appear, check that the key file is named exactly elevenlabs.key (not elevenlabs.key.txt), that it is in the data folder, and that you clicked the refresh arrow — see Use ElevenLabs voices.

Frequently asked questions

Is Kadr really free?

Yes. Kadr is freeware: free to use on any number of computers, also for commercial work, with no account, no watermark, no ads and no telemetry.

Does Kadr work offline?

Yes. Editing, export, auto captions, background removal and the other smart tools all run on your computer. The internet is only used for the one-time FFmpeg download, update checks (which you can switch off) and — only if you choose them — ElevenLabs voices.

Where are my projects stored?

WhatWhere
Projects, settings, My kit%APPDATA%\Kadr — projects are in its projects folder, one folder each
Portable versionthe data folder next to Kadr.exe
Exported videosVideos\Kadr in your user folder, unless you chose another folder
FFmpeg downloaded by Kadr%LOCALAPPDATA%\Kadr\tools\ffmpeg\bin

To open %APPDATA%\Kadr, paste it into the address bar of File Explorer. Settings → About → Data folder always shows the folder your copy of Kadr uses.

How do I move a project to another computer?

Copy the project's folder from %APPDATA%\Kadr\projects to the same place on the other computer, and copy your media files too. If the media ends up in a different folder there, relink it. For the cleanest hand-over, export the finished video instead.

Kadr closed unexpectedly. Is my work lost?

No. Kadr saves after every change, so your project is exactly as you left it. Only an export that was running needs to be started again.

Is the editor available in Ukrainian?

The editor's buttons and menus are in English for now; this guide and the website are also available in Ukrainian. Auto captions and text to speech work in Ukrainian and about a hundred other languages.

Is there a Mac version?

Kadr currently runs on Windows 10 and 11 (64-bit). A macOS version is in preparation; watch the releases page.

Can an AI assistant edit for me?

Yes — that is what makes Kadr special. Claude and other AI assistants can use every Kadr feature while you watch. See the documentation for AI agents.

How do I report a bug or suggest a feature?

Open an issue on GitHub. Mention your Kadr version from Settings → About and describe the steps that lead to the problem.
