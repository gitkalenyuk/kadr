Voices, AI video and money

Kadr can speak text with 39 cloud and self-hosted voice providers and generate video with 37 AI video providers. Both can cost the user real money. Every paid call therefore follows one pattern — estimate → ask the user → run with the confirm token — and Kadr enforces it: a paid command without a valid token is refused, and a daily spending limit stops runaway costs.

The rules

  1. Prefer what is free. Local voices (Windows SAPI, eSpeak NG, macOS say), self-hosted servers and Edge read-aloud cost nothing and need no confirmation. Speech or video identical to an earlier request is reused for free.
  2. Always ask before paying. Call the matching tts.estimate / videogen.estimate, show the user the cost text, wait for an explicit yes, then repeat the call with confirm_token. Never pass a token the user has not agreed to. A token is bound to the exact arguments and price and expires after 15 minutes; change anything that affects the price and you need a new estimate.
  3. Never handle keys. API keys live in Kadr's OS-encrypted vault; commands that accept keys are write-only and no result, event or error ever contains one. Don't ask the user to paste a key into the chat — send them to Settings → Voices / Video generation / AI assistant. Don't run secrets.export unless the user explicitly asks for a key backup.
  4. Respect the limit. spending.get shows today's spending, the daily limit and what is left. A call that would exceed it fails with conflict; tell the user — never try to raise the limit yourself (spending.set_limit is the user's setting).

Find out what is set up

QuestionCall
Which voice providers work right now?tts.providers {"ready_only": true, "models": false}
Which voices (e.g. Ukrainian)?tts.voices {"language": "uk"} — ids look like elevenlabs:<voice_id>, azure:uk-UA-PolinaNeural, sapi:Microsoft Zira Desktop
Which models and parameters does a voice provider have?tts.models {"provider": "elevenlabs"} (e.g. eleven_v3, eleven_multilingual_v2)
Which video providers have a working key?videogen.providers {"configured_only": true}
Which video models, and what can they do?videogen.models {"provider": "fal", "featured_only": true} or {"capability": "first_last_frame"} — each model lists capabilities and a parameter schema (durations in seconds, resolutions, aspect ratios, file params with their roles) plus a price hint
How much is left today?spending.get {"days": 1, "entries": 0}

A provider without a usable key is simply not ready — the error of a call to it has a hint telling the user where to add one. Don't retry in a loop.

Paid voice-over

// → {"paid": true, "cost_text": "≈ $0.0023 (prices as of 2026-10-07)", "requires_confirmation": true, "confirm_token": "ct1.…", "quota": {…}}
// Ask: "This line costs about $0.002 with ElevenLabs (eleven_v3). Go ahead?"  — user: "yes"
{"name": "tts_speak", "arguments": {"project_id": "prj_1a2b3c4d5e6f", "provider": "elevenlabs", "model": "eleven_v3", "voice": "JBFqnCBsd6RMkjVDRZzb", "text": "It was a cold night in March.", "at_us": 2000000, "confirm_token": "ct1.…"}}
kadrctl run tts.estimate --project_id prj_1a2b3c4d5e6f --provider elevenlabs --model eleven_v3 --voice JBFqnCBsd6RMkjVDRZzb --text "It was a cold night in March."
kadrctl run tts.speak --project_id prj_1a2b3c4d5e6f --provider elevenlabs --model eleven_v3 --voice JBFqnCBsd6RMkjVDRZzb --text "It was a cold night in March." --at_us 2s --confirm_token "ct1.…"
  • requires_confirmation: false means the call is free (local voice, cached speech) or the user allowed small amounts without asking (Ask before paying in the provider's settings). Then you may call tts.speak without a token.
  • Without a token a paid call fails with invalid_argument, field confirm_token, and a hint that says exactly this.
  • The same rules apply to tts.from_text (estimate with project_id + segment_id) and to tts.provider.test with a sample_text.
  • Long text is split at sentence ends for providers with short limits and joined; every engine's output is trimmed and loudness-normalised to about -16 LUFS, so mixing providers sounds even.
  • Subscription plans (ElevenLabs) are billed in characters from the plan's quota: show the user quota as well as the price.

Fill a gap with an AI-generated shot

  1. Find the gap

    timeline.get → the range to fill (start_us, duration_us) on the main track, or the segment_id of a clip to replace.

  2. Estimate

    Call videogen.estimate with the same arguments you will generate with. Kadr fills the duration from the range (the shortest allowed duration that covers it) and the aspect ratio from the canvas, checks references against the model's capabilities, picks the endpoint (text, image, first+last frame, references, video edit) and prices it. use_neighbors: true uses the last frame of the clip before the gap as first_frame and the first frame of the clip after it as last_frame when the model supports them.

  3. Ask the user

    Show estimate_text (or “cost unknown” — credit-based providers and models without a public price are still paid), limit.remaining and any warnings. If cached is true an identical result exists and costs nothing.

  4. Generate

    Call videogen.generate with the same arguments plus confirm_token. It returns a job at once; the work runs in the background.

  5. Follow the job

    Poll videogen.job every few seconds (or listen to videogen.job events) until state is succeeded, failed or canceled. Generation usually takes one to several minutes. While the provider is unreachable the job stays unfinished with lost_contact_at and next_check_at — Kadr keeps checking by itself; do not generate again (that would be paid again). A job that failed with resumable: true is picked up with videogen.resume, at no extra cost. A finished job's result.url plays the video over the REST API.

  6. Check the result

    With a range or segment_id the clip is placed automatically as one undo step (placed in the job). Look at it with preview.frame or preview.contact_sheet before you continue.

Useful options

ArgumentUse
paramsModel parameters by the names videogen.models lists: duration (seconds), aspect_ratio, resolution, seed, negative_prompt, generate_audio, camera_motion… and extra_json for raw vendor fields.
references[{"role": "first_frame" | "last_frame" | "reference_image" | "reference_video" | "reference_audio" | "source_video", …one source}] where the source is path, url, material_id (+ time_us or edge), segment_id (+ edge / time_us), frame_us (a composited project frame), playhead: true or a neighbour. Frames are extracted with FFmpeg and uploaded the way the provider wants.
segment_idReplace this clip: its range is the target; the new media keeps its position, effects, transform and keyframes.
fitauto (default), trim, fit (speed changed to fill exactly), keep_speed (full length).
muteMute the generated sound (B-roll under narration).
new_takeGenerate again even though an identical result exists (costs again — ask).
retry_ofRe-run an earlier job (vg_…) with changed arguments. A retry is a new paid call: estimate it too.

videogen.place places a finished job (or any video file) again — into another range, at the playhead, replacing a clip, or only into Media with import_only. videogen.cancel stops a job; a job canceled while still queued is refunded in the ledger, but some providers cannot cancel a running job and still bill it (the result says so).

Errors you will see

ErrorMeaning and what to do
invalid_argument, field confirm_tokenPaid call without a (valid) token, or the arguments changed since the estimate. Estimate again and ask.
conflict mentioning the daily limitToday's spending plus running jobs plus this estimate would exceed the user's limit. Tell the user; don't retry.
not_availableNo usable key (all keys invalid, exhausted or rate-limited) or a missing setting. The hint names the provider settings page; keys fail over automatically before you ever see this.
Job failed with error.hintThe provider refused the request (content policy, unsupported duration/size, bad reference). Change the prompt or parameters and retry with retry_of — after a new estimate.

What the user sets up (not you)

  • Keys and key order per provider (many keys per provider, used in order with failover) — Settings → Voices, Video generation, AI assistant. Write-only commands exist (tts.keys.add, videogen.keys.add), but only use them when the user hands you a key file path for exactly that purpose.
  • The daily limit and per-provider limits (spending.set_limit).
  • Custom providers (tts.provider.add, videogen.provider.add) — you can help write the template if asked; tts.provider.test and videogen.provider.test check them with free requests.

Inside Kadr, the built-in assistant follows exactly these rules: paid steps appear as approval cards with the price.
