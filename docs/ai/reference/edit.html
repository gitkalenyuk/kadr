Edit commands

6 commands in the Edit category. Each one works the same from the editor UI, REST, MCP and kadrctl.

  • clipboard.copyCopy
  • clipboard.cutCut
  • clipboard.pastePaste
  • edit.historyGet undo history state
  • edit.redoRedo
  • edit.undoUndo

clipboard.copy

Copy

Ctrl+CNo undo stepTimeline › Context menu › CopyMCP clipboard_copy

Copies clips to the editor's clipboard (kept in memory per project, not the OS clipboard) so they can be pasted with clipboard.paste — Ctrl+C in CapCut. All properties are copied (effects, filters, keyframes, text style…). Linked clips are copied along when linkage is on. The project is not changed and nothing is added to undo history.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idstringID of the clip. Required unless segment_ids is given.
segment_idsstring[]Several segment ids at once (multi-selection). Combined with segment_id when both are given.

Returns

{copied: [segment ids]}.

Examples

Copy a clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/clipboard.copy \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run clipboard.copy --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: clipboard_copy
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

clipboard.cut

Cut

Ctrl+XUndoableTimeline › Context menu › CutMCP clipboard_cut

Copies clips to the editor's clipboard and deletes them from the timeline — Ctrl+X in CapCut. Deletion follows timeline.segment.delete (ripple on the magnet main track, linked clips included, emptied tracks removed). Undo restores the clips; the clipboard keeps the copy.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idstringID of the clip. Required unless segment_ids is given.
segment_idsstring[]Several segment ids at once (multi-selection). Combined with segment_id when both are given.

Returns

{cut: [segment ids]}.

Examples

Cut a clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/clipboard.cut \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_1a2b3c4d5e6f"}'
kadrctl run clipboard.cut --project_id prj_1a2b3c4d5e6f --segment_id seg_1a2b3c4d5e6f
// MCP tool: clipboard_cut
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_1a2b3c4d5e6f"
}

clipboard.paste

Paste

Ctrl+VUndoableTimeline › Context menu › PasteMCP clipboard_paste

Pastes the clips from clipboard.copy / clipboard.cut at at_us (default: the playhead) — Ctrl+V in CapCut. Clips keep their timing relative to each other and get new ids (pasted linked clips are linked to each other). Each clip goes back to its original track if it still exists (or to track_id when given and compatible); on the main track the magnet inserts at the nearest clip boundary and ripples, and the rest of the pasted selection follows by the same amount; on other tracks an occupied spot sends the clip to a new track. Transitions are not pasted. Fails with conflict when the clipboard is empty.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
at_usintegerTimeline time in microseconds (1 s = 1000000). Defaults to the current playhead position. Unit: microseconds.
track_idstringOptional destination track for the pasted clips (used for clips whose type it accepts).

Returns

{pasted: [{track_id, segment}]} — the new clips.

Examples

Paste at the playhead

curl -X POST http://127.0.0.1:7777/api/v1/commands/clipboard.paste \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run clipboard.paste --project_id prj_1a2b3c4d5e6f
// MCP tool: clipboard_paste
{
  "project_id": "prj_1a2b3c4d5e6f"
}

Paste at 20 s

curl -X POST http://127.0.0.1:7777/api/v1/commands/clipboard.paste \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"at_us":20000000,"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run clipboard.paste --at_us 20s --project_id prj_1a2b3c4d5e6f
// MCP tool: clipboard_paste
{
  "at_us": 20000000,
  "project_id": "prj_1a2b3c4d5e6f"
}

edit.history

Get undo history state

No undo stepMCP edit_history

Reports whether undo/redo are available and the labels of the actions they would revert or re-apply. The editor uses this to enable the Undo/Redo buttons and show their tooltips.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{can_undo, can_redo, undo_label, redo_label}.

Examples

Check history

curl -X POST http://127.0.0.1:7777/api/v1/commands/edit.history \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run edit.history --project_id prj_1a2b3c4d5e6f
// MCP tool: edit_history
{
  "project_id": "prj_1a2b3c4d5e6f"
}

edit.redo

Redo

Ctrl+Shift+ZNo undo stepTop bar › RedoMCP edit_redo

Re-applies the change most recently reverted by edit.undo. Any new edit after an undo clears the redo history. Returns nothing_to_undo when there is nothing to redo.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

History state after redoing: {can_undo, can_redo, undo_label, redo_label}.

Examples

Redo

curl -X POST http://127.0.0.1:7777/api/v1/commands/edit.redo \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run edit.redo --project_id prj_1a2b3c4d5e6f
// MCP tool: edit_redo
{
  "project_id": "prj_1a2b3c4d5e6f"
}

edit.undo

Undo

Ctrl+ZNo undo stepTop bar › UndoMCP edit_undo

Reverts the most recent undoable change to the project (one command, or one whole batch). Works the same no matter whether the change was made in the UI or through the API. Returns nothing_to_undo when the history is empty.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

History state after undoing: {can_undo, can_redo, undo_label, redo_label}.

Examples

Undo last change

curl -X POST http://127.0.0.1:7777/api/v1/commands/edit.undo \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run edit.undo --project_id prj_1a2b3c4d5e6f
// MCP tool: edit_undo
{
  "project_id": "prj_1a2b3c4d5e6f"
}
