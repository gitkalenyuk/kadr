Presets commands

6 commands in the Presets category. Each one works the same from the editor UI, REST, MCP and kadrctl.

  • presets.applyApply preset
  • presets.deleteDelete preset
  • presets.getGet preset
  • presets.listList My kit
  • presets.renameRename preset
  • presets.saveSave to My kit

presets.apply

Apply preset

UndoableLibrary › My kit › ApplyMCP presets_apply

Applies a preset from the user's kit to a clip, like clicking a card in "My kit" with a clip selected. Only the part stored in the preset changes (e.g. a filter preset sets only the filter). This is one undo step. Clips on locked tracks are rejected (conflict); a preset of the wrong kind for the clip fails with invalid_argument and a hint. Kinds and their targets: text_style → text clips (content, word timings and animations of the target are kept); adjust → video, photo and adjustment clips; filter → video, photo, sticker and filter clips; effect → video, photo and sticker clips (merged into the clip's effect list, same id replaced) or effect clips (first effect); transition → the LEFT clip of two touching clips on a video track (duration clamped to half of the shorter clip); animation → video, photo, sticker and text clips (In/Out replace Combo and vice versa, durations fit into the clip; loop and per-letter parts only for text).

Parameters

ParameterTypeDescription
preset_idrequiredstringID of a saved preset ("pst_…"). Get it from presets.list.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringClip to apply the preset to (project.get → tracks[].segments[].id).

Returns

{preset_id, kind, name, segment_id, segment: the updated segment, notes: adjustments made to fit the clip (e.g. a clamped transition duration)}.

Examples

Apply a saved caption look to a text clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.apply \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"preset_id":"pst_4c5d6e7f8a9b","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run presets.apply --preset_id pst_4c5d6e7f8a9b --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: presets_apply
{
  "preset_id": "pst_4c5d6e7f8a9b",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

presets.delete

Delete preset

No undo stepDeletes dataLibrary › My kit › DeleteMCP presets_delete

Removes a preset from the user's kit (My kit → card → Delete). Clips that already use the look keep it — presets are copied into clips when applied, never linked. This cannot be undone with edit.undo because the kit is not part of a project.

Parameters

ParameterTypeDescription
preset_idrequiredstringID of a saved preset ("pst_…"). Get it from presets.list.

Returns

{deleted: preset id, kind}.

Examples

Delete a preset

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.delete \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"preset_id":"pst_4c5d6e7f8a9b"}'
kadrctl run presets.delete --preset_id pst_4c5d6e7f8a9b
// MCP tool: presets_delete
{
  "preset_id": "pst_4c5d6e7f8a9b"
}

presets.get

Get preset

No undo stepLibrary › My kitMCP presets_get

Returns one preset of the user's kit with all captured values (data.text_style, data.adjust, data.filter, data.effects, data.transition or data.animations depending on kind), so an AI agent can inspect what presets.apply would change before applying it.

Parameters

ParameterTypeDescription
preset_idrequiredstringID of a saved preset ("pst_…"). Get it from presets.list.

Returns

The preset: {id, kind, name, summary, source, created_at, updated_at, data}.

Examples

Inspect a preset

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.get \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"preset_id":"pst_4c5d6e7f8a9b"}'
kadrctl run presets.get --preset_id pst_4c5d6e7f8a9b
// MCP tool: presets_get
{
  "preset_id": "pst_4c5d6e7f8a9b"
}

presets.list

List My kit

No undo stepLibrary › My kitMCP presets_list

Lists the presets saved in the user's kit ("My kit" tab), newest first, optionally filtered by kind and by a case-insensitive name/summary search. Use the returned ids with presets.apply, presets.rename and presets.delete. counts reports how many presets exist per kind (before filtering), handy for building the kind navigation. The kit is per user, not per project.

Parameters

ParameterTypeDescription
kindstringOnly presets of this kind (text_style, adjust, filter, effect, transition, animation).
One of text_style adjust filter effect transition animation
querystringCase-insensitive text matched against the preset name and summary.

Returns

{presets: [preset…], total: number returned, kinds: all valid kinds, counts: {kind: n}}.

Examples

Everything in the kit

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.list \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run presets.list
// MCP tool: presets_list
{}

Only text styles

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.list \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"text_style"}'
kadrctl run presets.list --kind text_style
// MCP tool: presets_list
{
  "kind": "text_style"
}

presets.rename

Rename preset

No undo stepLibrary › My kit › RenameMCP presets_rename

Renames a preset in the user's kit (My kit → card → Rename). The name is trimmed and may be at most 80 characters; it does not need to be unique. Renaming changes nothing in any project.

Parameters

ParameterTypeDescription
namerequiredstringNew name shown in My kit (1–80 characters).
preset_idrequiredstringID of a saved preset ("pst_…"). Get it from presets.list.

Returns

The renamed preset.

Examples

Rename a look

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.rename \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"name":"Teal & orange","preset_id":"pst_4c5d6e7f8a9b"}'
kadrctl run presets.rename --name 'Teal & orange' --preset_id pst_4c5d6e7f8a9b
// MCP tool: presets_rename
{
  "name": "Teal & orange",
  "preset_id": "pst_4c5d6e7f8a9b"
}

presets.save

Save to My kit

No undo stepInspector › Add to kitMCP presets_save

Saves part of a clip's look as a reusable preset in the user's kit ("My kit" in the left library panel, the "Add to kit" buttons in the inspector). The preset is stored per user in <DataDir>/presets.json, so it is available in every project. kind decides what is captured from segment_id: text_style copies the whole text look (font, size, colour, stroke, shadow, box, glow, gradient fill, extrude, curve, word-art effect, caption highlight) but not the words; adjust copies all colour adjustments; filter, effect, transition and animation copy those settings. Fails with invalid_argument when the clip has nothing of that kind (e.g. no filter). The project is not modified, so this is not an undo step. Re-apply with presets.apply. Kinds and their targets: text_style → text clips (content, word timings and animations of the target are kept); adjust → video, photo and adjustment clips; filter → video, photo, sticker and filter clips; effect → video, photo and sticker clips (merged into the clip's effect list, same id replaced) or effect clips (first effect); transition → the LEFT clip of two touching clips on a video track (duration clamped to half of the shorter clip); animation → video, photo, sticker and text clips (In/Out replace Combo and vice versa, durations fit into the clip; loop and per-letter parts only for text).

Parameters

ParameterTypeDescription
kindrequiredstringWhat to capture: text_style (look of a text clip), adjust (colour adjustments incl. HSL/curves/LUT), filter (filter id + intensity), effect (the clip's video effects with their parameters), transition (the transition after the clip), animation (In/Out/Combo plus text loop and per-letter animations).
One of text_style adjust filter effect transition animation
project_idrequiredstringProject that contains the clip to capture (from project.list).
from_segment_idstringAlias of segment_id (accepted for compatibility); segment_id wins when both are set.
namestringName shown in My kit (max 80 characters). Default: "<Kind> <n>", e.g. "Text style 3".
segment_idstringClip to capture the look from (project.get → tracks[].segments[].id). Required unless from_segment_id is given.

Returns

The saved preset: {id, kind, name, summary, source (clip type it came from), created_at, updated_at, data: {text_style|adjust|filter|effects|transition|animations}}.

Examples

Save a caption look

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.save \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"text_style","name":"Bold yellow subtitles","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run presets.save --kind text_style --name 'Bold yellow subtitles' --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: presets_save
{
  "kind": "text_style",
  "name": "Bold yellow subtitles",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

Save a colour grade

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.save \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"adjust","name":"Warm evening","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run presets.save --kind adjust --name 'Warm evening' --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: presets_save
{
  "kind": "adjust",
  "name": "Warm evening",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}

Save a transition with an automatic name

curl -X POST http://127.0.0.1:7777/api/v1/commands/presets.save \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"kind":"transition","project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_9a8b7c6d5e4f"}'
kadrctl run presets.save --kind transition --project_id prj_1a2b3c4d5e6f --segment_id seg_9a8b7c6d5e4f
// MCP tool: presets_save
{
  "kind": "transition",
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_9a8b7c6d5e4f"
}
