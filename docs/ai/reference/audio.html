audio.detect_beats

Detect beats

UndoableToolbar › BeatMCP audio_detect_beats

Finds the beats/onsets (drum hits, note attacks) of an audio clip or of a video clip's sound, like CapCut's auto Beat feature, and returns their times on the TIMELINE in microseconds (speed and reverse of the segment are taken into account; only beats inside the segment's timeline range are returned). The source range is decoded to mono 11025 Hz and analysed in pure Go: spectral flux of the log-magnitude spectrum (512-sample window, 11.6 ms hop), adaptive threshold (local mean + delta) with peak picking, then each beat is refined in the time domain to the attack sample (typically within a few milliseconds). bpm is a rough tempo from the median beat interval. With add_markers=true a timeline marker labelled "Beat" is added at every beat (existing markers within 10 ms are kept, not duplicated) so clips can be snapped to the music. At most the first 20 minutes of the clip are analysed. Without add_markers the project is unchanged (note: the call is still recorded as an undo step).

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.
add_markersbooleanWhen true, add a timeline marker (label "Beat") at every detected beat.
Default false
sensitivitynumber0..1. Higher finds weaker onsets and allows beats closer together (min gap 80 ms at 1, 250 ms at 0). 0.5 suits most music; use 0.7-0.9 for busy percussion, 0.2-0.4 to keep only strong downbeats.
Default 0.5Range 0 … 1

Returns

{segment_id, beats_us[] (timeline µs, ascending), strengths[] (0..1 per beat), count, bpm (0 when fewer than 4 beats), sensitivity, markers_added, analyzed_us}.

Examples

List beats of a music clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/audio.detect_beats \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_0a1b2c3d4e5f"}'
kadrctl run audio.detect_beats --project_id prj_1a2b3c4d5e6f --segment_id seg_0a1b2c3d4e5f
// MCP tool: audio_detect_beats
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_0a1b2c3d4e5f"
}

Mark beats on the timeline

curl -X POST http://127.0.0.1:7777/api/v1/commands/audio.detect_beats \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"add_markers":true,"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_0a1b2c3d4e5f","sensitivity":0.7}'
kadrctl run audio.detect_beats --add_markers --project_id prj_1a2b3c4d5e6f --segment_id seg_0a1b2c3d4e5f --sensitivity 0.7
// MCP tool: audio_detect_beats
{
  "add_markers": true,
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_0a1b2c3d4e5f",
  "sensitivity": 0.7
}

audio.extract

Extract audio

UndoableTimeline › Context menu › Extract audioMCP audio_extract

CapCut's "Extract audio": separates the sound of a video clip into its own audio clip. A new segment with the same material, source range, timeline range, speed (incl. keep_pitch/curve), reverse flag, volume, fades, volume keyframes, voice effect, noise reduction and loudness normalisation is placed on the first unlocked audio track that is free at that time range (a new audio track is created otherwise). The video segment is muted (volume 0, its volume keyframes move to the audio clip) and both segments are linked with a shared link_group so they move/trim together while timeline linkage is on (an existing link_group of the video segment is reused). Works on video clips on the main or overlay tracks whose material has an audio stream; fails with invalid_argument for photos, freeze frames or silent videos, and with conflict when the clip's track is locked or its audio was already extracted.

project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Returns

{video_segment_id, audio_segment_id, audio_track_id, created_track, link_group}.

audio.loudness

Measure loudness

No undo stepInspector › Audio › BasicMCP audio_loudness

Measures the loudness of a clip's sound over its source range with ffmpeg's ebur128 filter (EBU R128 / ITU-R BS.1770-4: K-weighted, gated integrated loudness in LUFS, loudness range in LU and true peak in dBFS; mono sources are measured as dual-mono because they play on both channels). Speed, reverse and voice effects are not applied to the measurement. Also reports the clip volume in dB, the gain that "Normalize loudness" applies (brings the clip to target_lufs = -14 LUFS, but never lifts the true peak above -1 dBTP; limited to -30..+20 dB) and effective_lufs = integrated + volume_db (+ normalize gain when enabled). Silence reports -70 LUFS / -144 dBFS. Useful for AI agents balancing music against voice-over: e.g. keep background music ~10-15 LU below speech. Results are cached per file and range.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Returns

{segment_id, integrated_lufs, loudness_range_lu, true_peak_dbfs, volume_db, normalize_gain_db, normalize_enabled, effective_lufs, target_lufs, source_start_us, source_duration_us, method}.

Examples

Measure a voice-over clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/audio.loudness \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_0a1b2c3d4e5f"}'
kadrctl run audio.loudness --project_id prj_1a2b3c4d5e6f --segment_id seg_0a1b2c3d4e5f
// MCP tool: audio_loudness
{
  "project_id": "prj_1a2b3c4d5e6f",
  "segment_id": "seg_0a1b2c3d4e5f"
}

audio.restore

Restore audio

UndoableTimeline › Context menu › Restore audioMCP audio_restore

Undoes a separation at any later time (CapCut's "Restore audio"): deletes the audio clip that audio.separate / audio.extract created from a video clip and gives the video its sound back. Pass EITHER segment of the pair: the video clip (main/overlay track) or the separated audio clip (same material and link_group on an audio track). The video gets the audio clip's current volume, fades, volume keyframes, voice effect, noise reduction and loudness normalisation, so it sounds as before; trims or moves made to the audio clip alone are dropped (the video plays its own source range). If the separated audio was split, every piece is removed. An audio track left empty is deleted, and the link_group is cleared when no other clip remains linked. Fails with invalid_argument when the clip has no separated audio, and with conflict when one of the tracks is locked.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringID of the target segment (clip). Get it from project.get → tracks[].segments[].id.

Returns

{video_segment_id, removed_segment_ids[], removed_track_ids[], volume_db (restored video volume, -144 = muted), link_group}.

Examples

Put the sound back into a video clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/audio.restore \

  -d '{"project_id":"prj_1a2b3c4d5e6f","segment_id":"seg_0a1b2c3d4e5f"}'

Separate audio

CapCut's "Separate audio" (Ctrl+Shift+S): moves the sound of a video clip into its own audio clip on an audio track, exactly like audio.extract. sfx.add

Add sound effect

UndoableLibrary › Audio › Sound effectsMCP sfx_add

Adds a built-in sound effect to the timeline as an audio clip — the "+" button (or drag) of a sound effect in the Audio panel. The effect's WAV is synthesised once into the library folder (<DataDir>/library/sfx/<id>.wav), imported as a material named after the effect (the same material is reused when the effect is added again) and placed at at_us (default: the playhead) on the first audio track that is free for its whole length; a new audio track is created when all are busy (or next to track_id when that track is busy). The clip keeps the effect's full length; trim, fade or change its volume afterwards with the usual segment commands. Typical use: whoosh on a cut, pop when a sticker appears, ding on a key point, riser that ENDS at a drop (at_us = drop_us - duration_us).

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
sfx_idrequiredstringSound effect id from sfx.list (e.g. "whoosh_soft", "pop_bubble", "ding").
at_usintegerTimeline time where the effect starts (1 second = 1000000). Defaults to the playhead. Unit: microseconds.
Range 0 … ∞
track_idstringAudio track to place it on. Omit to use the first free audio track (or a new one).

Returns

{segment_id, track_id, material_id, sfx_id, name, start_us, duration_us}.

Examples

Whoosh at 2 s

tts.from_text

Speak text clip

UndoableInspector › Text › Text to speechMCP tts_from_text

Reads a text segment aloud (CapCut's Text → Text to speech): speaks the segment's content with a local voice and places the speech as an audio clip starting exactly at the text's start, on the first free audio track. The text and the speech are linked (shared link_group) so they move together. Running it again on the same text REPLACES its previous speech (handy after editing the words or changing the voice). sync_duration=true is CapCut's "sync text and speech": the text segment is stretched or shortened to the length of the speech (never overlapping the next clip on its track — then clamped=true). Fails with invalid_argument for non-text or empty segments, conflict for locked tracks, not_available without a speech engine.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
segment_idrequiredstringID of a text segment (on a text track) whose content is spoken. Get it from project.get or timeline.get.
ratenumberSpeaking speed multiplier: 1 = the voice's normal speed, 0.5 = half as fast, 2 = twice as fast.
Default 1Range 0.5 … 2
sync_durationbooleanWhen true, set the text segment's duration to the length of the speech.
Default false
voicestringVoice to use: an id from tts.voices (e.g. "sapi:Microsoft Zira Desktop", "espeak:en-us"), a voice name, a language code ("en-US", "de", "ru" — picks a voice of that language) or part of a name ("zira"). Omit for the default voice (an English system voice when installed).

Returns

{segment_id (the new audio clip), track_id, material_id, start_us, duration_us, voice, provider, path, cached, text_segment_id, text_duration_us, synced, clamped, link_group, replaced_segment_ids[]}.

tts.speak

Text to speech

UndoableLibrary › Audio › Text to speechMCP tts_speak

Speaks text with a local voice and adds the speech to the timeline as a new audio clip (CapCut's Text to speech → Add to timeline). The speech is rendered by the selected engine (Windows SAPI, eSpeak NG or macOS say — see tts.voices), trimmed of leading/trailing silence, loudness-normalised to about -16 LUFS (peaks <= -1.5 dBTP, so voice-overs from every engine sound equally loud) and saved as a 48 kHz WAV in the project's cache (cache/tts/); the file is imported as a material named "Speech: <text>" and placed at at_us on the first free audio track (a new audio track when all are busy, or on track_id). The same text, voice and rate reuse the cached file. Up to 5000 characters per call; for narration split long scripts into sentences or paragraphs. Fails with not_available when no speech engine is installed (the hint explains what to install) and not_found for an unknown voice.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
textrequiredstringWhat to say (plain text, up to 5000 characters).
at_usintegerTimeline time where the speech starts (1 second = 1000000). Defaults to the playhead. Unit: microseconds.
Range 0 … ∞
ratenumberSpeaking speed multiplier: 1 = the voice's normal speed, 0.5 = half as fast, 2 = twice as fast.
Default 1Range 0.5 … 2
track_idstringAudio track to put the clip on; when it is busy at that time a new audio track is created next to it. Omit to use the first free audio track.
voicestringVoice to use: an id from tts.voices (e.g. "sapi:Microsoft Zira Desktop", "espeak:en-us"), a voice name, a language code ("en-US", "de", "ru" — picks a voice of that language) or part of a name ("zira"). Omit for the default voice (an English system voice when installed).

Returns

{segment_id, track_id, material_id, start_us, duration_us, voice (voice id used), provider, path, cached}.

Examples

Say a line at the playhead

  "project_id": "prj_1a2b3c4d5e6f",

tts.voices

List text-to-speech voices

No undo stepLibrary › Audio › Text to speechMCP tts_voices

Lists the speech voices installed on this computer that tts.speak and tts.from_text can use, like the voice picker of CapCut's Text to speech (local engines send nothing online; the optional ElevenLabs cloud provider is used only after tts.set_api_key): Windows SAPI desktop voices (via PowerShell System.Speech, e.g. "Microsoft Zira Desktop"), eSpeak NG voices (~130 languages, robotic but universal) and macOS `say` voices. Each voice has an id "<provider>:<name>", a display name, a language code and a gender when known. providers[] tells which engines are available and why the others are not; default_voice is what is used when voice is omitted. The list is cached for 10 minutes; refresh=true re-detects (e.g. after installing a voice).

Parameters

ParameterTypeDescription
refreshbooleanRe-detect engines and voices instead of using the cached list.
Default false

Returns

{voices: [{id, provider, name, language, gender}], default_voice (voice id or "" when none), providers: [{id, name, available, voices, error}]}.

Examples

List voices

curl -X POST http://127.0.0.1:7777/api/v1/commands/tts.voices \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{}'
kadrctl run tts.voices
// MCP tool: tts_voices
{}

Re-detect voices

curl -X POST http://127.0.0.1:7777/api/v1/commands/tts.voices \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"refresh":true}'
kadrctl run tts.voices --refresh
// MCP tool: tts_voices
{
  "refresh": true
}
