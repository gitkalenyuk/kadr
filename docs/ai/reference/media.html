media.create_proxy

Create proxy

No undo stepLibrary › Media › Create proxyMCP media_create_proxy

Generates a low-resolution proxy of a video (540p on the short side, H.264, short GOP for fast seeking) in the background, like CapCut's "Create proxy". The player and timeline decode the proxy instead of the original for smooth preview of 4K/HEVC footage; export always uses the original. The command returns immediately with status "started" (or "running" if a job is already in progress, or "ready" when a proxy for the current file already exists — then proxy_path is set right away). Progress is published as media.import.progress events with stage "proxy"; when done the material's proxy_path is saved and a media.ready event with stage "proxy" is sent. Only videos can have proxies.

Parameters

ParameterTypeDescription
material_idrequiredstringID of the material (imported media item), e.g. "mat_1a2b3c4d5e6f". Get it from media.list or media.import.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
forcebooleanRegenerate the proxy even if one already exists for this file.
Default false

Returns

{material_id, status: "started"|"running"|"ready", proxy_path}.

Examples

Create a proxy for a 4K clip

curl -X POST http://127.0.0.1:7777/api/v1/commands/media.create_proxy \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"material_id":"mat_1a2b3c4d5e6f","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run media.create_proxy --material_id mat_1a2b3c4d5e6f --project_id prj_1a2b3c4d5e6f
// MCP tool: media_create_proxy
{
  "material_id": "mat_1a2b3c4d5e6f",
  "project_id": "prj_1a2b3c4d5e6f"
}

media.delete

Remove media

UndoableLibrary › Media › DeleteMCP media_delete

Removes a material from the project's media library (Media panel → right-click → Delete). Like CapCut, every timeline segment that uses it is removed from all tracks too: on the main track with the magnet on, the following clips shift left to close the gap; a transition leading into a removed clip is dropped; overlay/audio tracks that become empty are removed (the main track is kept). The file on disk is never touched and cached thumbnails are kept so edit.undo restores everything instantly.

Parameters

ParameterTypeDescription
material_idrequiredstringID of the material (imported media item), e.g. "mat_1a2b3c4d5e6f". Get it from media.list or media.import.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{deleted: true, material_id, removed_segments: [segment ids], removed_tracks: [track ids]}.

Examples

Remove a clip from the project

curl -X POST http://127.0.0.1:7777/api/v1/commands/media.delete \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"material_id":"mat_1a2b3c4d5e6f","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run media.delete --material_id mat_1a2b3c4d5e6f --project_id prj_1a2b3c4d5e6f
// MCP tool: media_delete
{
  "material_id": "mat_1a2b3c4d5e6f",
  "project_id": "prj_1a2b3c4d5e6f"
}

media.generate

Generate media

UndoableLibrary › Stickers › GeneratedMCP media_generate

Creates a procedural media file — a background, texture, pattern, test card or countdown drawn by the engine itself (no stock footage, nothing downloaded) — and adds it to the project as a normal material, like CapCut's generated/stock backgrounds but fully original and offline. Still kinds (solid colours, still gradients, grids, checkers, stripes, textures, patterns, colour bars without tone) are written as a PNG (material type photo, duration 0: it can be stretched to any length on the timeline); banner and frame are PNGs with a transparent background meant for an overlay track; kinds that move (speed > 0, noise, countdowns, timers) or make sound (colour-bar tone, countdown beeps) are rendered frame by frame and encoded to an H.264 MP4 of duration_us (material type video). Files go to <project>/cache/generated/ and are reused when the same kind, params, size, duration and fps are asked again (cached = true; the existing material is returned instead of a duplicate). Pick a ready-made look with preset_id (ids from library.list kind=generated, e.g. "sunset_gradient", "neon_floor", "countdown_5", "film_grain") — params then override single preset values — or give kind + params yourself. Size defaults to the project canvas; videos use the canvas fps (or 30) and even pixel sizes. With add_to_timeline the new material is also placed in the same undo step, exactly like timeline.segment.add: on the main track at the clip boundary nearest at_us (magnet), or appended to the end of the main track when at_us is omitted; track_id / new_track choose another track (e.g. an overlay track for grain, confetti, light leaks, film dust, banners or frames on top of a clip — light_leak and film_dust are drawn on black for segment.set_blend mode screen). Moving backgrounds with a loop param (mesh, aurora, lava, plasma, bokeh, particles, light_leak) repeat seamlessly every loop seconds, which is also their default length. Rendering runs while the command executes (typically 2-10 s for 5 s of 1080p video); duration_us is limited to 60 s — for longer backgrounds use a still kind or add the clip several times. Undo removes the material (and the placed clip); the cached file stays on disk. Kinds: • solid — a flat colour card (PNG) — backgrounds, chroma-key plates, fade cards. Params: color (color, default "#000000"): Fill colour.. • gradient — a smooth linear or radial colour gradient (PNG, or a flowing video when speed > 0). Params: colors (colors, 2-6, default ["#FF7A59","#7B2FF7"]): Colour stops, evenly spaced, from start to end (2-6).; type (enum linear|radial, default "linear"): linear = along angle; radial = from the centre outwards.; angle (number -360..360, default 135): Direction of a linear gradient in degrees: 0 = left to right, 90 = top to bottom.; speed (number 0..5, default 0): Colour flow speed in back-and-forth cycles per 10 seconds. 0 = a still picture (PNG).. • color_bars — a test card of vertical colour bars (PNG, or a video with a sine tone when tone = true). Params: style (enum classic|rainbow|retro, default "classic"): classic = broadcast-style 75% bars with a lower calibration row; rainbow = 12 hues over a grey step wedge; retro = muted 70s palette.; tone (boolean, default false): Add a continuous sine test tone (the output becomes a video with sound).; tone_hz (number 100..8000, default 1000): Frequency of the test tone in hertz.. • noise — film grain, TV static, paper and soft cloudy textures from value noise (video while speed > 0, else PNG). Params: color (color, default "#808080"): Base colour; the noise brightens and darkens it.; color2 (color): Optional second colour: the noise blends between color and color2 instead of brightening/darkening.; amount (number 0..1, default 0.5): Strength (contrast) of the noise.; scale (number 1..400, default 1): Grain size in pixels at 1080p height: 1-2 = fine grain/static, 100+ = soft clouds.; octaves (integer 1..5, default 1): Layers of finer detail added on top (fractal noise); 3-4 for paper and smoke.; monochrome (boolean, default true): Same noise in R, G and B (false = coloured RGB noise).; speed (number 0..4, default 1): How fast the noise changes: 1 = 24 new grain patterns per second (soft noise drifts smoothly). 0 = a still picture (PNG).; seed (integer 0..1e+06, default 1): Random seed: another number gives another pattern.. • shapes — circles, rounded squares, triangles and rings drifting over a colour (video while speed > 0, else PNG). Params: shape (enum mixed|circle|square|triangle|ring, default "mixed"): Which shapes to draw.; count (integer 1..80, default 18): Number of shapes.; colors (colors, 1-8, default ["#FF5C8A","#FFD23F","#3EC1D3","#9B5DE5","#00F5D4"]): Shape colours, used in turn.; background (color, default "#16161D"): Background colour.; size (number 0.01..0.5, default 0.07): Average shape radius as a fraction of the frame height.; opacity (number 0.1..1, default 0.9): Shape opacity.; speed (number 0..5, default 1): Drift speed (1 = calm). 0 = a still picture (PNG).; seed (integer 0..1e+06, default 7): Random seed for positions, sizes and directions.. • countdown — a numeric countdown (from N to 1, one number per second by default) as a video. Params: from (integer 1..60, default 5): First number; the clip counts down to 1. Default length = from seconds.; style (enum ring|plain|film, default "ring"): ring = number inside an emptying progress ring; plain = big fading numbers; film = projector-leader look with a sweeping wedge and crosshair (use a light background).; background (color, default "#111114"): Background colour.; color (color, default "#FFFFFF"): Colour of the numbers (and of the film-style circles).; accent (color, default "#FF3B5C"): Colour of the progress ring / sweeping wedge.; beep (boolean, default false): Add a short beep at every number (the video gets a sound track).. • grid — a line grid — flat (blueprint, graph paper) or a perspective floor running to the horizon (video while speed > 0, else PNG). Params: colors (colors, 2-6, default ["#FFD23F","#1B1B1F"]): Stripe colours, repeated in order.; width (number 0.005..0.5, default 0.06): Width of one stripe as a fraction of the frame height.; angle (number -180..180, default 45): Stripe direction in degrees: 0 = vertical stripes, 90 = horizontal.; speed (number 0..10, default 0): Movement in stripes per second. 0 = a still picture (PNG).. • mesh — a soft modern mesh gradient: colour clouds blended into each other, slowly drifting in a seamless loop (video while speed > 0, else PNG). Params: colors (colors, 2-6, default ["#FF9A8B","#FF6A88","#FF99AC","#FAD0C4","#A18CD1"]): Colours of the blended clouds (2-6).; softness (number 0..1, default 0.5): 0 = distinct colour patches, 1 = very soft, misty blending.; grain (number 0..0.3, default 0.04): Fine film grain on top (0 = clean).; speed (number 0..3, default 1): How far the colour clouds drift (1 = calm). 0 = a still picture (PNG).; loop (number 2..30, default 8): Seconds until the motion repeats exactly (seamless loop); also the default clip length.; seed (integer 0..1e+06, default 3): Random seed: another number gives another arrangement.. • aurora — northern lights: glowing curtains of light waving over a starry night sky (video while speed > 0, else PNG). Params: colors (colors, 2-4, default ["#00FFA3","#00C2FF","#B026FF"]): Curtain colours from the bottom edge of the light upwards.; background (color, default "#040714"): Night sky colour at the top.; color2 (color, default "#0A2A3C"): Sky colour near the horizon (bottom).; stars (boolean, default true): Twinkling stars in the sky.; landscape (boolean, default true): Dark mountain and forest silhouette along the bottom.; speed (number 0..3, default 1): Wave speed of the curtains. 0 = a still picture (PNG).; loop (number 2..30, default 10): Seconds until the motion repeats exactly (seamless loop); also the default clip length.; seed (integer 0..1e+06, default 5): Random seed: another number gives another arrangement.. • lava — glossy blobs that rise, sink, merge and split like a lava lamp (video while speed > 0, else PNG). Params: colors (colors, 1-4, default ["#FFB000","#FF3D6E","#B5179E"]): Blob colours from top to bottom of the frame.; background (color, default "#1B0B2E"): Background colour at the top.; color2 (color, default "#3A0D4F"): Background colour at the bottom.; count (integer 2..16, default 7): Number of blobs.; size (number 0.04..0.3, default 0.13): Blob radius as a fraction of the frame height.; speed (number 0..3, default 1): Rise/sink speed. 0 = a still picture (PNG).; loop (number 2..30, default 10): Seconds until the motion repeats exactly (seamless loop); also the default clip length.; seed (integer 0..1e+06, default 11): Random seed: another number gives another arrangement.. • plasma — a retro demo-scene plasma: interfering colour waves cycling through a palette (video while speed > 0, else PNG). Params: colors (colors, 1-6, default ["#FFD27A","#FF9F5A","#FFF2C4"]): Light colours.; background (color, default "#120E1C"): Background colour at the top.; color2 (color, default "#2B1B2E"): Background colour at the bottom.; count (integer 4..150, default 36): Number of light discs.; size (number 0.01..0.3, default 0.08): Average disc radius as a fraction of the frame height.; softness (number 0..1, default 0.35): Edge softness: 0 = crisp discs, 1 = very blurry.; speed (number 0..3, default 1): Drift speed. 0 = a still picture (PNG).; loop (number 2..30, default 10): Seconds until the motion repeats exactly (seamless loop); also the default clip length.; seed (integer 0..1e+06, default 8): Random seed: another number gives another arrangement.. • particles — light particles: floating dust, fireflies, falling snow, twinkling stars or rising embers (video while speed > 0, else PNG). Params: style (enum dust|fireflies|snow|stars|embers, default "dust"): dust = slow glowing motes; fireflies = wandering pulsing green-gold lights; snow = flakes falling with a sway; stars = twinkling starfield; embers = sparks rising and flickering.; color (color, default "#FFFFFF"): Particle colour (fireflies and embers tint it warmer).; background (color, default "#0B0F1A"): Background colour at the top.; color2 (color): Optional background colour at the bottom (vertical gradient).; count (integer 10..800, default 160): Number of particles.; size (number 0.2..5, default 1): Particle size multiplier.; speed (number 0..3, default 1): Movement speed. 0 = a still picture (PNG).; loop (number 2..30, default 8): Seconds until the motion repeats exactly (seamless loop); also the default clip length.; seed (integer 0..1e+06, default 4): Random seed: another number gives another arrangement.. • light_leak — film light leaks, burns, prism streaks and lens flares on black — put it on an overlay track with the Screen (or Add) blend mode (video while speed > 0, else PNG). media.import

Import media

Ctrl+IUndoableLibrary › Media › ImportMCP media_import

Imports video, photo and audio files into the project's media library — the Import button of the Media panel (left panel → Media → Local), the native file dialog, or dropping files onto the window. Every file is probed with ffprobe: type (video / photo / audio, detected from the streams and extension; animated GIFs are videos, single-frame GIFs are photos), duration (photos get 0 because they can be stretched to any length), display width/height (already swapped for 90°/270° rotated phone videos), rotation, frame rate, video/audio codecs, sample rate, channels and file size. A folder path imports the supported media files directly inside it (not recursive, max 500). Files already in the project (same path) are not imported twice: they are reported in duplicates with their existing material_id. Files that cannot be imported (missing, relative path, not a media file) are reported in errors without failing the whole import; the command only fails when nothing at all could be imported. Importing does NOT place anything on the timeline — call timeline.segment.add with the returned material ids for that. After the command returns, thumbnails, the filmstrip and audio waveforms are generated in the background: watch the media.import.progress events and media.ready (data.stage = "assets") on the event stream; the thumbnail/frame/waveform endpoints also work immediately (they generate on demand).

Parameters

ParameterTypeDescription
pathsrequiredstring[]Absolute paths of files (or folders) on the machine running Kadr, e.g. ["C:\\Users\\me\\Videos\\clip.mp4"]. Surrounding quotes and file:// URLs are accepted.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{materials: [Material], duplicates: [{path, material_id}], errors: [{path, code, message}]}. Material = {id, type (video|photo|audio), name, path, duration_us, width, height, rotation, fps, video_codec, has_audio, audio_codec, sample_rate, channels, size_bytes, imported_at}.

Examples

Import a clip and a song

curl -X POST http://127.0.0.1:7777/api/v1/commands/media.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"paths":["C:\\Users\\me\\Videos\\beach.mp4","C:\\Users\\me\\Music\\summer.mp3"],"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run media.import --paths '["C:\\Users\\me\\Videos\\beach.mp4","C:\\Users\\me\\Music\\summer.mp3"]' --project_id prj_1a2b3c4d5e6f
// MCP tool: media_import
{
  "paths": [
    "C:\\Users\\me\\Videos\\beach.mp4",
    "C:\\Users\\me\\Music\\summer.mp3"
  ],
  "project_id": "prj_1a2b3c4d5e6f"
}

Import every media file of a folder

curl -X POST http://127.0.0.1:7777/api/v1/commands/media.import \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"paths":["/home/me/Footage/trip"],"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run media.import --paths '["/home/me/Footage/trip"]' --project_id prj_1a2b3c4d5e6f

media.relink

Relink media

UndoableLibrary › Media › RelinkMCP media_relink

Points a material at another file — CapCut's "Link media" for files that were moved or renamed (the card shows a missing badge). The new file is probed and must be the same kind (video, photo or audio); the material keeps its id, so every timeline clip using it follows automatically. Metadata (duration, size, codecs…) is refreshed, the old proxy is dropped and thumbnails/waveform/filmstrip are regenerated in the background. If the new file is shorter than ranges used on the timeline, those segment ids are listed in warnings (the clips are left unchanged; trim them with timeline.segment.trim).

Parameters

ParameterTypeDescription
material_idrequiredstringID of the material (imported media item), e.g. "mat_1a2b3c4d5e6f". Get it from media.list or media.import.
pathrequiredstringAbsolute path of the replacement file on the machine running Kadr.
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{material: Material, warnings: [{segment_id, message}]}.

Examples

Relink a moved file
