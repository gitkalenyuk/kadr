playback.pause

Pause

No undo stepPlayer › PauseMCP playback_pause

Pauses playback, leaving the playhead where playback reached (pressing Pause under the player). Pausing when nothing is playing is harmless and just returns the current state. Publishes a playback.state event {playing:false, time_us} and moves the playhead (playhead.moved). Use playback.seek afterwards to put the playhead at an exact time.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Examples

Pause

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.pause \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run playback.pause --project_id prj_1a2b3c4d5e6f
// MCP tool: playback_pause
{
  "project_id": "prj_1a2b3c4d5e6f"
}

playback.play

Play

No undo stepPlayer › PlayMCP playback_play

Starts playback from the playhead (or from from_us), like pressing Play under the player. If the playhead is at the end of the timeline, playback starts over from 0. While playing, the engine advances the playhead about 10 times per second (playhead.moved events, source "playback") and stops by itself at the end; the editor shows the composited stream (/stream) with sound (/audio). Publishes a playback.state event {playing, time_us}. Playing an empty timeline does nothing and returns playing=false. Playback state is not saved in the project and is not undoable.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
from_usintegerOptional start time. Defaults to the current playhead position. Unit: microseconds.
Range 0 … ∞

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Examples

Play from the playhead

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.play \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run playback.play --project_id prj_1a2b3c4d5e6f
// MCP tool: playback_play
{
  "project_id": "prj_1a2b3c4d5e6f"
}

Play from 5 seconds

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.play \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"from_us":5000000,"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run playback.play --from_us 5s --project_id prj_1a2b3c4d5e6f
// MCP tool: playback_play
{
  "from_us": 5000000,
  "project_id": "prj_1a2b3c4d5e6f"
}

playback.seek

Seek

No undo stepTimeline › Ruler clickMCP playback_seek

Moves the playhead to time_us — clicking or dragging on the timeline ruler. The player then shows the frame at that time (render it yourself with preview.frame). If playback is running it continues from the new position (a playback.state event with the new time_us is published). Times are not clamped to the timeline length (CapCut lets the playhead sit past the last clip); negative values become 0. Publishes playhead.moved. Not undoable; does not modify the project.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
time_usrequiredintegerTarget playhead time in microseconds (2.5 s = 2500000). Unit: microseconds.

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Examples

Go to 2.5 seconds

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.seek \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","time_us":2500000}'
kadrctl run playback.seek --project_id prj_1a2b3c4d5e6f --time_us 2.5s
// MCP tool: playback_seek
{
  "project_id": "prj_1a2b3c4d5e6f",
  "time_us": 2500000
}

playback.state

Playback state

No undo stepPlayerMCP playback_state

Returns whether the project is playing, the current playhead time (advancing in real time while playing), the timeline duration and the project frame rate. Use it to poll playback started by the user or another client, or subscribe to playback.state / playhead.moved events on the WebSocket instead.

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Is it playing?

playback.step

Step frame

Left/RightNo undo stepKeyboardMCP playback_step

Moves the playhead exactly one frame (1/fps of the project frame rate, e.g. 33333 µs at 30 fps) backward or forward — the Left/Right arrow keys. The playhead is first snapped to the frame grid, so repeated steps land on frame boundaries. Pauses playback if it is running. Stepping stops at 0 and at the end of the timeline. Publishes playhead.moved.

Parameters

ParameterTypeDescription
directionrequiredstring"backward" (Left arrow) or "forward" (Right arrow).
One of backward forward
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Examples

Next frame

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.step \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"direction":"forward","project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run playback.step --direction forward --project_id prj_1a2b3c4d5e6f
// MCP tool: playback_step
{
  "direction": "forward",
  "project_id": "prj_1a2b3c4d5e6f"
}

playback.toggle

Play / Pause

SpaceNo undo stepPlayer › Play buttonMCP playback_toggle

Toggles between playing and paused — the Space key and the round play button under the player. When starting, playback begins at the playhead (from 0 if the playhead is at the end) and the engine advances the playhead in real time until the end of the timeline. When pausing, the playhead stays where playback reached. Publishes playback.state {playing, time_us}; every connected editor and API client sees the change.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.

Returns

{playing, time_us, duration_us, fps}: time_us is the playhead after the command.

Examples

Play or pause

curl -X POST http://127.0.0.1:7777/api/v1/commands/playback.toggle \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run playback.toggle --project_id prj_1a2b3c4d5e6f
// MCP tool: playback_toggle
{
  "project_id": "prj_1a2b3c4d5e6f"
}

preview.contact_sheet

Contact sheet

No undo stepPlayerMCP preview_contact_sheet

Renders several evenly spaced frames of the project into one PNG grid (a contact sheet) so an AI agent can review the whole edit — pacing, cuts, text and overlays — in a single image instead of calling preview.frame many times. Frames are sampled at the centre of `count` equal slices of [start_us, end_us) (default: the whole timeline) and laid out left-to-right, top-to-bottom; times_us lists the time of each tile in that order. Uses the same renderer as the player and export. Read-only.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
columnsintegerNumber of tiles per row; rows are added as needed.
Default 4Range 1 … 12
countintegerNumber of frames (tiles) to render.
Default 12Range 1 … 48
end_usintegerEnd of the sampled range. Defaults to the end of the last segment. Unit: microseconds.
Range 0 … ∞
start_usintegerStart of the sampled range. Defaults to 0 (timeline start). Unit: microseconds.
Range 0 … ∞
tile_widthintegerWidth of each tile; the tile height follows the canvas aspect ratio. Unit: pixels.
Default 320Range 32 … 960

Returns

{width, height, columns, rows, tile_width, tile_height, times_us[], png_base64, warnings?}.

Examples

Overview of the whole video

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.contact_sheet \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run preview.contact_sheet --project_id prj_1a2b3c4d5e6f
// MCP tool: preview_contact_sheet
{
  "project_id": "prj_1a2b3c4d5e6f"
}

Six frames of the first 10 seconds

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.contact_sheet \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"columns":3,"count":6,"end_us":10000000,"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run preview.contact_sheet --columns 3 --count 6 --end_us 10s --project_id prj_1a2b3c4d5e6f
// MCP tool: preview_contact_sheet
{
  "columns": 3,
  "count": 6,
  "end_us": 10000000,
  "project_id": "prj_1a2b3c4d5e6f"
}

preview.frame

Render frame

No undo stepPlayerMCP preview_frame

Renders the composited picture of the project at one timeline time — exactly what the player shows and what export will contain, because the same renderer is used: every visible track in order (main video, overlays, stickers, text, then filter/effect/adjustment tracks applied to everything below them), transforms, crop, opacity, blend modes, masks, chroma key, filters, adjustments, effects, animations, keyframes and transitions. Use it after edits to SEE the result. Returns the frame as base64 PNG plus `url`, the binary endpoint GET /api/v1/projects/{id}/frame (add the API token as Authorization header or ?token=; supports &w=, &h= and &format=png|jpeg). time_us defaults to the playhead; times past the end show only the canvas background. The height follows the canvas aspect ratio. Missing or undecodable media is skipped and listed in `warnings`. Read-only: the project and playhead are not changed.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
time_usintegerTimeline time to render (1 second = 1000000). Defaults to the current playhead position. Unit: microseconds.
Range 0 … ∞
widthintegerOutput width in pixels; the height is derived from the canvas aspect ratio (640 → 640x360 for 16:9). Unit: pixels.
Default 640Range 16 … 3840

Returns

{width, height, time_us, png_base64, url, warnings?, note}: png_base64 is the PNG file encoded as base64; url is the path of the same frame on the /frame endpoint (JPEG by default).

Examples

Look at the frame 2 seconds into the video

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.frame \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","time_us":2000000}'
kadrctl run preview.frame --project_id prj_1a2b3c4d5e6f --time_us 2s
// MCP tool: preview_frame
{
  "project_id": "prj_1a2b3c4d5e6f",
  "time_us": 2000000
}

Small preview at the playhead

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.frame \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","width":320}'
kadrctl run preview.frame --project_id prj_1a2b3c4d5e6f --width 320
// MCP tool: preview_frame
{
  "project_id": "prj_1a2b3c4d5e6f",

preview.layout

Canvas layout

No undo stepPlayerMCP preview_layout

Returns where every visible clip is drawn on the canvas at one moment — the boxes the player uses for on-canvas selection, move/scale/rotate handles and snapping, and that agents can use to reason about composition (e.g. 'is the title over the face?'). Covers video, photo, sticker and text segments of visible tracks (effects, filters, adjustments and audio have no box). Coordinates are canvas pixels of Project.Canvas (e.g. 1920x1080), origin top-left, +y down. Each box gives the unrotated rectangle x, y, w, h, its centre cx, cy, rotation in degrees clockwise around the centre and the four rotated corners; w/h include crop, fit, transform.scale, keyframes and the current In/Out/Combo animation (exactly the renderer's placement); text boxes are the rendered text image (incl. stroke, shadow, box). transform holds the keyframed values without animation (what segment.set_transform edits) and base_w/base_h the size at scale 1, so a handle drag maps back to x = transform.x + dx/(canvas_width/2), scale = new_w/base_w. Boxes are in compositing order: the LAST box is on top, so hit-test from the end. Both clips of a running transition are listed. Read-only.

Parameters

ParameterTypeDescription
project_idrequiredstringID of the project to operate on (e.g. "prj_8f3a..."). Get it from project.list or project.create.
time_usintegerTimeline time to lay out (1 second = 1000000). Defaults to the current playhead. Unit: microseconds.
Range 0 … ∞

Returns

{time_us, canvas_width, canvas_height, boxes:[{segment_id, track_id, track_type, type: video|photo|sticker|text, x, y, w, h, rotation, cx, cy, corners:[[x,y]×4 TL,TR,BR,BL], flip_h?, flip_v?, opacity, z, locked?, animated?, base_w, base_h, transform:{x, y, scale, rotation}, missing?}], warnings?}.

Examples

Boxes at the playhead

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.layout \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f"}'
kadrctl run preview.layout --project_id prj_1a2b3c4d5e6f
// MCP tool: preview_layout
{
  "project_id": "prj_1a2b3c4d5e6f"
}

Boxes 3 seconds in

curl -X POST http://127.0.0.1:7777/api/v1/commands/preview.layout \
  -H "Authorization: Bearer $KADR_TOKEN" \
  -d '{"project_id":"prj_1a2b3c4d5e6f","time_us":3000000}'
kadrctl run preview.layout --project_id prj_1a2b3c4d5e6f --time_us 3s
// MCP tool: preview_layout
{
  "project_id": "prj_1a2b3c4d5e6f",
