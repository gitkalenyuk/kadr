One project, three formats

You get three exports of the same edit: the original 16:9 for YouTube, a 9:16 version for TikTok, Reels and Shorts where every shot follows its subject, and a 1:1 version for feeds that shows the whole picture over a blurred fill. The original project stays as it is.

  • Time: ~2 min
  • You need: A finished 16:9 Kadr project (for example from the beat-cut recipe)
  • Main commands: project.duplicate, project.set_canvas, ai.auto_reframe, segment.set_background, preview.layout, text.update, export.estimate, export.start, export.list

Ask Claude

Take my Kadr project "Night drive" (16:9) and make two more versions as separate copies. "Night drive 9x16": switch to 9:16 and auto-reframe every main-track clip so it follows the subject, with smooth camera motion. "Night drive 1x1": switch to 1:1 and keep the full picture with a blurred background behind it. In each copy, check with preview_layout that the title fits inside the frame and make it smaller if it doesn't. Then export all three at 1080p to C:\Users\you\Videos\Kadr\night-drive\ and tell me when they're done.

Step by step

Each step shows the same calls twice. The kadrctl tab is for PowerShell: a line that starts with kadrctl --% passes JSON, and without --% the same line also works in Command Prompt. The MCP tab is the tool call an agent sends — the tool name and its arguments. Ids such as prj_…, mat_… and seg_… come from the results of earlier steps, so yours will differ. Paths under C:/Users/you are examples.

  1. Find the project

    kadrctl run project.list --query "Night drive"
    {"name": "project_list", "arguments": {"query": "Night drive"}}

    The original is prj_408e1a6dfbd6: eight shots cut to the beat, a filter, an effect, music and a title.

  2. Make the 9:16 copy and reframe it

    project.duplicate makes an independent copy (media files are shared, not copied). Segment ids stay the same in the copy, so the ids you already know still work. project.set_canvas switches the frame to 1080×1920.

    kadrctl run project.duplicate --project_id prj_408e1a6dfbd6 --name "Night drive 9x16"
kadrctl run project.set_canvas --project_id prj_b050d0c2e585 --ratio 9:16
    {"name": "project_duplicate", "arguments": {"project_id": "prj_408e1a6dfbd6", "name": "Night drive 9x16"}}
{"name": "project_set_canvas", "arguments": {"project_id": "prj_b050d0c2e585", "ratio": "9:16"}}

    Then ai.auto_reframe runs on every main-track shot in one batch (reframe-9x16.json). smoothing 0.7 makes the virtual camera move calmly.

  3. Make the title fit

    A title sized for a wide frame can be too wide for a narrow one. preview.layout returns each text box in canvas pixels; the box fits when x ≥ 0 and x + w ≤ canvas_width.

    kadrctl run preview.layout --project_id prj_b050d0c2e585 --time_us 1s
    {"name": "preview_layout", "arguments": {"project_id": "prj_b050d0c2e585", "time_us": 1000000}}
    canvas_width 1080
text  x -66   w 1212     too wide: sticks out 66 px on each side

    The cinematic template uses size 18; size 12 fits:

    kadrctl run text.update --project_id prj_b050d0c2e585 --segment_id seg_546525632ffb --size 12
kadrctl run preview.layout --project_id prj_b050d0c2e585 --time_us 1s
    {"name": "text_update", "arguments": {"project_id": "prj_b050d0c2e585", "segment_id": "seg_546525632ffb", "size": 12}}
{"name": "preview_layout", "arguments": {"project_id": "prj_b050d0c2e585", "time_us": 1000000}}
    text  x 135   w 810      fits, with 135 px margins

  4. Make the 1:1 copy with a blurred fill

    On a square canvas the 16:9 shots fit the width and leave space above and below. segment.set_background with apply_to_all fills it on every main-track clip with a blurred, zoomed copy of the clip itself.

    kadrctl run project.duplicate --project_id prj_408e1a6dfbd6 --name "Night drive 1x1"
kadrctl run project.set_canvas --project_id prj_4d5e818c84de --ratio 1:1
kadrctl run segment.set_background --project_id prj_4d5e818c84de --segment_id seg_896a3c69fde1 --type blur --blur 0.75 --apply_to_all
    {"name": "project_duplicate", "arguments": {"project_id": "prj_408e1a6dfbd6", "name": "Night drive 1x1"}}
{"name": "project_set_canvas", "arguments": {"project_id": "prj_4d5e818c84de", "ratio": "1:1"}}
{"name": "segment_set_background", "arguments": {"project_id": "prj_4d5e818c84de", "segment_id": "seg_896a3c69fde1", "type": "blur", "blur": 0.75, "apply_to_all": true}}

  5. Estimate the files

    export.estimate takes the same parameters as an export and returns the output size, frame count and file size without rendering anything.

    kadrctl run export.estimate --project_id prj_4d5e818c84de --resolution 1080p
    {"name": "export_estimate", "arguments": {"project_id": "prj_4d5e818c84de", "resolution": "1080p"}}

  6. Queue the three exports

    Exports run one at a time: the first starts right away and the others wait in state queued. 1080p means the shorter side is 1080 px, so each export gets the right shape. Missing folders are created.

    kadrctl run export.start --project_id prj_408e1a6dfbd6 --resolution 1080p --path C:/Users/you/Videos/Kadr/night-drive/night-drive-16x9.mp4
kadrctl run export.start --project_id prj_b050d0c2e585 --resolution 1080p --path C:/Users/you/Videos/Kadr/night-drive/night-drive-9x16.mp4
kadrctl run export.start --project_id prj_4d5e818c84de --resolution 1080p --path C:/Users/you/Videos/Kadr/night-drive/night-drive-1x1.mp4
kadrctl run export.list
    {"name": "export_start", "arguments": {"project_id": "prj_408e1a6dfbd6", "resolution": "1080p", "path": "C:/Users/you/Videos/Kadr/night-drive/night-drive-16x9.mp4"}}
{"name": "export_start", "arguments": {"project_id": "prj_b050d0c2e585", "resolution": "1080p", "path": "C:/Users/you/Videos/Kadr/night-drive/night-drive-9x16.mp4"}}

    Follow the jobs with export.status, or listen for export.progress and export.done on the event stream.

Variations

  • Captions in narrow frames. Re-split captions for the narrow frame with captions.relayout, for example max_words 3.
  • Different grades per copy. The copies are independent: filter.apply or segment.set_adjust in one does not touch the others.
  • Photo slideshows. ai.auto_reframe replaces existing position and scale keyframes. For a Ken Burns slideshow use the blurred fill instead so the moves stay.
  • Other sizes. project.set_canvas also offers 4:3, 3:4, 21:9, 2.35:1, 2:1, 1.85:1 and 5.8-inch.
  • Smaller files. codec hevc gives files about 30% smaller at the same quality; bitrate lower trades quality for size.

Tips

  • Positions are fractions of the canvas, so stickers and text keep their relative place after a ratio change — but check them with preview.layout or preview.contact_sheet.
  • export.list shows every job since Kadr started; jobs are forgotten on restart.
  • Delete a copy with project.delete; imported media files are never deleted.
