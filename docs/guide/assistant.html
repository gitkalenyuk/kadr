AI assistant

Kadr has an AI assistant built in. Type what you want — “cut the silent pauses”, “add bold captions”, “generate a foggy forest shot for the gap at 0:08” — and it edits your project while you watch: it reads the timeline, runs Kadr's own commands, looks at the result and answers. Every edit can be undone, risky steps wait for your OK, and one click reverts everything a chat did.

Open the assistant

Click AI in the top bar, to the left of Shortcuts and Export, or press Ctrl+Shift+A. The chat slides down over the editor; Esc closes it. Click the dock button in its header to pin it to the right side of the editor instead, so you can see the timeline and the player while it works.

Choose what powers it

The assistant needs an AI model. Kadr can use two kinds, and you can switch per chat with the picker under the message box.

Agents on this computerAPI providers
What it isAn AI coding agent you install on your PC — Claude Code, OpenAI Codex, Gemini CLI, Antigravity, Cursor Agent, GitHub Copilot CLI, OpenCode, Qwen Code, Amp, Goose, Crush, Kimi Code, Aider, Cline, Factory Droid or Warp. Kadr starts it in the background and connects it to Kadr for that chat only.A model you call directly with an API key: Anthropic (Claude), OpenAI (GPT), Google Gemini, OpenRouter, DeepSeek, xAI (Grok), Mistral, Groq, Together AI, Fireworks, Qwen (Alibaba), Moonshot (Kimi), Zhipu GLM — or a local model in Ollama or LM Studio, or any OpenAI-compatible server.
Sign-inThe agent's own sign-in (your subscription or plan) or its API keyAn API key (local models need none)
Who paysYour agent plan or keyYour API account, per token; local models are free

Set up an agent on this computer

  1. Open the settings

    Open Settings → AI assistant. Under Agents on this computer Kadr lists every agent it knows with its state: Not installed, Installed, Sign in (installed, not signed in), Chat only (it can talk but not use Kadr's tools) or Ready. The refresh button detects them again.

  2. Install

    Not installed? Click Install. Kadr runs the agent's official install command (npm, winget, pip or the vendor's script) and shows its output as it runs. Some agents need Node.js for npm — the install menu says what each method needs.

  3. Sign in

    Click Sign in. The agent's own sign-in opens the provider's website in your browser (or a terminal window for agents that sign in there); Kadr notices when you're done. Prefer a key? Open the agent's details and paste its API key instead (for example ANTHROPIC_API_KEY for Claude Code) — it is stored encrypted and passed only to that agent.

  4. Test

    Test checks detection and sign-in for free. The second test button runs one tiny real request through Kadr to prove everything works end to end (it uses a little of your plan or key).

Kadr never changes your agent's own configuration: it gives each chat its own working folder and connects Kadr's tools only for that run.

Set up an API provider

  1. In Settings → AI assistant → API providers, click Add API provider (or open one you added) and paste your API key (several keys work like for voices: in order, with failover). One OpenAI or Gemini key also serves voices and video generation.
  2. Pick a Model. Kadr lists current models with their price per million tokens; the refresh button loads the provider's live list (a free request). The eye icon marks models that can see images, the brain icon models that reason.
  3. Test checks the key for free; the tiny-prompt test sends “Reply with OK” (a few tokens).
  4. For Ollama or LM Studio, start the local server and pull a model that supports tools; Kadr finds it at its usual address (change the Base URL for a server on another PC).

At the top of the section choose what the assistant uses by default (Assistant uses, Default model, Reasoning effort). When nothing is chosen, Kadr uses Claude Code if it is ready, otherwise the first API provider with a key.

Chat

  • Type your request and press Enter (Shift+Enter for a new line). An empty chat offers a few examples to start from.
  • Attach with the paperclip: files from your PC (photos, video, documents), the selected clip or clips, or the current frame. You can also drag files from Windows Explorer, drag clips from the timeline or Media into the chat, right-click a clip and choose Ask AI about this clip, and paste images or text.
  • While it works you see what it does: each Kadr command it runs, with its arguments and result (click to expand) and thumbnails of the frames it looked at. Answers are formatted (lists, tables, code).
  • Stop ends the current turn at once. Edits already made stay — undo them or revert the chat.

What it may do without asking

The button next to the model picker sets the permission mode of the chat:

ModeBehaviour
Ask on risky (default)Edits run right away (each one can be undone). It asks before paid generation, deleting files or projects, overwriting files and anything outside Kadr.
Ask every actionEvery change waits for your approval. Reading the project never asks.
Full autoNever asks — except before paid generation, which is always confirmed and stays within your daily spending limit.

When it needs your OK, an approval card appears in the chat with what it wants to do (and the price, for paid generation): Approve, Deny (optionally with a note telling it what to do instead), or Always for this chat (not offered for paid generation). Unanswered cards are denied after 10 minutes.

Allow actions outside Kadr (in the same menu, off by default) lets an agent use its own shell, file and web tools in this chat — it still asks unless you chose Full auto. Some agents (Kimi Code, Warp) cannot be limited to Kadr's tools and start only when this is on. The default mode for new chats is in Settings → AI assistant → Permissions.

The assistant can never see or change your API keys, the spending limit or other secrets — those commands are blocked for it.

Undo a whole chat

Before the first message of a chat, Kadr remembers the project. Revert session (the undo arrow in the chat header) puts the project back exactly as it was — as one undo step, so Ctrl+Z brings the assistant's work back if you change your mind. If you also edited the project yourself since then, Kadr warns you first, because your changes would be reverted too. Single steps can always be undone with Ctrl+Z as usual.

Chat history

Each project keeps its own chats. The clock button shows them with title, model, number of actions and cost; open one to continue it, or start a New chat. Chats are stored in the project's folder, are never part of an export and are deleted with the project. In Settings → AI assistant → Chat history you can keep them forever or delete chats older than 7, 30 or 90 days.

Costs

  • API providers bill per token. Kadr prices every request with the model's list price and records it in Settings → Spending; the daily limit applies to the assistant too.
  • Agents on this computer use your plan or key; their usage is shown in the chat when the agent reports it.
  • Ollama and LM Studio run on your PC and cost nothing.
  • When the assistant generates video or speech with a paid provider, it always shows you the price and waits for your approval.

Privacy

Your messages, attachments, a description of the project and the frames the assistant looks at are sent to the AI provider you chose (or stay on your PC with a local model). Keys are kept in Kadr's encrypted vault. The assistant only edits through Kadr's commands — the same ones as the buttons — so everything it does shows up in the undo history.

Advanced settings

  • Steps per message, Output tokens, History budget and Tool result size limit how long a turn may run and how much the model reads; older parts of a long chat are summarised automatically.
  • Custom provider (in Add API provider) — add any OpenAI-compatible server (vLLM, llama.cpp server, LiteLLM, a company proxy) or an endpoint that speaks the Anthropic, OpenAI Responses or Gemini format.
  • Executable (in an agent's details) — point Kadr at an agent installed in an unusual folder.

Prefer to drive Kadr from an agent outside the app? That still works exactly as before — see the documentation for AI agents.
