Voices: cloud and local text to speech

Text to speech in Kadr works offline out of the box with the voices of your computer. If you want more natural voices, you can connect almost any speech service — ElevenLabs, OpenAI, Azure, Google and 35 more — or a speech server running on your own PC. Kadr keeps your keys encrypted, switches to the next key when one runs out, and tells you the price before a paid voice speaks.

You don't need any of this to make a voice-over: the Windows voices and eSpeak NG are free and never send anything online. How to add speech to a video is explained in Audio → Text to speech; this page is about where the voices come from.

Four kinds of voices

KindExamplesCostsLeaves your PC?
Built-inWindows voices (SAPI), eSpeak NG (about 130 languages, Ukrainian included), macOS voicesFreeNo

Providers with Ukrainian voices are marked UA in the list (for example ElevenLabs, OpenAI, Azure, Google, Cartesia, MiniMax, Narakeet, Edge, Piper and eSpeak NG).

Add a provider

  1. Open the Voices settings

    Open Settings → Voices (Home → Settings, or Menu → Settings… in the editor). At the top are the built-in engines with their voice counts; below, under Cloud & self-hosted providers, the providers you use.

  2. Pick a provider

    Click Add a provider. The gallery lists every supported service with its price hint; search by name or filter by category. Each card says whether the provider was checked against its official documentation or is experimental.

  3. Paste your API key

    Get a key from the provider's website (each card has a link to its keys page) and paste it. Kadr encrypts it right away. Self-hosted servers and Edge need no key — switch them on instead.

  4. Test it

    Click Test. This is a free check — it reads the voice list or the account, never makes paid speech — and shows whether the key works, how many voices it unlocked and, where the service reports it, how much quota is left (ElevenLabs characters, for example).

  5. Choose the model and the voice

    Pick a Default model (for ElevenLabs, for example, eleven_multilingual_v2, eleven_v3 or a fast Flash model) and a Default voice. Some services need one more setting, such as the Region of Azure or Amazon Polly. Base URL lets you point a provider at a proxy or a server on another PC. Switch on Default if Kadr should use this provider whenever you don't choose one.

The voices of every ready provider now appear in Audio → Text to speech and in the inspector under Text → Speech, grouped by provider. Click the refresh arrow next to Voice if a new provider's voices don't show up yet.

Several keys for one provider

You can store as many keys per provider as you like — say, ten ElevenLabs accounts. Kadr uses them in order: when a key is rejected, runs out of credit or hits a rate limit, the next key takes over automatically and the failed one is marked.

  • Add key — one key with an optional label (“Main”, “Backup”).
  • Paste many — one key per line. Lines like Main: sk_… set a label; empty lines, # comments and duplicates are skipped.
  • Import file… — .txt, .env, .csv or .json with one key per line or entry.

The API keys list shows every key masked (sk_…a1b2) with its status:

StatusMeaningWhat Kadr does
OKThe last request with this key workedUses it
ExhaustedOut of quota or creditSkips it until the quota resets (or for an hour), then tries again
Rate-limitedToo many requests right nowWaits the time the service asks for and uses the next key meanwhile
InvalidThe service rejected the keySkips it until you test it again or click Forget the error
Not testedNot used yetTries it in its turn
DisabledYou switched the key off (the eye button)Keeps it stored but never uses it

The arrows change the order, the pencil renames a key, the circular arrow forgets an error, the eye skips a key without deleting it, the refresh button tests one key (free), the gauge re-reads the remaining quota and the bin removes a key. Keys are never shown again after you save them — not even to you.

Prices and confirmation

Paid services charge per character (or per second of audio). Kadr knows each service's published prices, dated (“≈ $0.08 per 1000 characters, prices as of 2026-10-07”), and estimates every speech before it is made. Subscription plans such as ElevenLabs are billed from your plan's character quota instead — the key list shows what is left.

  • Kadr asks before paid speech. You see the estimated price and confirm. To skip the question for small amounts, set Ask before paying for that provider to an amount (for example 0.05): speech that costs less is made without asking.
  • The same text is free the second time. Speech you already made for the project (same text, voice and speed) is reused from the cache.
  • Daily spending limit. In Settings → Spending you can set how much Kadr may spend per day on all paid AI services together, or per provider. A request that would go over the limit is refused instead of spending. See Spending.
  • Failed speech is taken back. When the provider reports that it could not make the speech, its estimated price is refunded in Kadr's spending history, so it does not count against your limit.

Prices are estimates from the providers' public price lists. Your actual bill comes from the provider and can differ (discounts, plans, taxes, price changes).

Connect your own speech server or another service

If your service isn't in the gallery, choose Custom provider in Add a provider. Three modes:

  • OpenAI-compatible — the simplest. For any server that understands OpenAI's speech request (Kokoro-FastAPI, LocalAI, vLLM, a company proxy…): enter its Base URL, the model and voice names, and a key if it needs one. Mark it as running on this PC or your network to skip the price question.
  • HTTP template — for any other web API. Enter the method, URL and headers and write the JSON body with placeholders such as {text}, {voice}, {model}, {speed} and {lang}. Then say where the audio is in the answer: the raw audio bytes, a base64 field (JSON path such as data.audio), a URL to download, or a job to poll until it is done (job id path, poll URL with {job_id}, status path with done and failed values, result path).
  • Copy a built-in provider and change what you need, for example its address.

Click Test to check it. Custom providers are saved in Kadr's data folder; their keys go into the encrypted vault like all others.

Privacy and security

  • With a cloud voice, the text you speak is sent to that service. Built-in voices never leave your computer; self-hosted ones go only to your server.
  • Keys are encrypted by Windows for your user account (on a Mac: stored in the login Keychain). They are never written into projects, exports, logs or messages, and AI assistants cannot read them.
  • Moving to another computer? Settings → Spending → Keys & secrets → Export writes all keys into one password-protected file; Import reads it on the other PC. See Keys & secrets.
  • An ElevenLabs key you saved in Kadr 1.0 is moved into the encrypted vault automatically the first time this version starts.

Services that are not offered

PlayHT and LMNT have shut down their APIs, and Neets.ai could not be reached reliably, so they are not in the list. Hume Octave is included but marked experimental: Hume plans to end that API in November 2026.
