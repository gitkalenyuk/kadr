Fonts

Every text clip can use a different font. Kadr shows its built-in fonts and the fonts installed on your computer, and offers 146 free font families that it downloads for you in one click — 123 of them with Cyrillic letters.

Open the font picker

  1. Select a text clip

    Click a text or caption clip on the timeline (or in the player). The inspector shows Text → Basic.

  2. Click the font name

    In the Font section, click the current font's name. The font picker opens below it; your fonts are shown written in themselves.

  3. Pick a font

    Click a font to apply it at once — try a few, the picker stays open. Click the font name again or press Esc to close it.

At the top of the picker are a Search box and style chips — Sans, Serif, Display, Handwriting, Monospace, Pixel (and Symbol when you have symbol fonts) — plus a Cyrillic chip. Below them, switch between My fonts (ready to use) and More fonts (free fonts to download).

Where fonts come from

My fonts groups the fonts you can use right now by where they come from:

GroupWhat it is
Built-inFour fonts inside Kadr itself (Go Sans, Go Mono and friends). They look the same on every computer.
DownloadedFonts you downloaded from More fonts or imported from a file.
Bundled with Kadr24 free fonts that come with Kadr, all with Cyrillic: Montserrat, Rubik, Oswald, Manrope, Unbounded, Russo One, Rubik Mono One, Comfortaa, Yeseva One, Seymour One, Tektur, Rubik Bubbles, Caveat, Lobster, Pacifico, Marck Script, Amatic SC, Bad Script, Playfair Display, Lora, Prata, JetBrains Mono, Press Start 2P and Pixelify Sans. They work offline, right after installation.
On this computerEvery font installed in Windows, including the ones other programs installed.

The small badges help with other languages: UA — the font has the full Ukrainian alphabet (Ґ, Є, І, Ї); CYR — it has Cyrillic letters.

Download free fonts

  1. Open More fonts

    Switch to More fonts. You see the families you don't have yet with their style, Cyrillic support and download size; point at one to read a short note about its look and best use.

  2. Narrow the list

    Use the chips — for example Handwriting together with Cyrillic — or search for a mood such as “retro”, “script” or “mono”.

  3. Click the font

    Kadr downloads it (a small progress bar shows how far it is), checks the files and applies the font to the selected text. A message confirms when it is installed.

All 146 families are free and open-source under the SIL Open Font License, from the Google Fonts collection, so you can use them in any video, including commercial work. A download needs the internet only once: afterwards the font works offline and in every project. Fonts with several weights get a proper Regular and Bold, so the Bold button uses the real bold letters.

If a download fails — no internet, a firewall, a proxy — nothing half-finished is left behind. Click the font again to retry.

Import your own font file

Bought a font, or have one from your brand kit? Click Import font file at the bottom of the picker and choose a .ttf, .otf or .ttc file. Kadr checks it, copies it into its own folder (the original stays where it is) and adds it to My fonts → Downloaded. Import the Bold or Italic file of the same family too, and Kadr puts them together under one name.

Web fonts (.woff, .woff2) can't be imported — use the .ttf or .otf version. Make sure the font's licence allows the way you plan to use it.

Remove a font

In My fonts, point at a downloaded or imported font and click the bin, then click again to confirm. Built-in fonts and the fonts installed in Windows can't be removed here. Texts that used a removed font switch to Go Sans until you install it again — for a font from More fonts, one click brings it back.

Cyrillic and Ukrainian text

Turn on the Cyrillic chip to see only fonts that draw Cyrillic letters themselves, and look for the UA badge for complete Ukrainian. If you pick a Latin-only font for Ukrainian text, Kadr still shows every letter by borrowing the missing ones from a system font — readable, but the letters may not match. A font with the UA badge looks right.

Where the font files live

FontsFolder
Downloaded and imported%APPDATA%\Kadr\fonts, one folder per font (portable version: data\fonts next to Kadr.exe)
Bundled with Kadrthe fonts folder next to Kadr.exe
Installed in WindowsC:\Windows\Fonts and %LOCALAPPDATA%\Microsoft\Windows\Fonts

Installed a font in Windows while Kadr was open? Click the circular-arrow button next to the search box: Kadr looks through the font folders again and the new font appears.

Moving a project to another computer? Fonts are not stored inside the project. Install the same fonts there — for fonts from More fonts it is one click — otherwise those texts show Go Sans, and the font name in the inspector gets a warning sign. See How do I move a project to another computer?
